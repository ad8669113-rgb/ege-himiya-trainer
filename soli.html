Виды солей. Тривиальные названия

Что такое соль?

Соли — ионные соединения, образованные катионом металла (или NH₄⁺) и анионом кислотного остатка. Соли получаются при нейтрализации кислоты основанием или в других реакциях.

Средние соли + простые вещества

Средние соли реагируют с металлами и неметаллами (галогенами). Реакции идут по правилу вытеснения.

Соль + металл

ШАБЛОН
Соль + Активный металл → Новая соль + Металл↓ (вытесненный)
⚠️ Условие: металл стоит левее в ряду активности. Li, Na, K, Ba — с водой, не с солью!
📌 Правило
Более активный металл вытесняет менее активный из раствора его соли. Активность определяется по ряду напряжений (электрохимическому ряду).
⚡ Ряд активности металлов (сокращённый)
  • Li · K · Ba · Ca · Na · Mg · Al · Zn · Fe · Ni · Sn · Pb · H₂ · Cu · Hg · Ag · Au
  • Каждый металл левее вытесняет металл правее из раствора соли

Примеры реакций

Fe + CuSO₄ → FeSO₄ + Cu↓ Zn + 2AgNO₃ → Zn(NO₃)₂ + 2Ag↓ Cu + 2AgNO₃ → Cu(NO₃)₂ + 2Ag↓ Al + 3FeCl₂ → AlCl₃ + 3Fe   (нет: Al пассивируется в конц. HNO₃/H₂SO₄, но с солью реагирует)
⚠️ Исключения
  • Щелочные металлы (Li, Na, K) и Ca, Ba в водных растворах сначала реагируют с водой, а не с солью — вытеснения не будет
  • Na + CuSO₄(р-р): сначала Na + H₂O → NaOH + H₂↑, затем NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄

Соль + галоген (вытеснение галогенов)

ШАБЛОН
Соль галогенида + Активный галоген → Новая соль + Менее активный галоген
F₂ › Cl₂ › Br₂ › I₂ — ряд активности (убывает →)
⚠️ Реакция идёт только если галоген левее в ряду. Br₂ + NaCl → реакции нет
Cl₂ + 2NaBr → 2NaCl + Br₂   (Cl₂ вытесняет Br⁻) Cl₂ + 2KI → 2KCl + I₂   (Cl₂ вытесняет I⁻) Br₂ + 2KI → 2KBr + I₂   (Br₂ вытесняет I⁻) Br₂ + NaCl → реакция НЕ идёт (Br₂ слабее Cl₂)

Окислительные реакции солей с неметаллами

Некоторые соли реагируют с сернистым газом SO₂ как окислитель:

2KMnO₄ + 5SO₂ + 2H₂O → K₂SO₄ + 2MnSO₄ + 2H₂SO₄ Na₂SO₃ + Cl₂ + H₂O → Na₂SO₄ + 2HCl   (окисление сульфита)

Способы получения средних солей

Метод 1: реакции с участием простых веществ

Металл + неметалл → соль 2Fe + 3Cl₂ → 2FeCl₃ Ni + S →(t) NiS 2Na + S → Na₂S

Метод 2: кислота + основание / оксиды

HCl + NaOH → NaCl + H₂O   (нейтрализация) H₂SO₄ + CuO → CuSO₄ + H₂O   (кислота + основной оксид) H₂SO₄ + BaO → BaSO₄↓ + H₂O CO₂ + 2NaOH → Na₂CO₃ + H₂O   (кислотный оксид + щёлочь) SO₃ + Ca(OH)₂ → CaSO₄↓ + H₂O Кислотный оксид + основной оксид →(t) соль CO₂ + CaO →(t) CaCO₃ SiO₂ + Na₂O →(t) Na₂SiO₃

Метод 3: обменные реакции в растворе

Соль + кислота → новая соль + новая кислота  (условие: ↓ или ↑ или слабый электролит) Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ Соль + основание → новая соль + новое основание (или осадок) FeCl₃ + 3NaOH → Fe(OH)₃↓ + 3NaCl Соль + соль → две новые соли  (условие: осадок ↓) BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl

Метод 4: металл + кислота

Zn + H₂SO₄(разб.) → ZnSO₄ + H₂↑ Cu + 4HNO₃(конц.) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O 3Cu + 8HNO₃(разб.) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O Fe + 2HCl → FeCl₂ + H₂↑   (Fe с разб. HCl → Fe²⁺) 2Fe + 3Cl₂ → 2FeCl₃   (Fe с Cl₂ → Fe³⁺)
⚡ Запомни: Fe даёт разные степени окисления
  • Fe + разбавленные кислоты (HCl, H₂SO₄) → Fe²⁺ (FeCl₂, FeSO₄)
  • Fe + конц. HNO₃ → Fe³⁺ (Fe(NO₃)₃); конц. H₂SO₄ → пассивация на холоду
  • Fe + Cl₂, Br₂ → Fe³⁺ (FeCl₃)

Кислые соли

Кислые соли образуются при неполном замещении атомов водорода в многоосновной кислоте на металл.

Реакции кислых солей

1. Кислая соль + щёлочь → средняя соль + вода
NaHCO₃ + NaOH → Na₂CO₃ + H₂O HCO₃⁻ + OH⁻ → CO₃²⁻ + H₂O   (краткое ионное) NaH₂PO₄ + NaOH → Na₂HPO₄ + H₂O NaH₂PO₄ + 2NaOH → Na₃PO₄ + 2H₂O Ca(HCO₃)₂ + 2NaOH → CaCO₃↓ + Na₂CO₃ + 2H₂O
2. Кислая соль + кислота → средняя соль + кислота
NaHCO₃ + HCl → NaCl + H₂O + CO₂↑ HCO₃⁻ + H⁺ → H₂O + CO₂↑   (краткое ионное) KHSO₄ + KOH → K₂SO₄ + H₂O
3. Кислая соль + средняя соль → новая средняя соль + новая кислая соль  (условие: ↓)
Ca(HCO₃)₂ + CaCl₂ → нет реакции (нет осадка, газа) 3Ca(HCO₃)₂ + 2Na₃PO₄ → Ca₃(PO₄)₂↓ + 6NaHCO₃

Основные соли

Основные соли образуются при неполном замещении OH⁻ гидроксида на кислотный остаток. Содержат одновременно катион металла, OH⁻ и кислотный остаток.

Гидроксокомплексы

Гидроксокомплексы — комплексные соли, в которых лигандами выступают ионы OH⁻. Образуются из амфотерных гидроксидов при действии избытка щёлочи.

Образование гидроксокомплексов (4 реакции)

1. Амфотерный оксид + щёлочь(р-р) + H₂O → гидроксокомплекс Al₂O₃ + 2NaOH(р-р) + 3H₂O → 2Na[Al(OH)₄] ZnO + 2NaOH(р-р) + H₂O → Na₂[Zn(OH)₄] 2. Амфотерный гидроксид + щёлочь(р-р) → гидроксокомплекс Al(OH)₃ + NaOH + H₂O → Na[Al(OH)₄] Zn(OH)₂ + 2NaOH + 2H₂O → Na₂[Zn(OH)₄] 3. Амфотерный металл + щёлочь(р-р) + вода → гидроксокомплекс + H₂↑ 2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑ Zn + 2NaOH + 2H₂O → Na₂[Zn(OH)₄] + H₂↑ 4. Соль амфотерного металла + избыток щёлочи → гидроксокомплекс + соль AlCl₃ + 4NaOHизб. → Na[Al(OH)₄] + 3NaCl ZnSO₄ + 4NaOHизб. → Na₂[Zn(OH)₄] + Na₂SO₄
⚡ Недостаток vs избыток щёлочи
При недостатке NaOH выпадает осадок гидроксида:
AlCl₃ + 3NaOH → Al(OH)₃↓ + 3NaCl
При избытке NaOH осадок растворяется:
Al(OH)₃ + NaOH → Na[Al(OH)₄]

Свойства гидроксокомплексов (5 реакций)

1. Гидроксокомплекс + кислота → соль металла + соль щёлочного металла + вода Na[Al(OH)₄] + 4HCl → AlCl₃ + NaCl + 4H₂O Na₂[Zn(OH)₄] + 2H₂SO₄ → ZnSO₄ + Na₂SO₄ + 4H₂O 2. Гидроксокомплекс + кислотный оксид (CO₂, SO₂) → гидроксид амфот. металла↓ + кислая соль Na[Al(OH)₄] + CO₂ → Al(OH)₃↓ + NaHCO₃ Na₂[Zn(OH)₄] + CO₂ → Zn(OH)₂↓ + Na₂CO₃ 3. Гидроксокомплекс + соль аммония → гидроксид амфот. металла↓ + соль + NH₃↑ + вода Na[Al(OH)₄] + NH₄Cl → Al(OH)₃↓ + NaCl + NH₃↑ + H₂O 4. Гидроксокомплекс →(нагрев) метасоль + вода Na[Al(OH)₄] →(t) NaAlO₂ + 2H₂O Na₂[Zn(OH)₄] →(t) Na₂ZnO₂ + 2H₂O 5. Амфотерный оксид/металл + щёлочь(расплав) → метасоль + H₂↑ Al₂O₃ + 2NaOH →(сплавл.) 2NaAlO₂ + H₂O Al + NaOH(расплав) → NaAlO₂ + 1,5H₂↑
⚡ Амфотерные металлы ЕГЭ — список
  • Al → Na[Al(OH)₄] (тетрагидроксоалюминат натрия)
  • Zn → Na₂[Zn(OH)₄] (тетрагидроксоцинкат натрия)
  • Cr → Na[Cr(OH)₄] или Na₃[Cr(OH)₆]
  • Be → Na₂[Be(OH)₄]
