Основы органической химии
Определение
Органическая химия — раздел химии, изучающий соединения углерода, их строение, свойства и взаимопревращения.
Из ~20 миллионов известных химических соединений около 95% содержат атом углерода.

Атом углерода — всегда четырёхвалентен

Углерод образует ровно 4 связи. Атомы углерода могут соединяться друг с другом, образуя цепочки (линейные и разветвлённые) и кольца. Именно это делает мир органических веществ таким разнообразным.

Типы связей между атомами углерода

Тип связи Обозначение Характеристика Пример
Одинарная C–C Самая прочная, не ограничивает вращение этан CH₃–CH₃
Двойная C=C Более реакционная, участвует в реакциях присоединения этилен CH₂=CH₂
Тройная C≡C Самая реакционная из трёх ацетилен HC≡CH
⚠️ Запомни: по типу связи определяется класс углеводорода:
только C–C → алкан · одна C=C → алкен · одна C≡C → алкин · две C=C → алкадиен · бензольное кольцо → арен

Строение углеродной цепи

Атом C по числу соседей
  • Первичный — связан с 1 атомом C
  • Вторичный — связан с 2 атомами C
  • Третичный — связан с 3 атомами C
  • Четвертичный — связан с 4 атомами C
Формы цепи
  • Неразветвлённая — только первичные и вторичные C
  • Разветвлённая — есть третичные или четвертичные C
  • Замкнутая (цикл) — атомы C образуют кольцо

Примеры — найди тип каждого атома C

1° первичный 2° вторичный 3° третичный 4° четвертичный
Пентан CH₃–CH₂–CH₂–CH₂–CH₃ · неразветвлённая цепь

Крайние CH₃ — первичные: 1 сосед-углерод. Средние CH₂ — вторичные: 2 соседа. Чем больше C-соседей, тем меньше H при атоме.

2-Метилбутан · разветвлённая цепь · третичный C

C2 (CH) — третичный: связан с тремя углеродами (C1, C3 и ветвь-CH₃). Именно наличие 3° или 4° атома делает цепь разветвлённой.

2,2-Диметилпропан (неопентан) · четвертичный C

Центральный C связан с четырьмя атомами C → четвертичный. При нём нет H совсем. Встречается в сильно разветвлённых алканах.

ТЕОРИЯ 1
Как строятся названия по ИЮПАК
Название органического вещества = приставка-заместитель + корень (приставка числа C) + суффикс класса + цифра позиции
Разобрав любое название на эти части, можно сразу определить класс и строение.

Шаг 3 — Цифра в названии: позиция группы или связи

Цифра показывает, на каком по счёту атоме углерода находится функциональная группа или кратная связь. Нумерация ведётся так, чтобы цифра была наименьшей.

пропанол-1 → OH на первом C: CH₃–CH₂–CH₂OH
пропанол-2 → OH на втором C: CH₃–CH(OH)–CH₃
бутен-1 → C=C начинается с первого C: CH₂=CH–CH₂–CH₃
бутен-2 → C=C начинается со второго C: CH₃–CH=CH–CH₃
бутадиен-1,3 → две C=C: на 1-м и 3-м C: CH₂=CH–CH=CH₂

Разбор названий — тренируемся читать

1
2-метилпропанол-1
«2-метил» → есть ветка CH₃ на 2-м углероде · «проп» → 3 C в главной цепи · «ан» → одинарные связи · «ол» → спирт · «-1» → OH на 1-м углероде
→ одноатомный спирт, 4 атома C суммарно
2
Бутандиовая кислота
«бут» → 4 C · «ан» → одинарные связи · «ди» → две группы · «овая кислота» → карбоновая кислота
→ дикарбоновая кислота (щавелевая — если 2 C, это этандиовая)
3
2-аминопропановая кислота
«2-амино» → группа –NH₂ на 2-м C · «проп» → 3 C · «ановая кислота» → карбоновая кислота
→ есть и –NH₂, и –COOH → аминокислота (аланин)
4
1,2-диметилбензол (ксилол)
«1,2-диметил» → два CH₃ на позициях 1 и 2 · «бензол» → бензольное кольцо
→ арен, тривиальное название — ксилол
⚠️ Частые ловушки в именах
  • «метан» — алкан, но «метаналь» — альдегид (HCHO = формальдегид)
  • «пропанон» = ацетон — кетон, не путай с «пропаналь» = альдегид
  • «этандиовая» = щавелевая кислота — две COOH, не одна
  • Суффикс «-ат» в тривиальных названиях кислот: стеарат, пальмитат — это соли, а не сами кислоты
ТЕОРИЯ 2
Алгоритм: как определить класс соединения
В задании 10 ЕГЭ нужно быстро узнать класс вещества по формуле или названию. Используй этот алгоритм: задай вопросы по порядку и остановись на первом «да».
1
Есть бензольное кольцо C₆H₅– (или C₆H₄–)?
Ищи слово «бензол» в названии, или формулу с чередующимися C=C в кольце.
→ Да: Арен (или производное: фенол, анилин — если есть ещё –OH или –NH₂)
→ Нет: переходи к шагу 2
2
Есть атом азота N?
— Группа –NH₂ + группа –COOH → аминокислота
— Только –NH₂ (у алифатической цепи) → амин
— Группа –NO₂ → нитросоединение
— –NH₂ у бензольного кольца → анилин (ароматический амин)
→ Нет: переходи к шагу 3
3
Есть атом кислорода O?
Смотри на тип кислородсодержащей группы — ищи правый конец формулы или суффикс:
— –COOH (карбоксил) → карбоновая кислота
— –COO– (два атома O, один из них между C) → сложный эфир / жир
— –CHO (альдегидная группа, на конце цепи) → альдегид
— C=O внутри цепи (не конец) → кетон
— –OH (один O и H, у sp³ углерода) → спирт
— –OH у бензольного кольца → фенол
— –O– (атом O между двумя C, без H) → простой эфир
→ Нет: переходи к шагу 4
4
Только атомы C и H — это углеводород. Какие связи?
— Есть C≡C → Алкин
— Есть две C=C → Алкадиен
— Есть одна C=C → Алкен
— Есть цикл (замкнутая цепь), только C–C → Циклоалкан
— Только одинарные C–C → Алкан
⚠️ Ловушка: фенол (C₆H₅–OH) — это НЕ спирт, хотя содержит –OH. –OH у бензольного кольца → фенол. Спирт — это –OH у насыщенного атома C (sp³).
⚠️ Ловушка: анилин (C₆H₅–NH₂) — это ароматический амин, НЕ просто амин. В задачах ЕГЭ его часто выделяют отдельно.

⚠️ Формулы CₙH₂ₙ: алкен vs циклоалкан
Общая формула CₙH₂ₙ одинакова у алкенов И циклоалканов. Различай по строению: алкен — открытая цепь с C=C; циклоалкан — замкнутое кольцо, только C–C.
⚠️ Формулы CₙH₂ₙ₋₂: алкин vs алкадиен
Одинаковая формула, но: алкин — одна C≡C; алкадиен — две C=C. В задании смотри на суффикс (-ин vs -диен) или на количество кратных связей.

нитробензол		 нитробензол C₆H₅NO₂, нитроэтан CH₃CH₂NO₂ нитробензол; нитроглицерин = тринитроглицерин (эфир, не амин!)
Аминокислота CₙH₂ₙ₊₁NO₂ –NH₂ + –COOH в одной молекуле
глицин		 глицин H₂N–CH₂–COOH глицин = 2-аминоэтановая (аминоуксусная); аланин = 2-аминопропановая; валин = 2-амино-3-метилбутановая; глутаминовая к-та = 2-аминопентандиовая; лизин = 2,6-диаминогексановая; фенилаланин = 2-амино-3-фенилпропановая
Пептиды / белки (–NH–CHR–CO–)ₙ Пептидная связь –CO–NH– Ди-, три-, полипептиды из аминокислот Белки — природные полипептиды. В задании: ищи наличие и –NH₂, и –COOH → аминокислота; много звеньев → белок/пептид
Гетероциклические с N — N входит в кольцо
пиридин		 пиридин C₅H₅N, пиррол C₄H₅N, пролин (циклическая аминокислота) пиридин, пиррол; пролин — аминокислота с N в цикле
⚠️ Анилин — ароматический амин!
C₆H₅–NH₂ — не обычный амин, а производное бензола. Свойства отличаются: основные свойства слабее, нет реакции с кислотами как у алифатических аминов.
⚠️ Аминокислота ≠ амин!
Аминокислота содержит ОБЯЗАТЕЛЬНО и –NH₂, и –COOH. Если только –NH₂ — это амин. Если только –COOH — это кислота.
