Физические свойства. Аллотропия. Ряд ЭО

1.1 Ряд электроотрицательности

Атомы неметаллов имеют большое число электронов на внешнем слое, небольшой радиус и высокую ЭО — поэтому стремятся принимать электроны. Исключение — фтор: он всегда только окислитель, с.о. всегда −1.

◄ слабее (восстановители)сильнее (окислители) ►
Ме Si = H = P C S I Br Cl N O F
Si, H, P, C, S — преимущественно восстановители N, O, F — преимущественно окислители

1.2 Физические свойства и цвета

Важно знать наизусть агрегатное состояние и цвет каждого неметалла — это встречается в заданиях на наблюдаемые признаки реакций.

ВеществоСостояние при н.у.Цвет и особенности
F₂Газ🟡 Бледно-жёлтый. Самый сильный окислитель. С.о. всегда −1. Реагирует с водой со взрывом.
O₂ГазБесцветный, без запаха. 21% атмосферы. Жидкий O₂ — голубого цвета. Аллотропия: O₂ и O₃ (озон — резкий запах, сильнее окисляет).
Cl₂Газ🟡🟢 Жёлто-зелёный. Резкий запах. Ядовит. В воде → хлорная вода (HCl + HClO).
Br₂⚠ Жидкость🟤 Красно-бурая жидкость. Единственный жидкий неметалл при н.у.
I₂Твёрдое⬛ Серо-чёрные кристаллы. Пары фиолетовые. С крахмалом → синий цвет.
SТвёрдое🟡 Жёлтое твёрдое. Аллотропия: ромбическая S₈ (устойчивая при н.у.), моноклинная S₈.
N₂ГазБесцветный, без запаха. 78% атмосферы. Тройная связь N≡N — очень прочная.
✅ Запомнить — блок 1
  • 🟤 Br₂ — единственный жидкий неметалл. ⬛ I₂ — пары фиолетовые, с крахмалом — синий.
  • F₂ — только окислитель, с.о. всегда −1. Жидкий O₂ — голубой. О₃ — аллотроп кислорода, резкий запах.
  • Ряд ЭО: F₂ > O > N > Cl > Br > S > C > P = H = Si > Ме
  • 🟡 S↓ жёлтый осадок: при Cl₂+H₂S, H₂S+O₂(нед.), I₂+H₂S и др.
  • 🟤 NO₂ — бурый газ; NO — бесцветный; SO₂ — бесцветный, резкий запах.
2

Химические свойства галогенов

Галогены — самые активные неметаллы. Все реакции идут как реакции окисления: галоген принимает электроны. Активность убывает: F₂ > Cl₂ > Br₂ > I₂.

2.1 Реакции с водородом H₂

Все галогены реагируют с H₂, но условия и обратимость разные:

F₂ + H₂ → 2HF — взрыв в темноте, −200°C, неконтролируемо Cl₂ + H₂ →(свет или t°) 2HCl — взрыв на свету Br₂ + H₂ →(t°, кат.) 2HBr — только при нагревании I₂ + H₂ ⇄ 2HI — обратимо, неполно, I₂ частично выделяется обратно
⚠ Ловушка ЕГЭ
Реакция I₂ + H₂ — обратимая. Ставь ⇄, а не →. Иодоводород HI нестоек и разлагается при нагревании.

2.2 Реакции с металлами

Галогены реагируют со всеми металлами. Главные ловушки — железо и медь:

💡 Правило: активный галоген — максимальная с.о. металла

Активные галогены (F₂, Cl₂, Br₂) — сильные окислители: они забирают максимальное количество электронов у металла → металл в высшей с.о. (Fe³⁺, Cu²⁺).
Пассивный галоген (I₂) — слабее: забирает меньше электронов → металл в промежуточной с.о. (Fe²⁺, Cu⁺).

2Fe + 3Cl₂ →(t°) 2FeCl₃ — Fe окисляется до +3 Fe + I₂ →(t°) FeI₂ — I₂ слабее, Fe только до +2 Cu + Cl₂ →(t°) CuCl₂ — Cu до +2 2Al + 3Br₂ → 2AlBr₃ — без нагревания! 2Au + 3F₂ → 2AuF₃ — F₂ реагирует даже с золотом и платиной
🔴 Главные ловушки с металлами
  • Fe + Cl₂ → FeCl₃ (не FeCl₂!) — хлор окисляет Fe до +3
  • Fe + I₂ → FeI₂ (не FeI₃!) — иод слабее, только до +2
  • Cu + Cl₂ → CuCl₂ (не CuCl!) — хлор даёт Cu²⁺
  • F₂ реагирует с любым металлом, включая Au и Pt

2.3 Реакции с водой H₂O

2F₂ + 2H₂O → 4HF + O₂ — F₂ окисляет воду (разложение H₂O) Cl₂ + H₂O ⇄ HCl + HClO — хлорная вода, реакция диспропорционирования Br₂ + H₂O ⇄ HBr + HBrO — слабее, чем Cl₂ I₂ + H₂O ↛ — практически не реагирует
💡 Хлорная вода
Cl₂ + H₂O ⇄ HCl + HClO — смесь двух кислот. HClO (хлорноватистая кислота) — нестойкая, сильный окислитель. На свету разлагается: HClO → HCl + [O].

2.4 Реакции со щелочами

Реакции галогенов со щелочами (кроме F₂) — это диспропорционирование: один и тот же элемент одновременно окисляется и восстанавливается. Например, в Cl₂ + 2NaOH хлор из 0 идёт и в −1 (NaCl) и в +1 (NaClO). Cl₂ и Br₂ реагируют по-разному в зависимости от температуры. I₂ — при любых условиях одинаково. F₂ реагирует особо (нет диспропорционирования — F₂ только окислитель):

2F₂ + 4NaOH → 4NaF + O₂ + 2H₂O — F₂ окисляет OH⁻, выделяется O₂ Cl₂ + 2NaOH →(хол.) NaCl + NaClO + H₂O — хлорид + гипохлорит (отбеливатель) 3Cl₂ + 6KOH →(t°) 5KCl + KClO₃ + 3H₂O — хлорат Br₂ + 2NaOH →(хол.) NaBr + NaBrO + H₂O 3Br₂ + 6KOH →(t°) 5KBr + KBrO₃ + 3H₂O 3I₂ + 6KOH → 5KI + KIO₃ + 3H₂O — при любых условиях → иодат!
⚠ Ловушка ЕГЭ — иод и щелочь
I₂ + KOH всегда даёт KIO₃ (иодат), независимо от температуры. У Cl₂ и Br₂ — холод даёт гипогалогенит, горячо — галогенат. У иода такого разделения нет.

2.5 Вытеснение галогенов из солей

Более активный галоген вытесняет менее активный из раствора его соли:

Cl₂ + 2NaBr → 2NaCl + Br₂ — хлор вытесняет бром ✓ Cl₂ + 2KI → 2KCl + I₂ — хлор вытесняет иод ✓ Br₂ + 2KI → 2KBr + I₂ — бром вытесняет иод ✓ Br₂ + NaCl ↛ — бром НЕ вытесняет хлор ✗ I₂ + NaBr ↛   I₂ + NaCl ↛ — иод не вытесняет ни бром, ни хлор ✗

2.6 Реакции с галогеноводородными кислотами и кислотами-окислителями

Cl₂ + 2HBr → 2HCl + Br₂ — хлор вытесняет Br₂ из HBr Cl₂ + 2HI → 2HCl + I₂ Br₂ + 2HI → 2HBr + I₂ I₂ + 10HNO₃(конц.) → 10NO₂ + 2HIO₃ + 4H₂O
🔴 Только I₂ реагирует с конц. HNO₃!

F₂, Cl₂, Br₂ с конц. HNO₃ не реагируют — они сами сильные окислители и не могут быть окислены азотной кислотой.
Иод — самый слабый из галогенов-окислителей, поэтому конц. HNO₃ его окисляет до HIO₃.

3

Химические свойства серы

Сера — типичный неметалл с переменной с.о.: −2, 0, +4, +6. Проявляет свойства и окислителя (с металлами, H₂), и восстановителя (с кислотами-окислителями, O₂, F₂).

3.1 Сера как окислитель — с металлами и водородом

Fe + S →(t°) FeS — железо только до +2 (как с I₂!) 2Cu + S(нед.) →(t°) Cu₂S — недостаток S → Cu⁺ Cu + S(изб.) →(t°) CuS — избыток S → Cu²⁺ Hg + S → HgS — при обычных условиях! (демеркуризация ртути) 2Al + 3S →(t°) Al₂S₃ 2Na + S →(t°) Na₂S H₂ + S ⇄(t°) H₂S — обратимо
🔴 Ловушки с серой и металлами
  • Fe + S → FeS (не Fe₂S₃!) — как у иода: слабый окислитель → Fe только +2
  • Cu + S(нед.) → Cu₂S — недостаток серы → Cu только +1; Cu + S(изб.) → CuS — избыток серы → Cu до +2
  • Hg + S → HgS при н.у. — единственный металл, реагирующий с S без нагрева

3.2 Сера как восстановитель — с кислотами-окислителями и O₂

S + O₂ →(t°) SO₂ S + 2H₂SO₄(конц.) →(t°) 3SO₂ + 2H₂O S + 6HNO₃(конц.) →(t°) 6NO₂ + H₂SO₄ + 2H₂O S + 2HNO₃(разб.) →(t°) 2NO + H₂SO₄ S + F₂ → SF₆ — фторид серы(VI)

3.3 Реакция серы со щелочами — диспропорционирование

Как и галогены, сера диспропорционирует в щелочной среде: S(0) → S(+4) и S(−2) одновременно.

3S + 6KOH →(конц., t°) K₂SO₃ + 2K₂S + 3H₂O — диспропорционирование 3S + 6NaOH →(конц., t°) Na₂SO₃ + 2Na₂S + 3H₂O 3S + 6LiOH →(конц., t°) Li₂SO₃ + 2Li₂S + 3H₂O 3S + 3Ba(OH)₂ →(конц., t°) BaSO₃ + 2BaS + 3H₂O 3S + 3Ca(OH)₂ →(конц., t°) CaSO₃ + 2CaS + 3H₂O 3S + 3Sr(OH)₂ →(конц., t°) SrSO₃ + 2SrS + 3H₂O

Химические свойства азота и аммиака

Азот N₂ очень инертен из-за прочной тройной связи N≡N. Аммиак NH₃ — важнейший продукт промышленности, проявляет свойства основания и восстановителя.

4.1 Химические свойства азота N₂

N₂ + 3H₂ ⇄(t°, P, кат.) 2NH₃ — синтез Габера, обратимо N₂ + O₂ →(>1000°C или эл. разряд) 2NO — только при очень высокой t° N₂ + 3Mg →(t°) Mg₃N₂ — нитрид магния N₂ + 6Li →(t°) 2Li₃N — литий реагирует с N₂ даже при н.у. (медленно) N₂ + 3Ca →(t°) Ca₃N₂ N₂ + Fe, Cu, Ag ↛ — с малоактивными и средними металлами не реагирует
💡 Почему N₂ такой инертный?
Тройная связь N≡N — одна из самых прочных в химии (энергия 946 кДж/моль). Поэтому большинство реакций N₂ требует экстремальных условий или катализатора.

4.2 Аммиак NH₃ — свойства основания

NH₃ — слабое основание. Реагирует с кислотами, образуя соли аммония.

NH₃ + HCl → NH₄Cl — белый дым (качественная реакция на NH₃!) 2NH₃ + H₂SO₄ → (NH₄)₂SO₄ NH₃ + HNO₃ → NH₄NO₃ NH₃ + H₂O ⇄ NH₄⁺ + OH⁻ — слабое основание, реакция обратимая NH₃ + AlCl₃ + 3H₂O → Al(OH)₃↓ + 3NH₄Cl — осаждение гидроксидов

4.3 Аммиак NH₃ — свойства восстановителя

4NH₃ + 3O₂ →(t°) 2N₂ + 6H₂O — горение без катализатора → N₂ 4NH₃ + 5O₂ →(Pt, t°) 4NO + 6H₂O — каталитическое окисление → NO (производство HNO₃) 2NH₃ + 3CuO →(t°) N₂ + 3Cu + 3H₂O — NH₃ восстанавливает оксиды металлов 8NH₃ + 3Cl₂ →(изб. NH₃) N₂ + 6NH₄Cl
⚠ Главная ловушка — горение NH₃
  • Без катализатора: 4NH₃ + 3O₂ → 2N₂ + 6H₂O — продукт N₂
  • С Pt-катализатором: 4NH₃ + 5O₂ → 4NO + 6H₂O — продукт NO
  • Без указания катализатора — пиши N₂
