Раздел 1

Что такое ОВР — простым языком

Определение
Окислительно-восстановительные реакции (ОВР) — это реакции, в ходе которых степени окисления атомов элементов изменяются. Одни атомы отдают электроны, другие — принимают.

Представь атом как человека с деньгами. Отдаёт деньги — «беднеет» (степень окисления растёт). Получает — «богатеет» (степень окисления падает). Электроны — это валюта химии.

Схема ОВР
Окислитель
+
Восстановитель
→
Продукт восст.
+
Продукт окисл.
e⁻ переходят от восстановителя к окислителю
⚡
Электроны — главное
В ОВР всегда передаются электроны. Нет передачи электронов — нет ОВР.
⚖️
Баланс электронов
Сколько e⁻ отдал восстановитель — столько принял окислитель. Основа метода электронного баланса.
🔄
Две полуреакции
Любую ОВР можно разбить на окисление (отдача e⁻) и восстановление (приём e⁻). Они происходят одновременно.

Раздел 3

Алгоритм решения задания №19

Разберём на конкретной реакции — одной из самых частых на ЕГЭ:

Исходная реакция
KMnO₄  +  H₂S  +  H₂SO₄  →  MnSO₄  +  S↓  +  K₂SO₄  +  H₂O
1
Расставь степени окисления у всех элементов
Начинай с элементов с постоянной С.О.: металлы I А (+1), II А (+2), F (−1), O (−2), H (+1). Переменные элементы — через уравнение суммы.
Реакция со степенями окисления
+1K+7Mn−2O₄ + +1H₂−2S + +1H₂+6S−2O₄ → +2Mn+6S−2O₄ + 0S↓ + +1K₂+6S−2O₄ + +1H₂−2O
🟠 Mn: +7 → изменилась! 🟢 S: −2 → изменилась! K, H, O — не изменились
2
Найди атомы, у которых изменилась С.О. — определи окислитель и восстановитель
Сравни С.О. в реагентах и продуктах. Повысилась → окисление (восстановитель). Понизилась → восстановление (окислитель).
Mn: +7 → +2   С.О. понизилась → восстанавливается → окислитель (KMnO₄) S: −2 → 0    С.О. повысилась → окисляется → восстановитель (H₂S)
Раздел 5

Сильные окислители и восстановители

Правило прогноза
Высшая С.О. → только окислитель  |  Низшая С.О. → только восстановитель  |  Промежуточная → и то и другое
⚡
Только окислители — С.О. понижается после стрелки
Атомы в высшей С.О. — принимают e⁻, некуда повышать.

KMnO₄ — Mn: +7 → +2
2KMn+7O₄ + 5H₂S + 3H₂SO₄
→ 2Mn+2SO₄ + 5S↓ + K₂SO₄ + 8H₂O
HNO₃ (конц.) — N: +5 → +4
Cu + 4HN+5O₃(конц.)
→ Cu(NO₃)₂ + 2N+4O₂↑ + 2H₂O
H₂SO₄ (конц.) — S: +6 → +4
Zn + 2H₂S+6O₄(конц.)
→ ZnSO₄ + S+4O₂↑ + 2H₂O
🔋
Только восстановители — С.О. повышается после стрелки
Атомы в низшей С.О. — отдают e⁻, некуда понижать.

H₂S — S: −2 → +4
2H₂S−2 + 3O₂
→ 2S+4O₂ + 2H₂O
NH₃ — N: −3 → +2
4N−3H₃ + 5O₂
→ 4N+2O + 6H₂O
Na — Na: 0 → +1
2Na0 + Cl₂
→ 2Na+1Cl
🔄
И окислитель, и восстановитель — после стрелки С.О. одного элемента и повышается, и понижается
Атомы с промежуточной С.О. — могут и отдавать, и принимать e⁻.

Cl₂ — Cl: 0 → −1 и 0 → +1
Cl₂0 + 2NaOH
→ NaCl−1 + NaClO+1 + H₂O
H₂O₂ — O: −1 → −2 и −1 → 0
2H₂O−1₂
→ 2H₂O−2 + O0₂↑
🚫
Это НЕ ОВР — С.О. не меняется!
Если степени окисления всех элементов одинаковы в реагентах и продуктах — это не ОВР.

Нейтрализация — СО не меняются
Na+1OH + HCl → Na+1Cl + H₂O
Na: +1→+1, Cl: −1→−1 ❌ ОВР
Обмен — СО не меняются
BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
Ba: +2→+2, S: +6→+6 ❌ ОВР
Разложение карбоната — СО не меняются
CaCO₃ → CaO + CO₂
Ca: +2→+2, C: +4→+4 ❌ ОВР
Раздел 7

Лайфхаки для задания №19

🎯
«ПОВО» — мнемоника
Принимает → Окислитель → Восстанавливается. Отдаёт → Восстановитель → Окисляется.
⚡
«Флажки» — быстрое распознавание
Увидел KMnO₄, K₂Cr₂O₇, HNO₃ (конц.), H₂SO₄ (конц.) — сразу пиши «окислитель». H₂S, KI, NH₃, металл — «восстановитель».
📊
Метод «стрелка» для С.О.
Нарисуй над формулой стрелку: С.О. в реагенте → С.О. в продукте. Стрелка ↑ = окисление, ↓ = восстановление.
🚀
Порядок расстановки С.О.
Сначала K, Na, Ca, Ba, F. Потом O, H. Последними — переменные (N, S, Mn, Cr, Fe) через сумму = заряду.
