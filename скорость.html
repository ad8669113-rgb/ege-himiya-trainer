1
Что такое скорость химической реакции
▼

Скорость гомогенной реакции — изменение концентрации одного из реагирующих или образующихся веществ в единицу времени.

Формула скорости V = ±Δc / Δt    [моль/(л·с)] «+» — по продукту реакции; «−» — по реагенту
Гомогенные и гетерогенные реакции
  • Гомогенная — все вещества в одной фазе (р-р + р-р, г + г). Скорость зависит от концентрации и давления.
  • Гетерогенная — вещества в разных фазах (тв + р-р, тв + г). Скорость дополнительно зависит от площади поверхности контакта.

6 факторов, влияющих на скорость

  • Природа реагентов — тип связей, химическая активность
  • Температура — правило Вант-Гоффа: каждые +10°С → скорость × γ (2–4)
  • Концентрация — только для газов и растворов (не твёрдых!)
  • Давление — только если есть газообразные реагенты
  • Катализатор / ингибитор — снижает или повышает энергию активации
  • Площадь поверхности — только для гетерогенных реакций
2
Природа реагирующих веществ
▼

Скорость определяется типом химических связей и химической активностью реагентов. Чем активнее реагент — тем быстрее реакция.

Скорость по агрегатному состоянию

Тип реакцииПримерСкорость
тв + твFe(тв) + S(тв) → FeSОчень медленная
тв + г3Fe(тв) + 2O₂(г) → Fe₃O₄Медленная
тв + жFe(тв) + HCl(р-р) → FeCl₂ + H₂Быстрая
ж + жFeCl₂(р-р) + AgNO₃(р-р)Очень быстрая
г + гH₂(г) + F₂(г) → 2HFВзрыв, мгновенная

Химическая активность

Примеры Na + H₂O → быстрее, чем Li + H₂O (Na активнее Li) Zn + HCl → быстрее, чем Zn + CH₃COOH (HCl сильнее CH₃COOH)
⚠️ Ловушка ЕГЭ

Концентрация применима только к газам и растворам. Добавление/уменьшение количества твёрдого вещества не влияет на скорость реакции — только его измельчение (площадь поверхности).

3
Температура. Правило Вант-Гоффа
▼

Правило Вант-Гоффа: при повышении температуры на каждые 10°С скорость большинства реакций увеличивается в 2–4 раза.

V₂ = V₁ · γ^((T₂ − T₁)/10)
γ — температурный коэффициент (обычно 2–4)  ·  V₁ — скорость при T₁  ·  V₂ — скорость при T₂

Примеры расчёта

Пример 1 — повышение T на 30°С при γ = 2 V₂ = V₁ · 2^(30/10) = V₁ · 2³ = V₁ · 8 Скорость выросла в 8 раз
Пример 2 — найти γ: T₁=25°C, T₂=65°C, скорость выросла в 16 раз 16 = γ^((65−25)/10) = γ⁴ → γ = ⁴√16 = 2
⚠️ Важно

Температура влияет на скорость любой реакции — и гомогенной, и гетерогенной. Понижение температуры всегда замедляет реакцию. Катализатор не влияет на тепловой эффект реакции.

4
Концентрация реагирующих веществ
▼

С увеличением концентрации столкновения молекул происходят чаще → скорость реакции растёт.

⚠️ Главное правило

Концентрация применима только к газам и растворённым веществам. Изменение количества твёрдого вещества не влияет на скорость — его концентрация постоянна.

Разбавление и добавление воды

Добавление воды в раствор = разбавление = уменьшение концентрации → скорость уменьшается. Это типичная ловушка в задании 18.

Примеры: что влияет на концентрацию, что нет CuSO₄(р-р) + Na₂S(р-р): увеличение C(CuSO₄) или C(Na₂S) → V↑ Fe(тв) + S(тв): добавление Fe или S → V не изменится Zn(тв) + H₂SO₄(р-р): добавление воды → V↓ (разбавление)

5
Давление
▼

При увеличении давления объём газа уменьшается → концентрация газа растёт → скорость реакции увеличивается.

⚠️ Ключевое условие

Давление влияет на скорость только тогда, когда в реакции есть газообразные реагенты. Если реагенты — только твёрдые и/или растворённые вещества, давление не влияет на скорость.

Алгоритм: влияет ли давление?

Смотрим на реагенты (левую часть уравнения) N₂(г) + 3H₂(г) → 2NH₃(г)  ✓ давление влияет (есть г-реагенты) C(тв) + O₂(г) → CO₂(г)  ✓ давление влияет (O₂ — газ-реагент) Fe(тв) + S(тв) → FeS  ✗ давление не влияет (нет газов) CuSO₄(р-р) + Fe(тв) → Cu + FeSO₄  ✗ нет газообразных реагентов Газообразные ПРОДУКТЫ (↑) без газообразных реагентов — давление не влияет на скорость!

Катализатор и ингибитор
▼

Катализатор — вещество, ускоряющее реакцию, но не расходующееся в ней. Снижает энергию активации, открывая «более лёгкий путь» для реакции.

Ингибитор — замедляет реакцию. Применяется для защиты металлов от коррозии.

Каталитические реакции — запомнить!

2SO₂ + O₂ → 2SO₃
V₂O₅
2KClO₃ → 2KCl + 3O₂
MnO₂
N₂ + 3H₂ → 2NH₃
Fe
4NH₃ + 5O₂ → 4NO + 6H₂O
Pt
2H₂O₂ → 2H₂O + O₂
MnO₂
CO + 2H₂ → CH₃OH
ZnO, Cr₂O₃
⚠️ Важно
  • Катализатор подбирается индивидуально для каждой реакции.
  • Катализатор не смещает химическое равновесие, только ускоряет его достижение.
  • Ингибитор — в задании всегда уменьшает скорость, если вопрос про «что уменьшит».

7
Площадь поверхности соприкосновения
▼

Скорость гетерогенных реакций зависит от площади раздела фаз. Чем больше площадь — тем больше число столкновений между реагентами.

⚠️ Ключевое условие

Площадь поверхности влияет только если в реакции участвует твёрдое вещество (гетерогенная реакция). Для реакций г+г или р-р+р-р этот фактор не применим.

Ряд форм металла по площади поверхности

По возрастанию площади (= увеличению скорости) слиток < гранулы < стружка < порошок Измельчение = увеличение площади поверхности = ускорение реакции
Когда площадь НЕ влияет (оба реагента — газы или растворы) H₂(г) + Cl₂(г) → 2HCl(г)  — г+г, площадь не применима C₂H₄(г) + HCl(г) → C₂H₅Cl(г)  — г+г, площадь не применима CuSO₄(р-р) + NaOH(р-р) →  — р-р+р-р, площадь не применима
