хрома(VI)

Дихроматы, хроматы, оксид хрома — механизм окисления, зависимость от среды, полуреакции и метод электронного баланса.

Что такое ОВР

Окислительно-восстановительные реакции (ОВР) — реакции, при которых меняется степень окисления элементов.

Любая ОВР состоит из двух полуреакций:

Окислитель
+
Восстановитель
=
Продукт восстановления
+
Продукт окисления
В нашей теме — окислитель
Соединения хрома(VI): K₂Cr₂O₇, K₂CrO₄, CrO₃. Принимают электроны и восстанавливаются до Cr(III).

Коэффициенты расставляются методом электронного баланса (МЭБ). Ключевое: в дихромат-анионе два атома хрома → при восстановлении принимается сразу 6 электронов.

Полуреакция восстановления Cr(VI) — запомни по средам! Кислая:    Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O Нейтр.:   Cr₂O₇²⁻ + 7H₂O + 6e⁻ → 2Cr(OH)₃↓ + 8OH⁻ Щелочная: CrO₄²⁻ + 4H₂O + 3e⁻ → [Cr(OH)₆]³⁻ + 2OH⁻

Равновесие хромат ⇌ дихромат

Хроматы устойчивы в щелочной среде, дихроматы — в кислой. Переход при изменении pH:

Добавление кислоты → дихромат (оранжевый) 2K₂CrO₄ + H₂SO₄ → K₂Cr₂O₇ + K₂SO₄ + H₂O Добавление щёлочи → хромат (жёлтый) K₂Cr₂O₇ + 2KOH → 2K₂CrO₄ + H₂O
Качественный признак равновесия
Кислота + жёлтый K₂CrO₄ → раствор становится оранжевым. Щёлочь + оранжевый K₂Cr₂O₇ → жёлтым.

5

ОВР в кислой среде

В кислой среде дихромат восстанавливается до солей хрома(III). Признак: оранжевый → зелёный или серо-фиолетовый.

С хлорид-ионом (HCl конц.) K₂Cr₂O₇ + 14HCl → 2CrCl₃ + 3Cl₂↑ + 2KCl + 7H₂O 2CrO₃ + 12HCl(конц.) → 2CrCl₃ + 3Cl₂↑ + 6H₂O
С бромид- и иодид-ионами K₂Cr₂O₇ + 6KBr + 7H₂SO₄ → Cr₂(SO₄)₃ + 3Br₂ + 4K₂SO₄ + 7H₂O K₂Cr₂O₇ + 14HI → 2CrI₃ + 3I₂ + 2KI + 7H₂O
С пероксидом водорода K₂Cr₂O₇ + 3H₂O₂ + 4H₂SO₄ → Cr₂(SO₄)₃ + 3O₂↑ + K₂SO₄ + 7H₂O
С сероводородом и сульфидами K₂Cr₂O₇ + 3H₂S + 4H₂SO₄ → Cr₂(SO₄)₃ + 3S↓ + K₂SO₄ + 7H₂O K₂Cr₂O₇ + 6NaHS + 11H₂SO₄ → 2Cr₂(SO₄)₃ + 6S↓ + 2K₂SO₄ + 3Na₂SO₄ + 14H₂O
С нитритами, сульфитами, фосфином K₂Cr₂O₇ + 3NaNO₂ + 4H₂SO₄ → Cr₂(SO₄)₃ + 3NaNO₃ + K₂SO₄ + 4H₂O K₂Cr₂O₇ + 3K₂SO₃ + 4H₂SO₄ → Cr₂(SO₄)₃ + 4K₂SO₄ + 4H₂O Na₂Cr₂O₇ + 3SO₂ + H₂SO₄ → Cr₂(SO₄)₃ + Na₂SO₄ + H₂O 4K₂Cr₂O₇ + 3PH₃ + 16H₂SO₄ → 4Cr₂(SO₄)₃ + 3H₃PO₄ + 4K₂SO₄ + 16H₂O
✎ Практика — кислая среда
Реакция 1  ·  K₂Cr₂O₇ + HCl(конц.) →
Восст.: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O  (×1)
Окисл.: 2Cl⁻ → Cl₂ + 2e⁻  (×3)
────────────────────────────
K₂Cr₂O₇ + 14HCl → 2CrCl₃ + 3Cl₂↑ + 2KCl + 7H₂O
Реакция 2  ·  K₂Cr₂O₇ + KBr + H₂SO₄ →
Восст.: Cr₂O₇²⁻ + 14H⁺ + 6e⁻ → 2Cr³⁺ + 7H₂O  (×1)
Окисл.: 2Br⁻ → Br₂ + 2e⁻  (×3)
────────────────────────────
K₂Cr₂O₇ + 6KBr + 7H₂SO₄ → Cr₂(SO₄)₃ + 3Br₂ + 4K₂SO₄ + 7H₂O
6

ОВР в нейтральной среде

В нейтральной среде хроматы восстанавливаются до Cr(OH)₃↓ — зелёный осадок. На практике зачастую образуется светло-зелёный раствор тетрагидроксохромата K[Cr(OH)₄].

С нитритом натрия — нейтральная K₂Cr₂O₇ + 3NaNO₂ + 4H₂O → 2Cr(OH)₃↓ + 3NaNO₃ + 2KOH
С сульфидом калия — нейтральная 3K₂S + K₂Cr₂O₇ + 7H₂O → 3S↓ + 2Cr(OH)₃↓ + 8KOH
Образование тетрагидроксохромата (слабощелочная) Cr(OH)₃ + KOH(нед.) → K[Cr(OH)₄] K₂Cr₂O₇ + 3NaNO₂ + 4H₂O → 2K[Cr(OH)₄] + 3NaNO₃
Важно: нейтральная среда на практике
Cr(OH)₃ — амфотерный гидроксид. Растворяется в щёлочи, образующейся по ходу реакции → образуется K[Cr(OH)₄]. При смысле задания "смотри на продукт" — указывай осадок или раствор в зависимости от условия.
✎ Практика — нейтральная среда
Реакция 1  ·  K₂Cr₂O₇ + NaNO₂ + H₂O → Cr(OH)₃↓
Восст.: Cr₂O₇²⁻ + 7H₂O + 6e⁻ → 2Cr(OH)₃↓ + 4OH⁻  (×1)
Окисл.: NO₂⁻ + H₂O → NO₃⁻ + 2e⁻ + 2H⁺  (×3)
────────────────────────────
K₂Cr₂O₇ + 3NaNO₂ + 4H₂O → 2Cr(OH)₃↓ + 3NaNO₃ + 2KOH
Реакция 2  ·  K₂S + K₂Cr₂O₇ + H₂O → Cr(OH)₃↓ + S↓
Восст.: Cr₂O₇²⁻ + 7H₂O + 6e⁻ → 2Cr(OH)₃↓ + 8OH⁻  (×1)
Окисл.: S²⁻ → S↓ + 2e⁻  (×3)
────────────────────────────
3K₂S + K₂Cr₂O₇ + 7H₂O → 3S↓ + 2Cr(OH)₃↓ + 8KOH
7

Реакции сопропорционирования

Соединения хрома(VI) реагируют с солями хрома(II): оба приходят к Cr³⁺.

Cr²⁺ + Cr⁶⁺ → 2 Cr³⁺ 6CrSO₄ + K₂Cr₂O₇ + 7H₂SO₄ → 4Cr₂(SO₄)₃ + K₂SO₄ + 7H₂O K₂Cr₂O₇ + 6FeSO₄ + 7H₂SO₄ → Cr₂(SO₄)₃ + 3Fe₂(SO₄)₃ + K₂SO₄ + 7H₂O K₂Cr₂O₇ + 6FeO + 13H₂SO₄ → Cr₂(SO₄)₃ + 3Fe₂(SO₄)₃ + K₂SO₄ + 13H₂O (NH₄)₂Cr₂O₇ + 3Zn + 7H₂SO₄ → Cr₂(SO₄)₃ + 3ZnSO₄ + (NH₄)₂SO₄ + 7H₂O
Признак реакций сопропорционирования
Изменение цвета раствора с оранжевого на зелёный. При растворении твёрдых веществ — исчезновение твёрдой фазы + изменение цвета.
8

Ловушки ЕГЭ

⛔ Типичные ошибки
  • В Cr₂O₇²⁻ — два атома Cr: МЭБ принимает 6e⁻, не 3!
  • F⁻ не окисляется соединениями хрома(VI).
  • Соли аммония не окисляются хроматами/дихроматами.
  • Cl⁻ окисляется только конц. HCl, с NaCl реакция не идёт.
  • Среда определяет продукт: не пиши Cr³⁺ в щелочной и Cr(OH)₃ в кислой.
  • Нейтральная среда: Cr(OH)₃↓ или K[Cr(OH)₄] — смотри на смысл задания.
  • Нерастворимые соединения нельзя окислить в нейтральной среде — только в кислой.
📌 Цвета — запомни
  • K₂Cr₂O₇ — оранжевый раствор → после реакции: зелёный (Cr³⁺)
  • K₂CrO₄ — жёлтый → после реакции (щёлочь): изумрудно-зелёный
  • Cl₂ — жёлто-зелёный газ с резким запахом
  • Br₂ — коричневый (бромная вода)
  • S↓ — жёлтый осадок
  • O₂ — бесцветный газ без запаха
  • Cr(OH)₃↓ — зелёный осадок
  • K₃[Cr(OH)₆] — изумрудно-зелёный раствор
✎
