Что такое степень окисления?

💡 Определение
Степень окисления (с.о.) — условный заряд атома, который он получил бы, если бы все электроны в соединении перешли к более электроотрицательному атому. Слово «условный» важно: это инструмент расчётов, а не реальный заряд.
➕ Положительная
Атом отдал электроны
Na+1, Ca+2, Al+3
➖ Отрицательная
Атом принял электроны
O−2, Cl−1, N−3
0️⃣ Нулевая
Простые вещества
Na⁰, Fe⁰, O₂⁰, Cl₂⁰
🔬 Пример: NaCl
+1 Na ↑ отдаёт e⁻ восстановитель
−1 Cl ↑ принимает e⁻ окислитель
Восстановитель — тот, кто отдаёт электроны (сам окисляется, с.о. растёт).
Окислитель — тот, кто принимает электроны (сам восстанавливается, с.о. падает).
0️⃣ Почему у простого вещества с.о. = 0?
Степень окисления возникает тогда, когда один атом перетягивает электроны у другого.
Но если вещество состоит только из одного элемента — атому просто не с кем делить пару: все атомы одинаковые, никто не сильнее и не слабее. Электроны никуда не смещаются → степень окисления = 0.
Fe⁰ — железо
Cl₂⁰ — хлор
⚠ Запись
Знак ставится ПЕРЕД цифрой: +2, −1 — правильно; 2+, 1− — неправильно.

Как определить степень окисления

💡 Откуда берётся «сумма = 0»?
Молекула нейтральна — у неё нет заряда. До соединения каждый атом тоже нейтрален. Когда атомы связались, они обменялись электронами между собой — но электроны никуда не исчезли и не появились. Сколько один атом отдал — ровно столько другой принял.
Поэтому общий заряд молекулы остаётся = 0. Степень окисления — это просто способ поделить этот ноль между атомами.
NaCl: до соединения Na = 0, Cl = 0 → сумма = 0
после: Na = +1, Cl = −1 → +1 + (−1) = 0 ✓
🔢 Два элемента — проще простого
Один элемент всегда известен из таблицы, второй находишь через сумму = 0.
+4 S
−2 O₂
S + (−2·2) = 0
S = +4
+3 Fe₂
−2 O₃
2·Fe + (−2·3) = 0
Fe = +3
+1 Na
−1 Cl
(+1) + Cl = 0
Cl = −1
🔢 Три элемента — то же самое
Расставляешь известные, один остаётся неизвестным — обозначаешь его x и решаешь уравнение.
+1 H₂
+6 S
−2 O₄
+1·2 + S + (−2·4) = 0
+2 + S − 8 = 0
S = +6
+1 K
+7 Mn
−2 O₄
+1 + Mn + (−2·4) = 0
+1 + Mn − 8 = 0
Mn = +7
⚡ Ионы — сумма = заряду иона
Ион — это заряженная частица. Атом или группа атомов, которые потеряли или приобрели электроны и получили заряд: Na⁺, Cl⁻, SO₄²⁻, NH₄⁺.
Если вещество — ион, оно уже не нейтрально. Поэтому сумма с.о. = заряду иона, а не нулю.
+6 S
−2 O₄
²⁻
Заряд иона = −2
S + (−2·4) = −2
S − 8 = −2 → S = +6
−3 N
+1 H₄
⁺
Заряд иона = +1
N + (+1·4) = +1
N + 4 = +1 → N = −3
⚠ Исключение: пероксиды
В пероксидах (H₂O₂, Na₂O₂) кислород = −1, а не −2.
Видишь связь O–O в формуле или «пероксид» в названии → O = −1.
