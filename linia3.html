Что такое степень окисления?

💡 Определение
Степень окисления (с.о.) — условный заряд атома, который он получил бы, если бы все электроны в соединении перешли к более электроотрицательному атому. Слово «условный» важно: это инструмент расчётов, а не реальный заряд.
➕ Положительная
Атом отдал электроны
Na+1, Ca+2, Al+3
➖ Отрицательная
Атом принял электроны
O−2, Cl−1, N−3
0️⃣ Нулевая
Простые вещества
Na⁰, Fe⁰, O₂⁰, Cl₂⁰
🔑 Главное правило
Сумма всех с.о. в нейтральной молекуле = 0
Сумма с.о. в ионе = заряду иона
H₂O: 2·(+1)+(−2) = 0 ✓    SO₄²⁻: x+4·(−2) = −2
⚠ Запись
Знак ставится ПЕРЕД цифрой: +2, −1 — правильно; 2+, 1− — неправильно.
✏️ Задания — что такое с.о.
1
Чему равна сумма с.о. в H₂O? H = +1, O = −2.
Ответ
2·(+1)+(−2) = +2−2 = 0. Молекула нейтральна.
2
С.о. = 0 у какого типа веществ? Приведи 2 примера.
Ответ
В простых веществах с.о. всегда = 0. Примеры: Fe⁰ (железо), Cl₂⁰ (хлор).

Высшая и низшая с.о.

📓 Переписать и заучить
📌 Высшая с.о.
= номер группы
Исключения: F (нет +), O (макс. +2), Cu (макс. +2)
📌 Низшая с.о.
Металлы: = 0
Неметаллы: = номер группы − 8
ЭлементГруппаВысшая с.о.Низшая с.о.
NV+5 (HNO₃)−3 (NH₃) = 5−8
SVI+6 (H₂SO₄)−2 (H₂S) = 6−8
ClVII+7 (HClO₄)−1 (HCl) = 7−8
CIV+4 (CO₂)−4 (CH₄) = 4−8
PV+5 (H₃PO₄)−3 (PH₃) = 5−8
✏️ Задания — высшая/низшая с.о.
1
Какова высшая с.о. серы S (VI группа)?
Ответ
Высшая = номер группы = +6. Пример: H₂SO₄ (S = +6).
2
Какова низшая с.о. азота N (V группа)?
Ответ
Низшая = 5−8 = −3. Пример: NH₃ (N = −3). Диапазон N: от −3 до +5!

Как определять с.о. — пошагово

📋 5 шагов
1
Расставь постоянные с.о. — F, O, H, щелочные, Al, Zn, Ag
2
Обозначь неизвестное = x, учти количество атомов
3
Уравнение: молекула → сумма = 0; ион → сумма = заряду
4
Реши уравнение → найди x
5
Проверь: с.о. металла ≥ 0; не превышает номер группы

Разборы примеров

🔍 H₂SO₄
H=+1, O=−2, S=x
2·(+1)+x+4·(−2)=0
2+x−8=0 → S = +6
🔍 KMnO₄
K=+1, O=−2, Mn=x
(+1)+x+4·(−2)=0
1+x−8=0 → Mn = +7
⚠ Na₂O₂ (пероксид!)
Na=+1, O=x
2·(+1)+2·x=0
2+2x=0 → O = −1 (не −2!)
🔍 HPO₃²⁻ (ион!)
H=+1, O=−2, P=x
(+1)+x+3·(−2) = −2
1+x−6=−2 → P = +3
✅ Итог — ключевые правила
  • Начинай с постоянных (O, H, щелочные металлы, Al)
  • В молекуле сумма = 0; в ионе сумма = заряду
  • Умножай с.о. на количество атомов
  • В пероксидах O = −1, в гидридах H = −1
