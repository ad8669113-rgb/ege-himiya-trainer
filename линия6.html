Вещество Y

2 Читай условие: «раствор» или «твёрдое вещество»?
💧 РАСТВОР X / Y
Ищи только растворимые вещества. Нерастворимые соли и основания в раствор не войдут → исключи их из вариантов.
🧱 ТВЁРДОЕ X / Y
Ищи осадки, нерастворимые соединения или простые вещества (металлы). Растворимые соли в таком контексте — не подходят.
3Найди пару ионов, которая даёт осадок или газ по таблице растворимости / таблице газов.
4Проверь условие задания: если сказано «с X образуется осадок» — убедись, что именно с X, а не Y.
5Запиши двузначный ответ в порядке X, Y (если оговорено) или по возрастанию номеров.
Лайфхак: Запомни «БАНКА» — катионы, которые НЕ дают осадков ни с чем из стандартного набора анионов: Ba²⁺ даёт осадок с SO₄²⁻ → следи за Ba. Для задачи «осадок с X, газ с Y» сначала найди газ (проще) — это подскажет анион вещества.

Мини-пример

Дано: Na₂S реагирует с X → осадок; Na₂S реагирует с Y → газ. Вещества: 1) HCl 2) Pb(NO₃)₂ 3) CuSO₄ 4) Ba(OH)₂ 5) KNO₃

S²⁻ + Pb²⁺ → PbS↓ (чёрный осадок) → X = Pb(NO₃)₂
S²⁻ + 2H⁺ → H₂S↑ (газ с запахом) → Y = HCl
Ответ: 21 (X=Pb(NO₃)₂ → позиция 2, Y=HCl → позиция 1)

Тип 1 — Задания

Разбор типичных ошибок

  • AgNO₃ реагирует с хлоридами, давая AgCl↓ — это осадок из аниона, а не катиона. Не путай «с чем» выпадает осадок.
  • BaCl₂ с NaOH: Ba(OH)₂ растворим → осадка НЕТ. Распространённая ловушка.
  • FeCl₃ + KI → не ионный обмен, а ОВР (Fe³⁺ — окислитель). Осадка нет, хотя оба вещества — соли.
  • Na₂SO₄ + BaCl₂: BaSO₄↓ выпадает (хотя оба вещества — растворимые соли).
  • CaSO₄ — «малорастворим», не «нерастворим». В задаче может засчитываться как осадок — смотри условие.
ТИП 2 Растворение нерастворимого вещества

Теория

Нерастворимое вещество растворяется, если продукт реакции — газ, вода или слабый электролит, уводящий ион из системы. Ключевой навык: знать, что кислоты растворяют карбонаты, сульфиды, сульфиты с выделением газа, а сильные основания растворяют амфотерные гидроксиды.

Что и в чём растворяется:
• CaCO₃, BaCO₃, MgCO₃ → в любой кислоте (CO₂↑)
• FeS, ZnS, MnS → в разбавленных HCl, H₂SO₄ (H₂S↑); НЕ растворяются в H₂SO₄ конц.
• Zn(OH)₂, Al(OH)₃ → в NaOH (амфотеры)
• Cu(OH)₂ → НЕ растворяется в NaOH (не амфотер)

Алгоритм

1Определи тип нерастворимого вещества: карбонат/сульфид/гидроксид/фосфат?
2Для карбонатов/сульфидов/сульфитов: ищи кислоту в списке вариантов.
3Для гидроксидов: проверь амфотерность. Al(OH)₃ и Zn(OH)₂ → щёлочь; Fe(OH)₂ и Cu(OH)₂ → только кислота.
4Отличай «растворяется с газом» и «растворяется без газа» — в условии часто уточнено.
Лайфхак: «BaCO₃ растворяется с выделением CO₂ — кислота; растворяется без газа — ?». Без газа растворяется в НCl только если ион Ba²⁺ уходит в осадок с другим анионом... или в задаче имеется в виду другое. Перечитай условие на наличие двух критериев.

Мини-пример

BaCO₃ растворяется в HCl:
BaCO₃ + 2HCl → BaCl₂ + H₂O + CO₂↑
Ионная форма: CO₃²⁻ + 2H⁺ → H₂O + CO₂↑
BaCO₃ растворяется в H₂SO₄ — но осадок BaSO₄ может помешать → реакция идёт частично

ТИП 3 Задание с готовым ионным уравнением

Теория

Дано сокращённое ионное уравнение — нужно найти вещества X и Y из списка, реакция которых описывается этим уравнением. Главное: правильно определить, какие ионы участвуют, и сопоставить с молекулярными формулами.

Алгоритм «обратного хода»: смотришь на ионное уравнение, определяешь, какие ионы нужны (катион и анион). Затем ищешь в списке вещество, которое содержит эти ионы и при этом диссоциирует полностью (сильный электролит). Слабые кислоты, основания — в ионном уравнении не разбиваются.

Алгоритм

1Прочитай ионное уравнение. Определи, какой катион и анион взаимодействуют.
2Найди в списке вещества, содержащие эти ионы. Катион X в виде соли/кислоты и анион Y в виде соли/щёлочи.
3Проверь зрителей — ионы-наблюдатели (не участвующие в реакции) должны быть совместимы: нет нового осадка или газа между наблюдателями.
4Если уравнение включает NH₄⁺ или слабую кислоту — ищи соли аммония или слабую кислоту в списке.
Лайфхак: Ионное уравнение NH₄⁺ + OH⁻ → NH₃↑ + H₂O — значит нужна соль аммония + щёлочь. Не H₄NOH (не существует) — именно соль: (NH₄)₂SO₄, NH₄Cl, NH₄NO₃ + NaOH/KOH.

Мини-пример

Дано ионное уравнение: NH₄⁺ + OH⁻ → NH₃↑ + H₂O
X содержит NH₄⁺ (соль аммония): NH₄Cl, (NH₄)₂SO₄, NH₄NO₃
Y содержит OH⁻ (сильное основание): NaOH, KOH, Ca(OH)₂
Проверка: наблюдатели (Na⁺ и Cl⁻) — нет новых осадков ✓

Тип 3 — Задания

  • NaHCO₃ ≠ источник CO₃²⁻. HCO₃⁻ — отдельный анион, другое уравнение.
  • NH₃·H₂O — слабое основание, в ионном уравнении НЕ разбивается на NH₄⁺ + OH⁻.
  • CH₃COOH — слабая кислота, в ионном уравнении пишется целиком, не как H⁺.
  • AgF растворим! Не путать с AgCl, AgBr, AgI — все нерастворимы.
ТИП 4 Амфотерность

Теория

Главный признак Типа 4
РАСТВОРЕНИЕ ОСАДКА — вот ключевой сигнал амфотерности!
Осадок выпал → при добавлении избытка щёлочи растворился снова.

Амфотерные вещества реагируют и с кислотами, и со щелочами. В Линии 6 чаще всего проверяют: Al(OH)₃, Zn(OH)₂, Al₂O₃, ZnO. Важно: Cr(OH)₃ и Be(OH)₂ тоже амфотерны, но реже встречаются в заданиях.

Запомни навсегда: если в условии написано «сначала выпал осадок, потом растворился» — это 100% амфотерность. X = щёлочь (NaOH/KOH). Осадок — это Al(OH)₃ или Zn(OH)₂, которые растворяются в избытке щёлочи.
АмфотерРеакция с кислотойРеакция со щёлочью
Al(OH)₃Al(OH)₃ + 3HCl → AlCl₃ + 3H₂OAl(OH)₃ + NaOH → Na[Al(OH)₄] (тетрагидроксоалюминат)
Zn(OH)₂Zn(OH)₂ + H₂SO₄ → ZnSO₄ + 2H₂OZn(OH)₂ + 2NaOH → Na₂[Zn(OH)₄] (тетрагидроксоцинкат)
Al₂O₃Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂OAl₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]
ZnOZnO + H₂SO₄ → ZnSO₄ + H₂OZnO + 2NaOH + H₂O → Na₂[Zn(OH)₄]
Cr(OH)₃Cr(OH)₃ + 3HCl → CrCl₃ + 3H₂OCr(OH)₃ + NaOH → Na[Cr(OH)₄]

Алгоритм

1Смотри на «поведение осадка»: если в условии сказано «осадок сначала появляется, потом растворяется» — это амфотерность при избытке реагента.
2Для AlBr₃ + NaOH: при недостатке — Al(OH)₃↓; при избытке NaOH — осадок растворяется → Na[Al(OH)₄].
3Ищи в списке: X — щёлочь (для сначала осадка, потом растворения), Y — нейтральная соль или другую кислоту (только осадок).
Лайфхак: Задание «с X образуется осадок, который растворяется при избытке X» — это всегда NaOH/KOH + соль Al³⁺ или Zn²⁺. Запомни эту связку как флаг амфотерности.

Мини-пример

AlBr₃ + 3NaOH (нед.) → Al(OH)₃↓ + 3NaBr
Al(OH)₃ + NaOH (изб.) → Na[Al(OH)₄]
Итого при избытке: AlBr₃ + 4NaOH → Na[Al(OH)₄] + 3NaBr

Даны две пробирки с раствором гидроксида бария. В одну из двух пробирок добавили нерастворимое в воде вещество X. В результате добавленное вещество полностью растворилось. В другую пробирку добавили раствор вещества Y. В результате произошла реакция, которую описывает сокращённое ионное уравнение: NH₄⁺ + OH⁻ = NH₃ + H₂O. Из предложенного перечня выберите вещества X и Y, которые могут вступать в описанные реакции.

1) гидроксид магния
2) гидроксид цинка
3) карбонат кальция
4) ацетат аммония
5) сульфат аммония
X = 2 (гидроксид цинка), Y = 4 (ацетат аммония) → Ответ: 24
Ba(OH)₂ + Zn(OH)₂ → Ba[Zn(OH)₄] (амфотерный цинк растворяется в щёлочи). Ba(OH)₂ + 2CH₃COONH₄ → (CH₃COO)₂Ba + 2NH₃↑ + 2H₂O (NH₄⁺ + OH⁻ = NH₃ + H₂O).
  • Cu(OH)₂ НЕ амфотерен — не растворяется в NaOH. Только Al(OH)₃, Zn(OH)₂, Cr(OH)₃, Be(OH)₂.
  • NH₃(водн.) с Al³⁺ даёт Al(OH)₃↓, но осадок НЕ растворяется в избытке NH₃ (в отличие от Cu²⁺, Ag⁺).
  • Ba(OH)₂ с ZnSO₄: два осадка — Zn(OH)₂↓ И BaSO₄↓. Нельзя применять как «чистый» амфотерный тест.
ТИП 5 Особые вещества: NH₄⁺, кислые соли, гидрокарбонаты

Теория

Этот тип включает задания, где ключевую роль играют катион аммония (реагирует со щёлочью как NH₄⁺, давая NH₃↑), кислые соли (NaHCO₃, NaHSO₄, NaH₂PO₄) и гидрокарбонаты (реагируют как с кислотами, так и со щелочами).

Ключевые реакции NH₄⁺:
NH₄⁺ + OH⁻ → NH₃↑ + H₂O (нагревание усиливает)
(NH₄)₂SO₄ + 2NaOH → Na₂SO₄ + 2NH₃↑ + 2H₂O
NH₄Cl + AgNO₃ → AgCl↓ + NH₄NO₃ (Cl⁻ реагирует с Ag⁺)
Гидрокарбонат-анион HCO₃⁻:
HCO₃⁻ + H⁺ → CO₂↑ + H₂O (с кислотой)
HCO₃⁻ + OH⁻ → CO₃²⁻ + H₂O (со щёлочью, без газа)
2HCO₃⁻ + Ca²⁺ → CaCO₃↓ + H₂O + CO₂↑ (при нагревании)

Алгоритм

1Если видишь NH₄⁺ в условии: ищи щёлочь (NaOH, KOH) для NH₃↑ и ищи анионный партнёр (Cl⁻ → AgCl↓ с AgNO₃).
2Если видишь NaHCO₃: реагирует с кислотой → CO₂↑; реагирует с NaOH → Na₂CO₃ (нет газа, нет осадка).
3Для (NH₄)₂HPO₄ / (NH₄)₃PO₄ + Ba(OH)₂: сразу несколько продуктов — Ba₃(PO₄)₂↓ + NH₃↑ + H₂O.
4NaHSO₄: это кислая соль, в растворе даёт H⁺! Реагирует как кислота, не как нейтральная соль.
Лайфхак: (NH₄)₂HPO₄ + Ba(OH)₂ — «суперреакция» с двумя признаками: запах аммиака (NH₃↑) + белый осадок (Ba₃(PO₄)₂). Если в условии «два признака» — почти наверняка здесь.

№18719 · ТИП 5
Даны две пробирки с раствором вещества X. В одну из них добавили раствор гидроксида бария, при этом наблюдали образование осадка. В другую пробирку добавили раствор вещества Y и нагрели, в результате наблюдали выделение газа с резким запахом. Из предложенного перечня выберите вещества X и Y, которые могут вступать в описанные реакции.

1) (NH₄)₂HPO₄
2) NaOH
3) Ca(HCO₃)₂
4) HBr
5) HF

№18706 · ТИП 5
В пробирку с раствором щёлочи (вещество X) добавили раствор вещества Y. В результате произошла реакция, которую описывает сокращённое ионное уравнение: OH⁻ + H⁺ = H₂O. Из предложенного перечня выберите вещества X и Y, которые могут вступать в описанную реакцию.

1) сульфид калия
2) угольная кислота
3) серная кислота
4) гидроксид бария
5) гидроксид натрия
X = 5 (гидроксид натрия), Y = 3 (серная кислота) → Ответ: 53
NaOH + H₂SO₄ → Na₂SO₄ + H₂O (видимые признаки отсутствуют). Угольная кислота — слабая, в ионном уравнении не пишется как H⁺. Сульфид калия — не щёлочь. Гидроксид бария — щёлочь, но с H₂SO₄ даёт BaSO₄↓ — другое уравнение.
№18690 · ТИП 5
Даны две пробирки с раствором гидросульфита натрия. В одну из них добавили раствор вещества X, а в другую — раствор вещества Y. В результате в пробирке с веществом X выделился газ, а в пробирке с веществом Y выпал осадок. Из предложенного перечня выберите вещества X и Y, которые могут вступать в описанные реакции.

1) иодоводород
2) гидроксид натрия
3) сульфат бария
4) гидроксид кальция
5) фосфат калия
X = 1 (иодоводород), Y = 4 (гидроксид кальция) → Ответ: 14
NaHSO₃ + HI → NaI + SO₂↑ + H₂O (выделение газа SO₂). NaHSO₃ + Ca(OH)₂ → CaSO₃↓ (белый) + Na₂SO₃ + H₂O (осадок). Сульфат бария нерастворим — не реагирует с раствором.
№18668 · ТИП 5
Даны две пробирки с раствором бромида меди(II). В первую пробирку добавили металл X, в результате наблюдали образование красноватого налёта на его поверхности. Во вторую пробирку добавили раствор вещества Y. В этой пробирке произошла реакция, которую описывает сокращённое ионное уравнение: Cu²⁺ + S²⁻ = CuS. Из предложенного перечня выберите вещества X и Y, которые могут вступать в описанные реакции.

1) сероводород
2) железо
3) сульфид натрия
4) серебро
5) гидросульфид калия
X = 2 (железо), Y = 3 (сульфид натрия) → Ответ: 23
CuBr₂ + Fe → FeBr₂ + Cu↓ (красноватый налёт меди на поверхности железа). CuBr₂ + Na₂S → CuS↓ (чёрный) + 2NaBr (Cu²⁺ + S²⁻ = CuS). Серебро не вытесняет медь (Cu активнее Ag). Сероводород — слабая кислота, не даёт S²⁻ полностью.
  • NaHCO₃ + NaOH — нет газа и нет осадка (→ Na₂CO₃ + H₂O). Часто ошибочно ждут CO₂.
  • NaHSO₄ в растворе — это фактически кислота (H⁺ + HSO₄⁻ → 2H⁺ + SO₄²⁻). Не нейтральная соль!
  • Ca(OH)₂ + NaHCO₃ → осадок CaCO₃ (не газ). Гидрокарбонат в избытке Ca²⁺ всегда даёт CaCO₃↓.
ШПАРГАЛКА 5-минутное повторение перед экзаменом

Осадки — белые

  • BaSO₄ — Ba²⁺ + SO₄²⁻
  • AgCl — Ag⁺ + Cl⁻
  • Al(OH)₃ — Al³⁺ + OH⁻
  • Zn(OH)₂ — Zn²⁺ + OH⁻
  • BaCO₃ — Ba²⁺ + CO₃²⁻
  • CaCO₃ — Ca²⁺ + CO₃²⁻
  • Mg(OH)₂ — Mg²⁺ + OH⁻

Осадки — цветные

  • Cu(OH)₂ — голубой
  • Fe(OH)₂ — зелёный/серый
  • Fe(OH)₃ — бурый/рыжий
  • PbS, CuS — чёрные
  • AgBr — светло-жёлтый
  • AgI — жёлтый
  • Ag₃PO₄ — жёлтый

Газы при ионном обмене

  • CO₂↑ — CO₃²⁻ + H⁺
  • H₂S↑ — S²⁻ + H⁺
  • SO₂↑ — SO₃²⁻ + H⁺
  • NH₃↑ — NH₄⁺ + OH⁻
  • HF↑ (при нагр.) — F⁻ + H⁺

Амфотеры

  • Al(OH)₃ ✓ реаг. с NaOH
  • Zn(OH)₂ ✓ реаг. с NaOH
  • Al₂O₃ ✓ реаг. с NaOH
  • ZnO ✓ реаг. с NaOH
  • Cr(OH)₃ ✓ реаг. с NaOH
  • Cu(OH)₂ ✗ НЕ амфотер
  • Fe(OH)₂/₃ ✗ НЕ амфотер

Всегда растворимы (помни)

  • Все нитраты NO₃⁻
  • Все соли Na⁺, K⁺, NH₄⁺
  • BaCl₂, BaBr₂, Ba(NO₃)₂
  • Ca(NO₃)₂, CaCl₂, CaBr₂
  • AgNO₃, AgF
  • Pb(NO₃)₂

Особые реакции

  • NH₄⁺ + OH⁻ → NH₃↑
  • HCO₃⁻ + H⁺ → CO₂↑
  • HCO₃⁻ + OH⁻ → CO₃²⁻
  • 2Fe³⁺ + 2I⁻ → 2Fe²⁺ + I₂ (ОВР!)
  • Al³⁺ + 4OH⁻(изб) → [Al(OH)₄]⁻
  • Zn²⁺ + 4OH⁻(изб) → [Zn(OH)₄]²⁻

5 типов — ключи

  • Тип 1: осадок/газ при смешив.
  • Тип 2: растворение осадка
  • Тип 3: по ионному уравн.
  • Тип 4: амфотерность Al/Zn
  • Тип 5: NH₄⁺, HCO₃⁻, HSO₄⁻

Слабые электролиты (не бьются на ионы!)

  • H₂O — вода
  • H₂S, H₂CO₃, H₂SO₃
  • HF, CH₃COOH
  • NH₃·H₂O
  • HCN, H₃PO₄ (слабая)
