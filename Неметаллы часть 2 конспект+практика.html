Аллотропия. Физические свойства. Ключевые ловушки

1.1 Аллотропные модификации

Аллотропия — существование двух и более простых веществ одного элемента. Модификации отличаются структурой кристаллов или составом молекул.

⚫ Углерод C
Алмаз — атомная решётка, sp³, изолятор, самый твёрдый
Графит — слоистая, sp², проводник тока
Фуллерен C₆₀ — молекулярная решётка, шарообразная молекула
🔴 Фосфор P
Белый P₄ — молек. решётка, ядовит, светится, самовоспл.
Красный P — атомная, не ядовит, не светится
Чёрный P — слоистая, полупроводник, наиболее стабилен
🔵 Водород H
Протий ¹H — обычный водород (99,98%)
Дейтерий ²H — тяжёлый водород
Тритий ³H — радиоактивный

1.2 Физические свойства при н.у.

ВеществоСостояниеЦвет и особенности
P₄ белыйТвёрдое⬜ Восковидный, ядовит. Светится в темноте. Самовоспламеняется на воздухе.
P красныйТвёрдое🔴 Красный порошок. Не ядовит. Используется в спичках.

✏️ Задания — блок 1
1
Чем отличаются алмаз и графит? Почему у них разные свойства?
Ответ
Оба — C, но разная структура. Алмаз: sp³, атомная решётка, изолятор, твёрдый. Графит: sp², слоистая решётка, проводник, мягкий.
Пример аллотропии: один элемент, разные свойства из-за разного строения кристалла.
2
Чем белый фосфор отличается от красного? Почему белый хранят под водой?
Ответ
Белый P₄ — молекулярная решётка, ядовит, самовоспламеняется на воздухе → хранят под водой. Красный P — атомная решётка, не ядовит, безопасен.
Белый фосфор воспламеняется при ~34°С — поэтому хранение под водой обязательно.
3
Почему Si — полупроводник? Чем его решётка похожа на алмаз?
Ответ
Si — атомная кристаллическая решётка типа алмаза (sp³). Полупроводник: проводимость зависит от t° (растёт с нагревом).
На этом свойстве основана вся микроэлектроника — транзисторы, процессоры, солнечные батареи.
🚫 Главные ловушки ЕГЭ — часть 2
  • H₂ + Si ↛ и H₂ + P ↛ — напрямую не реагируют! SiH₄ и PH₃ — только косвенный синтез.
  • C + I₂ ↛ — углерод с иодом не реагирует. Но Si + I₂ → SiI₄ — кремний реагирует со всеми галогенами!
  • Si + HNO₃ ↛ и Si + H₂SO₄(конц.) ↛ — Si пассивен к этим кислотам, растворяется только в HF.
  • C + O₂(нед.) → 2CO — угарный газ! Ядовит, бесцветный, без запаха.
  • CO₂ + NaOH: изб. NaOH → Na₂CO₃; нед. NaOH → NaHCO₃. Соотношение важно!
  • SiO₂ + HF → SiF₄ + H₂O — HF разъедает стекло (SiO₂). Другие кислоты с SiO₂ не реагируют!
✅ Цвета важных продуктов
  • ⬜ P₂O₅ — белый дым при горении фосфора
  • ⬛ CuO — чёрный → при восстановлении H₂ даёт 🔴 красную Cu
  • ⬜ CaCO₃↓ — белый (помутнение известковой воды = качественная реакция на CO₂)
  • ⬜ H₂SiO₃↓ — белый студенистый осадок (силикаты + кислоты)
  • ⬜ Al(OH)₃↓ — белый осадок (гидролиз AlP)
2

Химические свойства фосфора

2.1 С простыми веществами

Фосфор реагирует с большинством простых веществ. С кислородом — количество O₂ определяет продукт. С галогенами — количество галогена определяет степень окисления P (+3 или +5). С водородом — напрямую не реагирует!

4P + 5O₂(изб.) → 2P₂O₅  (⬜ белый дым P₂O₅, очень гигроскопичен) 4P + 3O₂(нед.) → 2P₂O₃ 2P + 5Cl₂(изб.) → 2PCl₅   2P + 3Cl₂(нед.) → 2PCl₃   2P + 3I₂ → 2PI₃  (I₂ → P только до +3) H₂ + P ↛  (напрямую не реагирует! PH₃ — только косвенный синтез) 3Ca + 2P →t° Ca₃P₂   Al + P →t° AlP   3Zn + 2P →t° Zn₃P₂  (фосфиды — ионные соединения)
✏️ Задания — 2.1 Фосфор + простые вещества
1
4P + O₂(изб.) → ? Что наблюдается?
Ответ
4P + 5O₂(изб.) → 2P₂O₅. ⬜ Белый дым P₂O₅.
P₂O₅ очень гигроскопичен — мгновенно реагирует с водой: P₂O₅ + 3H₂O → 2H₃PO₄.
2
P + Cl₂(изб.) → ? и P + Cl₂(нед.) → ? Сравни с.о. P.
Ответ
Изб.: 2P + 5Cl₂ → 2PCl₅ (P→+5). Нед.: 2P + 3Cl₂ → 2PCl₃ (P→+3).
Количество галогена определяет с.о. фосфора: изб. → +5, нед. → +3. Аналогично с I₂ → всегда PCl₃.
3
H₂ + P → ? Можно ли получить PH₃ прямым синтезом?
Ответ
H₂ + P ↛. PH₃ нельзя получить прямым синтезом из P и H₂.
PH₃ (фосфин) получают гидролизом фосфидов: Ca₃P₂ + 6H₂O → 3Ca(OH)₂ + 2PH₃↑.

2.2 С кислотами-окислителями и щёлочью

Фосфор — восстановитель в реакциях с кислотами-окислителями. Окисляется до H₃PO₄ (высшая кислота). При реакции с горячей концентрированной щёлочью — диспропорционирует с образованием ядовитого фосфина PH₃.

P + 5HNO₃(конц.) → H₃PO₄ + 5NO₂↑ + H₂O  (🟤 NO₂) 3P + 5HNO₃(разб.) + 2H₂O → 3H₃PO₄ + 5NO↑ 2P + 5H₂SO₄(конц.) → 2H₃PO₄ + 5SO₂↑ + 2H₂O 4P(бел.) + 3KOH(конц.) + 3H₂O →t° 3KH₂PO₂ + PH₃↑  (PH₃↑ — фосфин, ядовит! Самовоспламеняется)

2.3 Оксид фосфора P₂O₅ и кислоты фосфора

P₂O₅ + 3H₂O → 2H₃PO₄  (P₂O₅ — сильный водоотнимающий агент) H₃PO₄ + NaOH(1:1) → NaH₂PO₄ + H₂O  (кислая соль — дигидрофосфат) H₃PO₄ + 2NaOH(1:2) → Na₂HPO₄ + 2H₂O  (кислая соль — гидрофосфат) H₃PO₄ + 3NaOH(1:3) → Na₃PO₄ + 3H₂O  (средняя соль — фосфат)

2.4 Гидролиз фосфидов и получение фосфора

AlP + 3H₂O → Al(OH)₃↓ + PH₃↑  (⬜ Al(OH)₃ — белый осадок) Ca₃P₂ + 6H₂O → 3Ca(OH)₂ + 2PH₃↑  («болотные огни» — самовоспл. PH₃) Ca₃(PO₄)₂ + 3SiO₂ + 5C →t° 3CaSiO₃ + 2P↑ + 5CO↑  (промышленное получение P)
✏️ Задания — 2.2–2.4 Фосфор со сложными веществами
1
P + HNO₃(конц.) → ? До какой кислоты окисляется P?
Ответ
P + 5HNO₃(конц.) → H₃PO₄ + 5NO₂↑ + H₂O. P→H₃PO₄ (высшая кислота). 🟤 NO₂.
P окисляется до максимальной с.о. +5. Аналогично S → H₂SO₄, C → CO₂.
2
4P(бел.) + KOH(конц.) + H₂O →(t°) ?
Ответ
4P + 3KOH(конц.) + 3H₂O →(t°) 3KH₂PO₂ + PH₃↑.
PH₃ — фосфин, ядовитый газ, самовоспламеняется на воздухе. KH₂PO₂ — гипофосфит.
3
AlP + H₂O → ? Что выделяется?
Ответ
AlP + 3H₂O → Al(OH)₃↓ + PH₃↑. ⬜ Al(OH)₃ белый осадок + PH₃ ядовитый газ.
Гидролиз фосфидов — лабораторный способ получения PH₃.
4
H₃PO₄ + NaOH → ? Зависит от соотношения.
Ответ
1:1 → NaH₂PO₄; 1:2 → Na₂HPO₄; 1:3 → Na₃PO₄.
H₃PO₄ — трёхосновная кислота. Каждый H заменяется при добавлении очередного моля NaOH.
✅ Запомнить — фосфор
  • H₂ + P ↛ — фосфор с водородом напрямую не реагирует!
  • P + Cl₂(изб.) → PCl₅ (+5); P + Cl₂(нед.) → PCl₃ (+3); P + I₂ → PI₃ (+3 только).
  • 4P(бел.) + KOH(конц.) →(t°) KH₂PO₂ + PH₃↑ (ядовитый, самовоспламеняется!).
  • H₃PO₄ — трёхосновная: 1 моль NaOH → NaH₂PO₄; 2 → Na₂HPO₄; 3 → Na₃PO₄.
3

Химические свойства кремния

3.1 С простыми веществами

Кремний — сравнительно инертный неметалл. Реагирует с галогенами (со всеми, включая I₂ — в отличие от C и S!), кислородом, углеродом. С водородом напрямую не реагирует.

Si + O₂ →t° SiO₂  (кварц; SiO₂ — атомная кристаллическая решётка) Si + 2Cl₂ →t° SiCl₄   Si + 2Br₂ →t° SiBr₄   Si + 2I₂ →t° SiI₄  (Si реагирует со всеми Hal₂, включая I₂!) Si + C →t° SiC  (карборунд — атомная решётка, прочность близка к алмазу) Si + 2Mg →t° Mg₂Si  (силицид магния; гидролиз: Mg₂Si + 4H₂O → 2Mg(OH)₂ + SiH₄↑) H₂ + Si ↛  (напрямую не реагирует! SiH₄ — только косвенный синтез)
⚠ Si vs C: ключевое отличие с галогенами
  • Si + I₂ → SiI₄ — кремний реагирует с иодом!
  • C + I₂ ↛ — углерод с иодом не реагирует.
  • S + I₂ ↛ — сера с иодом не реагирует.
✏️ Задания — 3.1 Кремний + простые вещества
1
Si + I₂ → ? Почему Si реагирует, а C и S нет?
Ответ
Si + 2I₂ →(t°) SiI₄. С + I₂ ↛; S + I₂ ↛.
Si образует прочные связи Si–I. У C и S связи с I₂ слишком слабые для реакции — ловушка ЕГЭ!
2
Si + C → ? Какая кристаллическая решётка у продукта?
Ответ
Si + C →(t°) SiC (карборунд). Атомная кристаллическая решётка — как алмаз.
SiC — один из самых твёрдых материалов, абразив, используется в технике.
3
H₂ + Si → ? Можно ли получить SiH₄ прямым синтезом?
Ответ
H₂ + Si ↛. SiH₄ нельзя получить прямым синтезом.
SiH₄ (силан) получают: Mg₂Si + 4HCl → 2MgCl₂ + SiH₄↑ (гидролиз силицида).

3.2 Со сложными веществами

Si — особый неметалл: он не реагирует с большинством кислот, включая конц. HNO₃ и H₂SO₄(конц.). Растворяется только в HF и смеси HF + HNO₃. Зато реагирует со щелочами!

Si + 4HF(г) → SiF₄↑ + 2H₂↑  (единственная кислота-неокислитель, растворяющая Si) Si + HNO₃ ↛   Si + H₂SO₄(конц.) ↛  (Si пассивен к этим кислотам!) Si + 2NaOH(конц.) + H₂O →t° Na₂SiO₃ + 2H₂↑  (Si растворяется в щёлочи — редкое свойство!) Si + 2H₂O(пар) →t° SiO₂ + 2H₂↑ Si + 2F₂ →t° SiF₄  (реагирует со всеми галогенами)

3.3 Оксид кремния SiO₂ и силикаты

SiO₂ + 4HF → SiF₄↑ + 2H₂O  (HF разъедает стекло! Другие кислоты с SiO₂ не реагируют) SiO₂ + 2NaOH →t° Na₂SiO₃ + H₂O  (Na₂SiO₃ — жидкое стекло) SiO₂ + Na₂CO₃ →t° Na₂SiO₃ + CO₂  (варка стекла — сильная кислота вытесняет слабую) SiO₂ + HCl ↛   SiO₂ + H₂SO₄ ↛  (SiO₂ не реагирует с обычными кислотами!) Na₂SiO₃ + 2HCl → 2NaCl + H₂SiO₃↓  (⬜ белый студенистый осадок H₂SiO₃) Na₂SiO₃ + CO₂ + H₂O → Na₂CO₃ + H₂SiO₃↓  (H₂SiO₃ слабее угольной кислоты!) SiO₂ + 2C →t° Si + 2CO↑  (промышленное получение Si)
✏️ Задания — 3.2–3.3 Кремний со сложными веществами
1
Si + HNO₃(конц.) → ? Si + NaOH → ? Сравни.
Ответ
Si + HNO₃(конц.) ↛. Si + 2NaOH(конц.) + H₂O →(t°) Na₂SiO₃ + 2H₂↑.
Si пассивен к кислотам-окислителям, но реагирует со щелочами. Редкое сочетание для неметалла!
2
SiO₂ + HF → ? Почему HF разъедает стекло?
Ответ
SiO₂ + 4HF → SiF₄↑ + 2H₂O. HF образует прочную связь Si–F.
Именно поэтому HF нельзя хранить в стеклянных сосудах. Используют пластик или парафин.
3
Na₂SiO₃ + CO₂ + H₂O → ? Что это означает о силе H₂SiO₃?
Ответ
Na₂SiO₃ + CO₂ + H₂O → Na₂CO₃ + H₂SiO₃↓. H₂SiO₃ слабее H₂CO₃.
Слабые кислоты вытесняются из солей более сильными. CO₂ + H₂O = H₂CO₃ > H₂SiO₃.
4
SiO₂ + Na₂CO₃ →(t°) ? Почему реакция идёт при нагреве?
Ответ
SiO₂ + Na₂CO₃ →(t°) Na₂SiO₃ + CO₂↑.
При нагреве CO₂ улетает, смещая равновесие. Это основа производства стекла.
✅ Запомнить — кремний
  • H₂ + Si ↛ — не реагирует напрямую! Но Si + I₂ → SiI₄ (реагирует со всеми Hal₂).
  • Si пассивен к HNO₃ и H₂SO₄(конц.), но реагирует с HF и со щёлочью.
  • SiO₂ + HF → SiF₄ + H₂O — HF разъедает стекло. Другие кислоты с SiO₂ не реагируют!
  • ⬜ H₂SiO₃↓ — белый студенистый осадок при реакции силикатов с кислотами.
4

Химические свойства углерода

4.1 С простыми веществами

Углерод — амфотерный по окислительно-восстановительным свойствам: может быть и окислителем (с активными металлами), и восстановителем (с O₂, галогенами, кислотами). Важно: C + I₂ ↛!

C + O₂(изб.) → CO₂   2C + O₂(нед.) → 2CO  (CO — угарный газ, ядовит! при нед. O₂) C + 2H₂ ⇄t°, кат. CH₄   C + 2S →t° CS₂  (CS₂ — бесцветный растворитель) C + 2F₂ → CF₄   C + 2Cl₂ →t° CCl₄   C + I₂ ↛  (углерод с иодом не реагирует!) C + Si →t° SiC   2C + Ca →t° CaC₂  (карбид кальция; CaC₂ + 2H₂O → Ca(OH)₂ + C₂H₂↑) 4Al + 3C →t° Al₄C₃  (метанид; Al₄C₃ + 12H₂O → 4Al(OH)₃ + 3CH₄↑)
✏️ Задания — 4.1 Углерод + простые вещества
1
C + O₂(нед.) → ? Чем опасен продукт?
Ответ
2C + O₂(нед.) → 2CO. CO — угарный газ, бесцветный, без запаха, ядовит!
CO связывается с гемоглобином крови в 200 раз прочнее O₂ → лишает ткани кислорода.
2
C + Cl₂ → ? и C + I₂ → ? Сравни.
Ответ
C + 2Cl₂ →(t°) CCl₄. C + I₂ ↛ (не реагирует).
CCl₄ — тетрахлорид углерода, растворитель. C с иодом не реагирует — запомни.
3
CaC₂ + H₂O → ? Что за газ выделяется?
Ответ
CaC₂ + 2H₂O → Ca(OH)₂ + C₂H₂↑. C₂H₂ — ацетилен.
Карбид кальция + вода → ацетилен. На этом основано получение ацетилена в лаборатории.

4.2 Со сложными веществами

C + H₂O(пар) →t° CO + H₂  («водяной газ» — смесь CO + H₂, топливо) C + 4HNO₃(конц.) → CO₂↑ + 4NO₂↑ + 2H₂O  (C→CO₂, 🟤 NO₂) 3C + 4HNO₃(разб.) → 3CO₂↑ + 4NO↑ + 2H₂O C + 2H₂SO₄(конц.) → CO₂↑ + 2SO₂↑ + 2H₂O C + NaOH ↛  (углерод со щелочами не реагирует! В отличие от Si)

4.3 CO и CO₂ — важнейшие соединения углерода

CO — восстановитель, ядовит, горит синим пламенем. CO₂ — кислотный оксид, реагирует с основаниями. Продукт с NaOH зависит от соотношения реагентов!

2CO + O₂ → 2CO₂  (горение CO — синее пламя) FeO + CO →t° Fe + CO₂   CuO + CO →t° Cu + CO₂  (CO — восстановитель оксидов металлов) 3Fe₂O₃ + CO →t° 2Fe₃O₄ + CO₂   Fe₃O₄ + CO →t° 3FeO + CO₂   FeO + CO →t° Fe + CO₂ CO₂ + H₂O ⇄ H₂CO₃  (угольная кислота — слабая, двухосновная) CO₂ + 2NaOH(изб.) → Na₂CO₃ + H₂O  (изб. NaOH → карбонат Na₂CO₃) CO₂ + NaOH(нед.) → NaHCO₃  (нед. NaOH → гидрокарбонат NaHCO₃) CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O  (⬜ CaCO₃↓ — помутнение известковой воды; кач. реакция на CO₂) CaCO₃ →t° CaO + CO₂   Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
✏️ Задания — 4.2–4.3 Углерод со сложными веществами
1
CO₂ + NaOH(изб.) → ? и CO₂ + NaOH(нед.) → ? В чём разница?
Ответ
Изб. NaOH: CO₂ + 2NaOH → Na₂CO₃ + H₂O. Нед. NaOH: CO₂ + NaOH → NaHCO₃.
Соотношение n(NaOH)/n(CO₂): >2 → карбонат; 1–2 → смесь; <1 → гидрокарбонат.
2
CO₂ + Ca(OH)₂ → ? Что наблюдается?
Ответ
CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O. ⬜ Белый осадок — помутнение известковой воды.
Классическая качественная реакция на CO₂. При избытке CO₂ осадок растворяется: CaCO₃ + CO₂ + H₂O → Ca(HCO₃)₂.
3
C + H₂O(пар) →(t°) ? Что такое «водяной газ»?
Ответ
C + H₂O(пар) →(t°) CO + H₂↑. «Водяной газ» = CO + H₂.
CO + H₂ — горючая смесь. Исторически использовалась как топливо. Сейчас применяется в химическом синтезе.
4
C + NaOH → ? и Si + NaOH →(t°) ? Сравни.
Ответ
C + NaOH ↛. Si + 2NaOH + H₂O →(t°) Na₂SiO₃ + 2H₂↑.
Углерод со щелочами не реагирует! Это отличие от Si — важная ловушка.
✅ Запомнить — углерод
  • C + O₂(нед.) → 2CO (угарный газ, ядовит!); изб. O₂ → CO₂.
  • C + I₂ ↛. C + NaOH ↛ (в отличие от Si, который реагирует со щелочью).
  • CO₂ + NaOH: изб. → Na₂CO₃; нед. → NaHCO₃.
  • ⬜ CaCO₃↓ — качественная реакция на CO₂ (помутнение известковой воды).
  • CO — восстановитель: FeO + CO →(t°) Fe + CO₂.
5

Химические свойства водорода

5.1 С простыми веществами

Водород — и окислитель (с активными металлами → гидриды H⁻¹), и восстановитель (с неметаллами → соединения H⁺¹). С Si и P напрямую не реагирует!

H₂ + F₂ →hν 2HF   H₂ + Cl₂ → 2HCl   H₂ + Br₂ ⇄ 2HBr   H₂ + I₂ ⇄ 2HI − Q H₂ + S ⇄ H₂S   2H₂ + O₂ → 2H₂O   N₂ + 3H₂ ⇄Fe, t°, P 2NH₃ C + 2H₂ ⇄t° CH₄  (метанирование) H₂ + Si ↛   H₂ + P ↛  (Si и P с H₂ напрямую не реагируют!) 2Na + H₂ →t° 2NaH   Ca + H₂ →t° CaH₂  (гидриды: H в с.о. −1)
✏️ Задания — 5.1 Водород + простые вещества
1
H₂ + Si → ? и H₂ + P → ?
Ответ
H₂ + Si ↛ и H₂ + P ↛. Обе реакции не идут напрямую!
SiH₄ и PH₃ получают косвенными путями (гидролиз силицидов и фосфидов).
2
2Na + H₂ →(t°) ? Какая с.о. H в NaH?
Ответ
2Na + H₂ →(t°) 2NaH. H в с.о. −1 (как у галогенов!).
NaH — гидрид натрия. Реагирует с водой: NaH + H₂O → NaOH + H₂↑.
3
H₂ + O₂ → ? Почему смесь называется «гремучим газом»?
Ответ
2H₂ + O₂ → 2H₂O. «Гремучий газ» — взрывоопасная смесь H₂ + O₂.
Воспламеняется при малейшей искре. Используется в кислородно-водородных горелках.

5.2 С оксидами металлов (восстановитель)

CuO + H₂ →t° Cu + H₂O  (⬛ CuO чёрный → 🔴 Cu красная медь) Fe₂O₃ + 3H₂ →t° 2Fe + 3H₂O   WO₃ + 3H₂ →t° W + 3H₂O PbO + H₂ →t° Pb + H₂O   ZnO + H₂ →t° Zn + H₂O

5.3 Получение водорода

Промышленность
CH₄ + H₂O(пар) →(t°) CO + 3H₂
(конверсия метана — основной способ) C + H₂O(пар) →(t°) CO + H₂
(газификация угля)

✏️ Задания — 5.2–5.3 Водород: восстановитель и получение
1
CuO + H₂ →(t°) ? Что наблюдается?
Ответ
CuO + H₂ →(t°) Cu + H₂O. ⬛ Чёрный CuO → 🔴 красная медь Cu.
Одна из самых наглядных реакций восстановления. Используется для демонстрации свойств H₂ как восстановителя.
2
CH₄ + H₂O(пар) →(t°) ? Как называется процесс?
Ответ
CH₄ + H₂O(пар) →(t°) CO + 3H₂. Конверсия метана (паровой риформинг).
Основной промышленный метод производства H₂. CO + H₂ = синтез-газ, используется в синтезе аммиака и метанола.
3
Получить H₂ в лаборатории: какой металл и кислота?
Ответ
Zn + H₂SO₄(разб.) → ZnSO₄ + H₂↑. Цинк + разбавленная H₂SO₄.
Можно также: Fe + HCl → FeCl₂ + H₂↑. Главное — металл левее H₂ в ряду активности.
✅ Запомнить — водород
  • H₂ + Si ↛ и H₂ + P ↛ — не реагирует напрямую с Si и P!
  • ⬛ CuO + H₂ →(t°) 🔴 Cu + H₂O — яркая реакция восстановления.
  • Конверсия метана: CH₄ + H₂O →(t°) CO + 3H₂ — промышленное получение H₂.
  • Гидриды щелочных металлов (NaH, KH): H в с.о. −1, реагируют с водой → H₂↑.
