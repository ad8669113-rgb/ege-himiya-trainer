1

Определение и классификация оксидов

Оксиды — сложные вещества, состоящие из двух химических элементов, один из которых — кислород в степени окисления −2.

1.1 Общая классификация

ТипОпределениеПримеры
НесолеобразующиеНе реагируют ни с кислотами, ни со щелочамиCO, N₂O, NO, SiO
ОсновныеОксиды металлов со с.о. +1, +2 (кроме амфотерных)Na₂O, CaO, FeO, CuO
КислотныеВсе оксиды неметаллов (кроме несолеобразующих) + оксиды металлов с с.о. ≥+5SO₃, CO₂, P₂O₅, CrO₃, Mn₂O₇
АмфотерныеОксиды металлов со с.о. +3, +4, а также ZnO, BeO, SnO, PbOAl₂O₃, ZnO, Cr₂O₃, Fe₂O₃

1.2 Оксиды металлов по степени окисления

С.О. металлаОксид металлаОксид неметалла
+1, +2Me₂O и MeO → основные
BeO, ZnO, SnO, PbO → амфотерные		CO, N₂O, NO, SiO → несолеобразующие
+3, +4Me₂O₃, MeO₂ → амфотерныеВсе оксиды неметаллов, кроме несолеобразующих → кислотные
+5, +6, +7Me₂O₅, MeO₃, Me₂O₇ → кислотные
⚠️ Запомни амфотерные оксиды с с.о. +2
ZnO, BeO, SnO, PbO — исключения: несмотря на с.о. +2, они амфотерные, а не основные!
✏️ Задания на закрепление — блок 1
1
К какому типу относится оксид: ZnO?
Ответ
Амфотерный оксид.
ZnO — исключение: с.о. +2, но амфотерный (как BeO, SnO, PbO).
2
Назовите несолеобразующие оксиды. Чем SiO отличается от SiO₂?
Ответ
CO, N₂O, NO, SiO — несолеобразующие оксиды. SiO (с.о. Si = +2) — несолеобразующий, а SiO₂ (с.о. Si = +4) — кислотный оксид (кварц, кремнезём).
SiO практически не встречается в заданиях ЕГЭ, но по классификации — несолеобразующий.
3
К какому типу относятся оксиды: CrO₃, Mn₂O₇?
Ответ
Кислотные оксиды — оксиды металлов с с.о. выше +5 (Cr: +6, Mn: +7).
Правило: с.о. металла ≥ +5 → кислотный оксид.
4
Являются ли CO₂ и SiO₂ кислотными оксидами? Обоснуй.
Ответ
Да, оба кислотные — оксиды неметаллов (C и Si), не являются несолеобразующими.
Все оксиды неметаллов кислотные, кроме CO, N₂O, NO, SiO.
✅ Запомнить
  • Несолеобразующие: CO, N₂O, NO, SiO — не дают соли ни с кислотами, ни со щелочами.
  • ZnO, BeO, SnO, PbO — амфотерные, хотя металл в с.о. +2.
  • С.о. металла +5, +6, +7 → кислотный оксид (CrO₃, Mn₂O₇, V₂O₅).
  • Fe₂O₃, Cr₂O₃, Al₂O₃ — амфотерные (с.о. +3).

Какой оксид металла является жидкостью при н.у.?

Химические свойства кислотных оксидов

Кислотные оксиды реагируют с основаниями и основными оксидами с образованием солей. Им соответствуют кислородсодержащие кислоты.

3.1 С водой

Кислотный оксид + H₂O = кислота (кроме SiO₂ — не реагирует!) CO₂ + H₂O ⇄ H₂CO₃ (неустойчивая, разлагается) SO₂ + H₂O ⇄ H₂SO₃ (неустойчивая) SO₃ + H₂O → H₂SO₄ N₂O₃ + H₂O → 2HNO₂ N₂O₅ + H₂O → 2HNO₃ 2NO₂ + H₂O → HNO₂ + HNO₃ (диспропорционирование N) 3NO₂ + H₂O → t° NO + 2HNO₃ (при нагревании) P₂O₅ + 3H₂O → 2H₃PO₄ SiO₂ + H₂O ↛ (не реагирует — H₂SiO₃ нерастворима)

3.2 С основными и амфотерными оксидами

Кислотный оксид + основный оксид = соль CaO + CO₂ → CaCO₃ Na₂O + SiO₂ → Na₂SiO₃ CuO + SO₃ → CuSO₄ Na₂O + 2NO₂ → NaNO₂ + NaNO₃ (диспропорционирование) 3K₂O + P₂O₅ → 2K₃PO₄
Кислотный оксид + амфотерный оксид = соль ZnO + SO₃ → ZnSO₄ Al₂O₃ + 3N₂O₅ → 2Al(NO₃)₃ (только с сильными кислотами)
⚠️ Ограничение
Основные оксиды малоактивных металлов (CuO, FeO и др.) реагируют только с кислотными оксидами, соответствующими сильным кислотам. Амфотерные оксиды — аналогично.

3.3 Со щелочами и гидроксидами

Кислотный оксид + щёлочь = соль + H₂O 2NaOH + SiO₂ → Na₂SiO₃ + H₂O 2NaOH + CO₂ → Na₂CO₃ + H₂O NaOH + CO₂ (избыток) → NaHCO₃ (кислая соль!) 2NaOH + SO₃ → Na₂SO₄ + H₂O 2NaOH + 2NO₂ → NaNO₂ + NaNO₃ + H₂O 6KOH(изб.) + P₂O₅ → 2K₃PO₄ + 3H₂O
С нерастворимыми основаниями: только кислотные оксиды сильных кислот Cu(OH)₂ + SO₃ → CuSO₄ + H₂O
С амфотерными гидроксидами: только кислотные оксиды сильных кислот Zn(OH)₂ + N₂O₅ → Zn(NO₃)₂ + H₂O

3.4 С солями (при сплавлении)

Менее летучий оксид вытесняет более летучий из соли: SiO₂ + CaCO₃ →t° CaSiO₃ + CO₂↑ SiO₂ + Na₂SO₃ →t° Na₂SiO₃ + SO₂↑
В водном растворе (более сильная кислота вытесняет слабую): Na₂SiO₃(р-р) + CO₂ + H₂O → Na₂CO₃ + H₂SiO₃↓ Na₂S(р-р) + CO₂ + H₂O → Na₂CO₃ + H₂S↑

3.5 Особое свойство SiO₂

🔬 SiO₂ реагирует с HF (плавиковой кислотой)
SiO₂ + 4HF(газ) → SiF₄ + 2H₂O
Используется для травления стекла. Опыты с HF — только в пластиковой посуде!
✏️ Задания на закрепление — блок 3
1
Почему SiO₂ не реагирует с водой?
Ответ
Потому что SiO₂ соответствует нерастворимая кремниевая кислота H₂SiO₃. Кислотные оксиды реагируют с водой только если образующаяся кислота растворима.
H₂SiO₃ выпадает в осадок → реакция невозможна.
2
Что образуется при растворении NO₂ в воде? Запиши уравнение.
Ответ
2NO₂ + H₂O → HNO₂ + HNO₃ (при н.у.)
3NO₂ + H₂O → NO + 2HNO₃ (при нагревании)
Диспропорционирование азота — ловушка ЕГЭ.
3
Завершите реакцию: SO₂ + NaOH (избыток CO₂) →
Ответ
SO₂ + NaOH (SO₂ в избытке) → NaHSO₃ (кислая соль — гидросульфит натрия)
При избытке кислотного оксида (многоосновной кислоты) → кислая соль.
4
Можно ли провести реакцию: FeO + CO₂? Обоснуй.
Ответ
Нет. FeO — основный оксид малоактивного металла. Он реагирует только с кислотными оксидами, соответствующими сильным кислотам (H₂SO₄, HNO₃). CO₂ — слабая кислота.
Угольная кислота слабее, чем нужно для реакции с FeO.
5
Запишите реакцию: Na₂SiO₃(р-р) + CO₂ + H₂O →
Ответ
Na₂SiO₃(р-р) + CO₂ + H₂O → Na₂CO₃ + H₂SiO₃↓
Более сильная H₂CO₃ вытесняет более слабую H₂SiO₃ из раствора. Реакция только в водном растворе!
✅ Запомнить
  • SiO₂ + H₂O ↛ (не реагирует!) | SiO₂ + 4HF → SiF₄ + 2H₂O (травление стекла)
  • 2NO₂ + H₂O → HNO₂ + HNO₃ | при нагр.: 3NO₂ + H₂O → NO + 2HNO₃
  • Избыток кислотного оксида + щёлочь → кислая соль (NaHSO₃, NaHCO₃)
  • Нелетучий оксид вытесняет летучий при сплавлении (SiO₂ > CO₂ > SO₂)
4

Химические свойства основных оксидов

Основные оксиды реагируют с кислотами и кислотными оксидами. Им соответствуют основания (гидроксиды).

4.1 С водой

Оксиды ЩМ и ЩЗМ + H₂O = щёлочь Na₂O + H₂O → 2NaOH K₂O + H₂O → 2KOH CaO + H₂O → Ca(OH)₂ (гашение извести) BaO + H₂O → Ba(OH)₂
Оксиды металлов средней активности с водой НЕ реагируют: CuO, FeO, Fe₂O₃ + H₂O ↛

4.2 С кислотными и амфотерными оксидами

Основный оксид + кислотный оксид = соль CaO + CrO₃ → CaCrO₄ K₂O + SO₂ → K₂SO₃ Na₂O + 2NO₂ → NaNO₂ + NaNO₃
Основный оксид ЩМ/ЩЗМ/Mg + амфотерный оксид →t° соль Na₂O + ZnO →t° Na₂ZnO₂ (цинкат натрия) Na₂O + Al₂O₃ →t° 2NaAlO₂ (метаалюминат натрия) CaO + Al₂O₃ →t° Ca(AlO₂)₂

4.3 С кислотами

Основный оксид + кислота = соль + H₂O Na₂O + 2HCl → 2NaCl + H₂O CaO + H₂SO₄ → CaSO₄ + H₂O CuO + 2HCl → CuCl₂ + H₂O Fe₃O₄ + 8HBr → FeBr₂ + 2FeBr₃ + 4H₂O (железная окалина = FeO·Fe₂O₃)
С кислотами-окислителями (ОВР): FeO + 4HNO₃(конц.) → Fe(NO₃)₃ + NO₂ + 2H₂O (Fe²⁺ → Fe³⁺) Cu₂O + 3H₂SO₄(конц.) → 2CuSO₄ + SO₂ + 3H₂O (Cu⁺ → Cu²⁺)

4.4 С амфотерными гидроксидами (сплавление)

K₂O + Zn(OH)₂ →t° K₂ZnO₂ + H₂O K₂O + 2Al(OH)₃ →t° 2KAlO₂ + 3H₂O BaO + 2Al(OH)₃ →t° Ba(AlO₂)₂ + 3H₂O
⚠️ Основные оксиды с солями НЕ реагируют
В отличие от кислотных оксидов, основные оксиды солей не вытесняют (нет реакции ионного обмена с солями в растворе).

4.5 Термическое разложение оксидов металлов после Cu

2HgO →t° 2Hg + O₂ 2Ag₂O →t° 4Ag + O₂
✏️ Задания на закрепление — блок 4
1
Что образуется при реакции: Na₂O + Al₂O₃ →(t°)?
Ответ
Na₂O + Al₂O₃ → 2NaAlO₂ (метаалюминат натрия).
Кислотный остаток AlO₂⁻ — метаалюминат. Реакция при сплавлении.
2
Составьте уравнение ОВР: FeO + HNO₃(конц.) →
Ответ
FeO + 4HNO₃(конц.) → Fe(NO₃)₃ + NO₂↑ + 2H₂O
Fe²⁺ — восстановитель, окисляется до Fe³⁺. Азот восстанавливается до +4 (NO₂) при конц. HNO₃.
3
Что получится при реакции Fe₃O₄ с соляной кислотой?
Ответ
Fe₃O₄ + 8HCl → FeCl₂ + 2FeCl₃ + 4H₂O (смесь солей Fe²⁺ и Fe³⁺).
Железная окалина = FeO·Fe₂O₃, поэтому продукты — смесь двух хлоридов.
4
Реагирует ли CuO с водой? Объясни.
Ответ
Нет. С водой реагируют только оксиды щелочных и щелочноземельных металлов (ЩМ и ЩЗМ). CuO — оксид металла средней активности.
Cu(OH)₂ нерастворима → CuO + H₂O ↛.
✅ Запомнить
  • С водой реагируют только ЩМ и ЩЗМ оксиды: Na₂O, K₂O, CaO, BaO, SrO.
  • Fe₃O₄ + кислота (не-окислитель) → FeCl₂ + 2FeCl₃ (смесь!)
  • FeO + конц. HNO₃ → Fe(NO₃)₃ + NO₂ (ОВР, Fe²⁺ → Fe³⁺)
  • Оксиды после Cu (HgO, Ag₂O) разлагаются при нагревании → металл + O₂
  • Формулы цинкатов и алюминатов: Na₂ZnO₂, NaAlO₂, Ca(AlO₂)₂

Химические свойства амфотерных оксидов

Амфотерные оксиды проявляют как кислотные, так и основные свойства в зависимости от партнёра по реакции.

5.1 Комплексные анионы при взаимодействии со щёлочью

Амфотерный оксидГидроксидКомплексный анион (р-р)Название
BeOBe(OH)₂[Be(OH)₄]²⁻Тетрагидроксобериллат
ZnOZn(OH)₂[Zn(OH)₄]²⁻Тетрагидроксоцинкат
Al₂O₃Al(OH)₃[Al(OH)₄]⁻ / [Al(OH)₆]³⁻Тетра- / Гексагидроксоалюминат
Cr₂O₃Cr(OH)₃[Cr(OH)₄]⁻ / [Cr(OH)₆]³⁻Тетра- / Гексагидроксохромат(III)
❗ Fe₂O₃ и Fe(OH)₃ — исключение!
Fe₂O₃ и Fe(OH)₃ не реагируют с водными растворами щелочей. Реакция возможна только с расплавом щёлочи: Fe₂O₃ + 2NaOH →(t°) 2NaFeO₂ + H₂O

5.2 С кислотами (проявляет основные свойства)

Амфотерный оксид + кислота = соль + H₂O ZnO + 2HNO₃ → Zn(NO₃)₂ + H₂O Al₂O₃ + 3H₂SO₄ → Al₂(SO₄)₃ + 3H₂O Fe₂O₃ + 6HBr → 2FeBr₃ + 3H₂O

5.3 С кислотными оксидами

Амфотерный оксид + кислотный оксид = соль (только сильные кислоты) ZnO + Cl₂O₅ → Zn(ClO₃)₂ Al₂O₃ + 3Cl₂O₇ → 2Al(ClO₄)₃

5.4 С основными оксидами (сплавление)

Амфотерный оксид + основный оксид ЩМ/ЩЗМ →t° соль K₂O + ZnO →t° K₂ZnO₂ Li₂O + Al₂O₃ →t° 2LiAlO₂ Na₂O + Fe₂O₃ →t° 2NaFeO₂ CaO + Cr₂O₃ →t° Ca(CrO₂)₂

5.5 Со щелочами (раствор vs расплав)

С раствором щёлочи → гидроксокомплекс ZnO + 2NaOH(р-р) + H₂O → Na₂[Zn(OH)₄] Al₂O₃ + 2KOH(р-р) + 3H₂O → 2K[Al(OH)₄]
С твёрдой щёлочью (сплавление) → средняя соль + H₂O ZnO + 2NaOH →t° Na₂ZnO₂ + H₂O Al₂O₃ + 2KOH →t° 2KAlO₂ + H₂O Fe₂O₃ + 2NaOH →t° 2NaFeO₂ + H₂O (только расплав!) Cr₂O₃ + 2NaOH →t° 2NaCrO₂ + H₂O

5.6 Амфотерные оксиды с карбонатами

Амфотерный оксид + карбонат/сульфит →t° новая соль + CO₂/SO₂ ZnO + Na₂CO₃ →t° Na₂ZnO₂ + CO₂↑ Al₂O₃ + CaSO₃ →t° Ca(AlO₂)₂ + SO₂↑
✏️ Задания на закрепление — блок 5
1
Запишите реакцию ZnO с раствором NaOH и с твёрдым NaOH. В чём разница продуктов?
Ответ
С р-ром: ZnO + 2NaOH(р-р) + H₂O → Na₂[Zn(OH)₄] (гидроксокомплекс)
С тв. щёлочью: ZnO + 2NaOH →(t°) Na₂ZnO₂ + H₂O (средняя соль — цинкат)
Ключевая разница: р-р → комплексная соль, расплав → средняя соль.
2
Реагирует ли Fe₂O₃ с раствором NaOH? Объясни.
Ответ
Нет. Fe₂O₃ не реагирует с водными растворами щелочей. Реакция возможна только с расплавом NaOH: Fe₂O₃ + 2NaOH →(t°) 2NaFeO₂ + H₂O.
Это важная ловушка! Fe₂O₃ и Fe(OH)₃ — исключения из амфотерных.
3
Запишите реакцию: Al₂O₃ + KOH (раствор) →
Ответ
Al₂O₃ + 2KOH(р-р) + 3H₂O → 2K[Al(OH)₄] (тетрагидроксоалюминат калия)
С раствором щёлочи → гидроксокомплекс!
4
Назовите соль Na₂ZnO₂.
Ответ
Цинкат натрия (тетраоксоцинкат(II) натрия). Кислотный остаток ZnO₂²⁻ — цинкат.
Аналогично: NaAlO₂ — метаалюминат натрия, NaFeO₂ — метаферрит натрия.
✅ Запомнить
  • Раствор щёлочи + ZnO/Al₂O₃ → гидроксокомплекс [Zn(OH)₄]²⁻, [Al(OH)₄]⁻
  • Расплав щёлочи + ZnO/Al₂O₃ → средняя соль Na₂ZnO₂, NaAlO₂
  • Fe₂O₃ не реагирует с р-ром NaOH! Только с расплавом.
  • При взаимодействии с кислотой — амфотерный оксид ведёт себя как основный.
  • При взаимодействии со щёлочью/основным оксидом — как кислотный.
6

Свойства несолеобразующих оксидов

CO, N₂O, NO, SiO — не образуют солей при обычных условиях, не реагируют ни с кислотами, ни со щелочами.

6.1 СО — угарный газ

CO — типичный восстановитель CuO + CO →t° Cu + CO₂ (восстановление оксидов металлов) FeO + CO →t° Fe + CO₂ Fe₂O₃ + 3CO →t° 2Fe + 3CO₂ 2CO + O₂ → 2CO₂ (горение) CO + 2H₂ →кат., t°, p CH₃OH (метанол) CO + NaOH(расплав) →t°, p HCOONa (формиат натрия) CO + Cl₂ →кат. COCl₂ (фосген — ядовитый газ!)

6.2 NO и N₂O

2NO + O₂ → 2NO₂ (NO моментально окисляется на воздухе) N₂O — окислитель, поддерживает горение: N₂O + O₂ ↛ (N₂O не реагирует с кислородом)
✏️ Задания на закрепление — блок 6
1
Почему CO называют несолеобразующим оксидом? Реагирует ли он вообще с чем-либо?
Ответ
CO не образует солей при взаимодействии с кислотами или щелочами при обычных условиях. Но CO — активный восстановитель: реагирует с O₂, оксидами металлов, щелочью (при высоком давлении), Cl₂.
Несолеобразующий ≠ химически инертный!
2
Что образуется при пропускании смеси CO и Cl₂ через активированный уголь?
Ответ
CO + Cl₂ →(кат.) COCl₂ — фосген (ядовитый газ, вызывает паралич дыхательных путей).
Историческое боевое отравляющее вещество.
7

Реакции с простыми веществами. Способы получения

7.1 Реакции оксидов с кислородом

Оксиды элементов в промежуточной с.о. + O₂ → высшие оксиды 4FeO + O₂ → 2Fe₂O₃ 2Cu₂O + O₂ → 4CuO 2SO₂ + O₂ →кат., t° 2SO₃ (ключевая реакция производства H₂SO₄) 4CrO + O₂ → 2Cr₂O₃ P₂O₃ + O₂ → P₂O₅ 2NO + O₂ → 2NO₂

7.2 Реакции оксидов с углеродом и водородом

Оксиды металлов средней активности и неактивных + C(кокс)/H₂ →t° ZnO + C →t° Zn + CO Fe₂O₃ + 3CO →t° 2Fe + 3CO₂ (доменный процесс) PbO + H₂ →t° Pb + H₂O SiO₂ + 2C →t° Si + 2CO CO₂ + C →t° 2CO (сопропорционирование)

7.3 Реакции оксидов с металлами

CO₂ + Mg → MgO + CO 2Mg(нед.) + SiO₂ →t° 2MgO + Si 4Mg(изб.) + SiO₂ →t° 2MgO + Mg₂Si 4Cu + 2NO₂ →t° 4CuO + N₂ 4Zn + 2NO₂ →t° 4ZnO + N₂

7.4 Общие способы получения оксидов

1
Взаимодействие простых веществ с кислородом: 4P + 5O₂ → 2P₂O₅; 2Cu + O₂ → 2CuO
2
Горение сложных веществ (водородные соединения, сульфиды): CH₄ + 2O₂ → CO₂ + 2H₂O; 2ZnS + 3O₂ → 2ZnO + 2SO₂
3
Разложение нерастворимых гидроксидов и солей: 2Al(OH)₃ →(t°) Al₂O₃ + 3H₂O; MgCO₃ →(t°) MgO + CO₂; 2Cu(NO₃)₂ →(t°) 2CuO + 4NO₂ + O₂
4
Взаимодействие солей с сильными кислотами: Na₂SO₃ + 2HCl → 2NaCl + SO₂ + H₂O
5
Вытеснение летучих оксидов нелетучими при сплавлении: Na₂CO₃ + SiO₂ →(t°) Na₂SiO₃ + CO₂
6
Восстановление высших оксидов до низших: CO₂ + C →(t°) 2CO; Fe₂O₃ + CO →(t°) 2FeO + CO₂
7
Окисление кислотами-окислителями: Cu + 4HNO₃(конц.) → Cu(NO₃)₂ + 2NO₂↑ + 2H₂O
✏️ Задания на закрепление — блок 7
1
Какой продукт образуется при разложении Cu(NO₃)₂ при нагревании?
Ответ
2Cu(NO₃)₂ →(t°) 2CuO + 4NO₂↑ + O₂
Разложение нитратов металлов средней активности → оксид + NO₂ + O₂.
2
Запишите реакцию восстановления Fe₂O₃ коксом в доменной печи.
Ответ
Fe₂O₃ + 3CO →(t°) 2Fe + 3CO₂ (CO получается из кокса: C + CO₂ → 2CO)
В доменной печи реальный восстановитель — CO, образующийся из кокса.
3
Какой газ образуется при сжигании H₂S в избытке кислорода?
Ответ
2H₂S + 3O₂(изб.) → 2SO₂ + 2H₂O
При недостатке кислорода: 2H₂S + O₂ → 2S + 2H₂O (выпадает жёлтая сера).
