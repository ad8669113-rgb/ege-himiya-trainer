Валентность элементов
Определение
Валентность — число химических связей, которые атом образует с другими атомами. Обозначается римскими цифрами: I, II, III, IV…

Как определить валентность

ПравилоКак работаетПримеры
По номеру группыВысшая валентность s- и p-элементов = номер группыN — V гр. → макс. IV (не V!), P — V гр. → V, S — VI гр. → VI
В оксидахВалентность = номер группыSO₃ → S(VI), P₂O₅ → P(V), CO₂ → C(IV)
В ЛВСВалентность неметалла = 8 − номер группыN: 8−5=III → NH₃; S: 8−6=II → H₂S; Cl: 8−7=I → HCl

Постоянная валентность

Всегда одно значение:
F — I   O — II   H — I
Na, K, Li, Rb, Cs — I
Mg, Ca, Sr, Ba, Be, Zn — II
Al — III
Переменная валентность:
N — III, IV
S — II, IV, VI
P — III, V
Cl — I, III, V, VII
Fe — II, III   Cu — I, II
⚠️ Исключения: O и F не проявляют валентность, равную номеру группы. O — VI группа, но валентность всегда II. F — VII группа, но валентность всегда I. N — V группа, но максимальная валентность IV (нет свободных d-орбиталей).
💡 Валентность в ЛВС = 8 − номер группы (для неметаллов): Cl(VII) → I, O(VI) → II, N(V) → III, C(IV) → IV, As/P(V) → III. Металлы (Na, Ca, Al…) летучих водородных соединений не образуют.

СО
Степень окисления
Определение
Степень окисления (СО) — условный заряд атома в соединении, рассчитанный из предположения, что все связи ионные. Сумма СО всех атомов в молекуле = 0, в ионе = заряду иона.

Алгоритм определения СО

ПравилоЗначениеПримеры
Простое вещество0O₂, Fe, Na, Cl₂ → СО = 0
F (всегда)–1HF, OF₂ → F всегда –1
O (обычно)–2H₂O, CO₂ → O = –2. Исключения: F₂O(+2), пероксиды H₂O₂(–1), O₂F₂(+1)
H с неметаллами+1HCl, NH₃, H₂SO₄ → H = +1
H с металлами (гидриды)–1NaH, CaH₂, KH → H = –1
Щелочные металлы+1Na, K, Li, Rb, Cs → всегда +1
Щелочноземельные + Be, Zn+2Ca, Mg, Sr, Ba, Be, Zn → всегда +2
Al+3Al₂O₃, AlCl₃ → Al всегда +3

Высшая и низшая СО

Высшая СО
= номер группы (кроме O и F)
N(V) → +5 S(VI) → +6
Cl(VII) → +7 P(V) → +5
⚠ O: макс. +2; F: макс. 0
Низшая СО (неметаллы)
= номер группы − 8
N(V–8) → –3 S(VI–8) → –2
Cl(VII–8) → –1 C(IV–8) → –4
Металлы: низшая СО = 0 (простое вещество)
💡 Переменная СО — как запомнить
Неметаллы: чётная группа → чётные СО, нечётная → нечётные
IV группа (чётные)
C: −4, +2, +4
Si: −4, +4
VI группа (чётные)
S: −2, +4, +6
Se: −2, +4, +6
O: −2, +2
VII группа (нечётные)
Cl: −1, +1, +3, +5, +7
Br: −1, +1, +3, +5, +7
I: −1, +1, +3, +5, +7
V группа (нечётные)
P, As: −3, +3, +5
N — исключение!
У азота все СО от −3 до +5:
−3, −2, −1, 0, +1, +2, +3, +4, +5
В т.ч. чётные +2 (NO) и +4 (NO₂)
Металлы: запоминай по лайфхаку

Формулы оксидов
Главное правило
Формула оксида определяется степенью окисления элемента. Сумма всех СО в молекуле = 0. Кислород всегда −2, поэтому если элемент имеет СО = +n, формула оксида определяется из баланса: n + (−2)·кол-во O = 0.

Формулы оксидов через СО

ФормулаСО элементаБалансПримеры
R₂O+12·(+1) + 1·(−2) = 0Na₂O, K₂O, Cu₂O, H₂O, N₂O
RO+21·(+2) + 1·(−2) = 0CaO, MgO, BeO, CuO, CO, SnO
R₂O₃+32·(+3) + 3·(−2) = 0Al₂O₃, Fe₂O₃, B₂O₃, N₂O₃
RO₂+41·(+4) + 2·(−2) = 0SiO₂, MnO₂, PbO₂, CO₂, TiO₂
R₂O₅+52·(+5) + 5·(−2) = 0N₂O₅, P₂O₅, As₂O₅, Cl₂O₅
RO₃+61·(+6) + 3·(−2) = 0SO₃, CrO₃, MnO₃
R₂O₇+72·(+7) + 7·(−2) = 0Cl₂O₇, Mn₂O₇
⚠️ Не образуют оксидов: F (слишком электроотрицательный — «забирает» кислород у других), благородные газы (He, Ne, Ar, Kr, Xe), а также Au, Pt в обычных условиях.
💡 Элементы с переменной СО образуют несколько оксидов:
Fe: FeO(+2), Fe₂O₃(+3), Fe₃O₄(смешанный), FeO₃(+6)  |  Cr: CrO(+2), Cr₂O₃(+3), CrO₃(+6)
Mn: MnO(+2), MnO₂(+4), MnO₃(+6), Mn₂O₇(+7)  |  Cu: Cu₂O(+1), CuO(+2)
N: N₂O(+1), NO(+2), N₂O₃(+3), NO₂(+4), N₂O₅(+5)

Два типа водородных соединений
ЛВС (летучие водородные соединения) — неметаллы + водород. H = +1, неметалл — отрицательная степень окисления.
Гидриды металлов — металлы I и II групп + водород. H = −1.

Разность степеней окисления

Разность = высшая СО − низшая СО. Для металлов низшая = 0, для неметаллов низшая = № группы − 8.

Формула расчёта
Разность = Высшая СО − Низшая СО
Металлы:
высшая = № группы
низшая = 0 (простое вещество)
разность = № группы
Неметаллы:
высшая = № группы
низшая = № группы − 8
разность = 8 (обычно)
Группа Элементы Высшая − Низшая = Разность
I металл Na, Li, K, Rb, Cs +1 − 0 = 1
I H ⚠ Водород (исключение) +1 − −1 = 2
II Be, Mg, Ca, Ba, Zn +2 − 0 = 2
III Al, Sc, La +3 − 0 = 3
IV металл Ti, Zr +4 − 0 = 4
IV неметалл C, Si +4 − −4 = 8
V металл V, Nb +5 − 0 = 5
V неметалл N, P +5 − −3 = 8
VI металл Cr, Mo, Fe (+6) +6 − 0 = 6
VI неметалл S, Se +6 − −2 = 8
VI O ⚠ Кислород (высшая ≠ +6) +2 − −2 = 4
VII металл Mn +7 − 0 = 7
VII неметалл Cl, Br, I +7 − −1 = 8
VII F ⚠ Фтор (высшая ≠ +7) 0 − −1 = 1
⚠ Исключения из общего правила
O и F — особые исключения: высшая СО ≠ номер группы
Для большинства элементов высшая СО = номер группы. У O и F это правило не работает.

F (фтор) — группа VII:
 • По правилу высшая должна быть +7, НО F — самый электроотрицательный элемент, не отдаёт электроны никому
 • Высшая СО: 0 (только в F₂ — простом веществе)
 • Низшая СО: −1 (в HF, NaF, CaF₂)
 • Разность: 0 − (−1) = 1

O (кислород) — группа VI:
 • По правилу высшая должна быть +6, НО O уступает по ЭО только фтору
 • Высшая СО: +2 (только в OF₂ — фторид кислорода)
 • Низшая СО: −2 (в большинстве соединений: H₂O, CO₂)
 • Разность: +2 − (−2) = 4
⚠ Особые случаи
  • He, Ne, Ar — разность = 0 (всегда 0)
  • Cu — +1 и +2, но не отрицательных → разность = 2
  • Fe — +2, +3, +6 → разность = 6 (от 0 до +6)
  • Si — от −4 до +4 → разность = 8
  • F — низшая −1, высшая 0 (фтор не бывает положительным!)
