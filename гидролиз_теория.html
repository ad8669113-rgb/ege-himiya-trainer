Необратимый гидролиз — основные понятия

Что такое необратимый гидролиз?

Необратимый гидролиз — обменная реакция взаимодействия веществ с водой, приводящая к их полному разложению.

💧 Какие вещества гидролизуются необратимо?
Карбиды, гидриды, нитриды, фосфиды, силициды и ковалентные галогениды полностью разрушаются при взаимодействии с водой — реакция необратимая.

Гидролиз гидридов и пероксидов

1. Гидролиз гидридов (H⁻)

Гидриды активных металлов гидролизуются с образованием гидроксида металла и водорода H₂.

💧 Вода
KH + HOH → KOH + H₂↑
CaH₂ + 2H₂O → Ca(OH)₂ + 2H₂↑
🧪 Кислая среда
NaH + HCl → NaCl + H₂↑
CaH₂ + 2HCl → CaCl₂ + 2H₂↑
Щелочная среда
Реакция не характерна

2. Гидролиз пероксидов (O₂²⁻)

💧 Без нагрева
Na₂O₂ + H₂O → 2NaOH + H₂O₂
BaO₂ + 2H₂O → Ba(OH)₂ + H₂O₂
🔥 При нагреве
2Na₂O₂ + 2H₂O →(t) 4NaOH + O₂↑
(H₂O₂ разлагается при нагреве)
🧪 Кислая среда
Na₂O₂ + 2HCl → 2NaCl + H₂O₂
2Na₂O₂ + 4HCl →(t) 4NaCl + O₂↑ + 2H₂O
⚠️ Важно про пероксиды
При нагреве H₂O₂ разлагается: 2H₂O₂ →(t) O₂↑ + 2H₂O.
Поэтому при горячем гидролизе пероксидов конечный продукт — щёлочь и O₂ (а не H₂O₂).

Гидролиз нитридов и фосфидов

3. Гидролиз нитридов (N³⁻)

В результате образуются гидроксид металла и аммиак NH₃.

💧 Вода
Na₃N + 3HOH → 3NaOH + NH₃↑
Ca₃N₂ + 6H₂O → 3Ca(OH)₂ + 2NH₃↑
Mg₃N₂ + 6H₂O → 3Mg(OH)₂↓ + 2NH₃↑
🧪 Кислая среда
Na₃N + 4HNO₃ → 3NaNO₃ + NH₄NO₃
Ca₃N₂ + 8HCl → 3CaCl₂ + 2NH₄Cl
AlN + 4HNO₃ → Al(NO₃)₃ + NH₄NO₃
(NH₃ реагирует с кислотой → соль аммония)
⚗️ Щелочная среда (амф. металл)
AlN + NaOH + 3H₂O → Na[Al(OH)₄] + NH₃↑
(Al(OH)₃ растворяется в изб. NaOH)
💡 Ключевое отличие кислой и щелочной среды для нитридов
  • Кислая среда: NH₃ + кислота → соль аммония (NH₄⁺)
  • Щелочная среда (амф. металл): Al(OH)₃ + изб. NaOH → Na[Al(OH)₄] — гидроксокомплекс

4. Гидролиз фосфидов (P³⁻)

В результате образуются гидроксид металла и фосфин PH₃.

💧 Вода
Li₃P + 3H₂O → 3LiOH + PH₃↑
Zn₃P₂ + 6H₂O → 3Zn(OH)₂ + 2PH₃↑
AlP + 3H₂O → Al(OH)₃ + PH₃↑
🧪 Кислая среда
2Li₃P + 3H₂SO₄ → 3Li₂SO₄ + 2PH₃↑
Zn₃P₂ + 3H₂SO₄ → 3ZnSO₄ + 2PH₃↑
2AlP + 3H₂SO₄ → Al₂(SO₄)₃ + 2PH₃↑
⚗️ Щелочная среда (амф. металл)
Zn₃P₂ + 6NaOH + 6H₂O → 3Na₂[Zn(OH)₄] + 2PH₃↑
AlP + NaOH + 3H₂O → Na[Al(OH)₄] + PH₃↑
⚠️ Фосфин не реагирует с кислотой!
  • Аммиак NH₃ — основание, реагирует с кислотами → NH₄⁺
  • Фосфин PH₃ — очень слабое основание, не образует солей с кислотами в обычных условиях
  • Поэтому при гидролизе фосфидов в кислой среде фосфин улетает, а не нейтрализуется

Гидролиз карбидов и силицидов

5. Гидролиз карбидов (ацетиленидов C₂²⁻ и метанидов C⁴⁻)

Карбиды делятся на два типа по продукту гидролиза:

Ацетилениды (C₂²⁻) → ацетилен C₂H₂↑ K₂C₂ + 2H₂O → 2KOH + C₂H₂↑ Na₂C₂ + 2H₂O → 2NaOH + C₂H₂↑ CaC₂ + 2H₂O → Ca(OH)₂ + C₂H₂↑
Метаниды (C⁴⁻) → метан CH₄↑ Al₄C₃ + 12H₂O → 4Al(OH)₃↓ + 3CH₄↑ Be₂C + 4H₂O → 2Be(OH)₂↓ + CH₄↑
🧪 Кислая среда
Na₂C₂ + 2HBr → 2NaBr + C₂H₂↑
CaC₂ + 2HBr → CaBr₂ + C₂H₂↑
Al₄C₃ + 12HBr → 4AlBr₃ + 3CH₄↑
⚗️ Щелочная среда (амф. металл)
Al₄C₃ + 4KOH + 12H₂O → 4K[Al(OH)₄] + 3CH₄↑
Be₂C + 4KOH → 2K₂[Be(OH)₄] + CH₄↑

Гидролиз сульфидов Al и Cr. Галогениды неметаллов

7. Гидролиз сульфидов алюминия и хрома (III)

Сульфиды Al₂S₃ и Cr₂S₃ — особые случаи: оба продукта (амфотерный гидроксид и H₂S) слабые, поэтому реакция идёт до конца.

💧 Вода
Al₂S₃ + 6H₂O → 2Al(OH)₃↓ + 3H₂S↑
Cr₂S₃ + 6H₂O → 2Cr(OH)₃↓ + 3H₂S↑
🧪 Кислая среда
Al₂S₃ + 6HCl → 2AlCl₃ + 3H₂S↑
Cr₂S₃ + 6HCl → 2CrCl₃ + 3H₂S↑
⚗️ Щелочная среда
Al₂S₃ + 8KOH → 2K[Al(OH)₄] + 3K₂S
Cr₂S₃ + 12KOH → 2K₃[Cr(OH)₆] + 3K₂S

Гидролиз галогенидов неметаллов (ковалентных)

В результате образуются кислородсодержащая кислота и галогеноводород.

В водной среде PCl₅ + 4H₂O → H₃PO₄ + 5HCl PCl₃ + 3H₂O → H₃PO₃ + 3HCl SiCl₄ + 3H₂O → H₂SiO₃ + 4HCl COCl₂ + H₂O → CO₂ + 2HCl (фосген)

В щелочной среде (продукты нейтрализации кислот)

PCl₅ + KOH — в зависимости от количества щёлочи PCl₅ + 8KOH(изб.) → 5KCl + K₃PO₄ + 4H₂O PCl₅ + 7KOH(нед.) → 5KCl + K₂HPO₄ + 3H₂O PCl₅ + 6KOH(б. нед.) → 5KCl + KH₂PO₄ + 2H₂O
Другие галогениды в щелочи (изб.) PCl₃ + 5KOH(изб.) → 3KCl + K₂HPO₃ + 2H₂O SiCl₄ + 6KOH(изб.) → 4KCl + K₂SiO₃ + 3H₂O COCl₂ + 4KOH(изб.) → 2KCl + K₂CO₃ + 2H₂O
⚠️ Правило для PCl₅ + KOH
Степень нейтрализации H₃PO₄ зависит от количества KOH:
• Изб. KOH → K₃PO₄ (средняя соль)
• Нед. KOH (2/3) → K₂HPO₄ (двузамещённая)
• Большой недостаток (1/3) → KH₂PO₄ (однозамещённая)

Двойной (совместный) гидролиз солей

Механизм двойного гидролиза

Соли, образованные слабой летучей кислотой и слабым нерастворимым основанием, нельзя получить смешиванием растворов — происходит взаимное усиление гидролиза.

💡 Механизм (на примере AlCl₃ + Na₂CO₃)
Al³⁺ + HOH ⇌ Al(OH)²⁺ + H⁺ — среда кислая
CO₃²⁻ + HOH ⇌ HCO₃⁻ + OH⁻ — среда щелочная
При смешивании H⁺ и OH⁻ нейтрализуются → равновесие смещается вправо → гидролиз идёт до конца.
Признак: осадок ↓ + газ ↑ одновременно.

  • При сливании солей Fe(III) с сульфидами и сульфитами протекает окислительно-восстановительная реакция, а не двойной гидролиз
  • Двойной гидролиз: Al³⁺ и Cr³⁺ с CO₃²⁻, SO₃²⁻, S²⁻; Fe³⁺ только с CO₃²⁻

Совместный гидролиз солей двухвалентных металлов

При совместном гидролизе солей двухвалентных металлов образуются основные соли:

Гидролиз солей MeO₂ˣ⁻

Что такое соли MeO₂ˣ⁻?

Это соли, кислотный остаток которых образован амфотерным металлом: алюминаты (AlO₂⁻), цинкаты (ZnO₂²⁻), хроматы-метасоединения (CrO₂⁻), ферриты (FeO₂⁻).

1. Водный гидролиз

Средние соли реагируют с водой с образованием гидроксокомплексов (кроме ферритов):

K₂ZnO₂ + 2H₂O → K₂[Zn(OH)₄] NaAlO₂ + 2H₂O → Na[Al(OH)₄] NaCrO₂ + 2H₂O → Na[Cr(OH)₄]
⚠️ Ферриты — исключение
Fe(OH)₃ проявляет слабые амфотерные свойства и не растворяется в разбавленных щелочах, поэтому феррит гидролизуется иначе:
NaFeO₂ + 2H₂O → Fe(OH)₃↓ + NaOH

2. Кислотный гидролиз

Гидроксокомплексы полностью разрушаются с образованием средних солей:

K₂ZnO₂ + 4HCl → 2KCl + ZnCl₂ + 2H₂O NaAlO₂ + 4HNO₃ → NaNO₃ + Al(NO₃)₃ + 2H₂O 2NaFeO₂ + 4H₂SO₄ → Na₂SO₄ + Fe₂(SO₄)₃ + 4H₂O
