⚡ Лайфхак: как быстро определить силу кислоты
Кислородсодержащие (O−H правило)
Считаем: кол-во O − кол-во H
≥ 2 → сильная
= 1 → средняя
≤ 0 → слабая
Пример: HNO₃ → 3O−1H = 2 → сильная ✓
H₃PO₄ → 4O−3H = 1 → слабая ✓
H₂SO₄ → 4O−2H = 2 → сильная ✓
Бескислородные
Все сильные, кроме:
HF — слабая (фтороводородная) H₂S — слабая (сероводородная)
HCl, HBr, HI → сильные
