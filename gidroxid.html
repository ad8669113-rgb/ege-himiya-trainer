Что такое гидроксиды? Классификация. Тривиальные названия

Определение

Гидроксиды — сложные вещества, содержащие гидроксогруппу –OH. В зависимости от того, как атом связан с группой OH, гидроксиды делятся на три класса.

Схема классификации
⚡ ВАЖНО — выучи наизусть
Амфотерные гидроксиды: Al(OH)₃, Zn(OH)₂, Be(OH)₂, Sn(OH)₂, Pb(OH)₂, Cr(OH)₃, Fe(OH)₃
Эти вещества — ловушка на ЕГЭ. Они реагируют и с кислотами, и со щелочами!

Классификация оснований

🟢 Щёлочи (растворимые основания)
Хорошо растворяются в воде. Активно вступают во все реакции.

NaOH — гидроксид натрия
KOH — гидроксид калия
Ba(OH)₂ — гидроксид бария
Ca(OH)₂ — гидроксид кальция (умеренно)
🔴 Нерастворимые основания
Осадки — выпадают в реакциях обмена. Разлагаются при нагревании.

Fe(OH)₂ — белый (буреет на воздухе)
Cu(OH)₂ — голубой

Классификация кислот

По наличию кислорода
Бескислородные: HCl, HBr, HI, HF, H₂S, H₂Se
(Без атома O в молекуле)

Кислородсодержащие: H₂SO₄, HNO₃, H₃PO₄, H₂CO₃, HClO₄…
(Есть атом O)
По основности (числу H⁺)
Одноосновные: HCl, HNO₃, HF — один H⁺
Двухосновные: H₂SO₄, H₂S, H₂CO₃ — два H⁺
Трёхосновные: H₃PO₄ — три H⁺

Основность = сколько протонов отщепляется!

Химические свойства кислот

💡 Главное правило
Кислоты реагируют с веществами, которые могут нейтрализовать кислотные свойства: металлами, основными оксидами, основаниями, солями слабых кислот.
1. Кислота + металл → соль + H₂↑

Реагируют металлы, стоящие в ряду активности до водорода. Металлы после водорода (Cu, Ag, Au) — не реагируют с разбавленными кислотами.

Zn + H₂SO₄(разб.) → ZnSO₄ + H₂↑ Fe + 2HCl → FeCl₂ + H₂↑ 2Na + 2HCl → 2NaCl + H₂↑
⚠️ Ловушки ЕГЭ
  • HNO₃ (любая) и H₂SO₄ (конц.) — не выделяют H₂! Выделяют NO, NO₂, SO₂
  • Cu, Ag, Au — не реагируют с HCl и разбавленной H₂SO₄
  • Al и Fe пассивируются в конц. HNO₃ и конц. H₂SO₄ — реакция не идёт
2. Кислота + основной оксид → соль + H₂O
CaO + 2HCl → CaCl₂ + H₂O Na₂O + H₂SO₄ → Na₂SO₄ + H₂O
3. Кислота + основание → соль + H₂O (нейтрализация)
⚡ ВАЖНО — Реакция нейтрализации — одна из самых важных для ЕГЭ. Идёт всегда между кислотой и основанием.
NaOH + HCl → NaCl + H₂O Ca(OH)₂ + 2HNO₃ → Ca(NO₃)₂ + 2H₂O 3NaOH + H₃PO₄ → Na₃PO₄ + 3H₂O
4. Кислота + соль → новая соль + новая кислота
⚡ ВАЖНО — Реакция идёт, если образуется осадок ↓, газ ↑ или слабый электролит (вода). Иначе — реакция не идёт!
Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl Na₂SiO₃ + 2HCl → 2NaCl + H₂SiO₃↓
📌 Условие реакции кислоты с солью
Реакция идёт только если продукт — нерастворимая соль (осадок ↓), газ (↑) или вода. Если ничего из этого не образуется — реакция не идёт.
5. Кислота + амфотерный гидроксид → соль + H₂O
Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O Zn(OH)₂ + H₂SO₄ → ZnSO₄ + 2H₂O
✅ Сильные кислоты — знать наизусть
  • HCl — хлороводородная (соляная)
  • H₂SO₄ — серная
  • HNO₃ — азотная
  • HBr — бромоводородная
  • HI — иодоводородная
  • HClO₄ — хлорная
  • HMnO₄ — марганцевая (перманганатная)

Химические свойства оснований

💡 Главное правило
Основания реагируют с кислотами, кислотными оксидами, солями (при условии образования осадка/газа/воды) и амфотерными гидроксидами. Щёлочи реагируют ещё с некоторыми металлами (Al, Zn).
1. Основание + кислота → соль + H₂O (нейтрализация)
KOH + HNO₃ → KNO₃ + H₂O Ba(OH)₂ + H₂SO₄ → BaSO₄↓ + 2H₂O Fe(OH)₃ + 3HCl → FeCl₃ + 3H₂O
2. Основание + кислотный оксид → соль + H₂O

Основные и амфотерные оксиды — основные свойства, кислотные оксиды — кислотные. Реагируют по принципу «кислотное + основное».

2NaOH + CO₂ → Na₂CO₃ + H₂O Ca(OH)₂ + SO₃ → CaSO₄ + H₂O NaOH + CO₂(изб.) → NaHCO₃
⚡ NaOH + CO₂ — два варианта!
  • NaOH(изб.) + CO₂ → Na₂CO₃ + H₂O  (средняя соль)
  • NaOH(недост.) + CO₂(изб.) → NaHCO₃  (кислая соль)
Это частая ловушка на ЕГЭ — следи за соотношением реагентов!
3. Щёлочь + соль → новое основание + новая соль

Реакция идёт при образовании осадка (нерастворимого основания) или газа (NH₃).

2NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄ 3KOH + FeCl₃ → Fe(OH)₃↓ + 3KCl 2NaOH + (NH₄)₂SO₄ → Na₂SO₄ + 2NH₃↑ + 2H₂O
4. Щёлочь + металл (Al, Zn) → соль + H₂↑

Только щёлочи (растворимые основания) реагируют с амфотерными металлами. Нерастворимые основания — не реагируют.

2NaOH + 2Al + 2H₂O → 2NaAlO₂ + 3H₂↑ 2KOH + Zn + 2H₂O → K₂[Zn(OH)₄] + H₂↑
📌 Запомни: только Al и Zn реагируют со щёлочами среди металлов
Be, Sn, Pb — тоже могут, но менее актуальны для ЕГЭ. Fe, Cu, Mg — со щёлочами не реагируют.
5. Нерастворимые основания разлагаются при нагревании
Cu(OH)₂ →(t°) CuO + H₂O 2Fe(OH)₃ →(t°) Fe₂O₃ + 3H₂O Fe(OH)₂ →(t°) FeO + H₂O
⚡ ВАЖНО — Щёлочи (NaOH, KOH) при нагревании не разлагаются — у них нет нерастворимых продуктов. Они только плавятся (~320 °C)!

Амфотерные гидроксиды

Амфотерные гидроксиды — это вещества, которые проявляют свойства и кислот, и оснований одновременно. Они реагируют как с кислотами, так и со щелочами.

⚡ СПИСОК — наизусть
Al(OH)₃ — гидроксид алюминия  |  Zn(OH)₂ — гидроксид цинка
Be(OH)₂ — гидроксид бериллия  |  Sn(OH)₂ — гидроксид олова(II)
Pb(OH)₂ — гидроксид свинца(II)  |  Cr(OH)₃ — гидроксид хрома(III)
Fe(OH)₃ — гидроксид железа(III)
1. Амфотерный + кислота → соль + H₂O (ведёт себя как основание)

В реакции с кислотой амфотерный гидроксид ведёт себя как основание — отдаёт OH⁻, образует соль и воду.

Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O Zn(OH)₂ + H₂SO₄ → ZnSO₄ + 2H₂O Cr(OH)₃ + 3HNO₃ → Cr(NO₃)₃ + 3H₂O Be(OH)₂ + 2HCl → BeCl₂ + 2H₂O
2. Амфотерный + щёлочь + H₂O → комплексная соль (ведёт себя как кислота)

В реакции со щёлочью в растворе амфотерный гидроксид ведёт себя как кислота — образует комплексную соль. Вода — реагент (пишется до стрелки)!

3. Амфотерный + щёлочь →(сплавление, t°) средняя соль + H₂O (без раствора)

При сплавлении (без воды) амфотерный гидроксид реагирует со щёлочью иначе — образует среднюю (простую) соль и воду. Комплекс не образуется!

Реакция (раствор) Реакция (сплавление) Продукт
Al(OH)₃ + NaOH + H₂O → Na[Al(OH)₄] Al(OH)₃ + NaOH →(t°) NaAlO₂ + 2H₂O Тетрагидроксоалюминат / метаалюминат натрия
Zn(OH)₂ + 2NaOH + H₂O → Na₂[Zn(OH)₄] Zn(OH)₂ + 2NaOH →(t°) Na₂ZnO₂ + 2H₂O Тетрагидроксоцинкат / цинкат натрия
Cr(OH)₃ + NaOH + H₂O → Na[Cr(OH)₄] Cr(OH)₃ + NaOH →(t°) NaCrO₂ + 2H₂O Тетрагидроксохромат / хромит натрия
Be(OH)₂ + 2NaOH + H₂O → Na₂[Be(OH)₄] Be(OH)₂ + 2NaOH →(t°) Na₂BeO₂ + 2H₂O Тетрагидроксобериллат / бериллат натрия
⚠️ Важно: амфотерные гидроксиды — НЕ реагируют с водой
Al(OH)₃, Zn(OH)₂ и остальные амфотерные гидроксиды нерастворимы в воде и не реагируют с ней. Они растворяются только в кислотах и щелочах.

Схема амфотерности Al(OH)₃

HCl (кислота)  ←  Al(OH)₃  →  NaOH (щёлочь)
↓                                              ↓
AlCl₃ + H₂O                           Na[Al(OH)₄]
⚠️ Ловушки ЕГЭ про амфотерные гидроксиды
  • Al(OH)₃ + NaOH в растворе → Na[Al(OH)₄] (комплексная соль); H₂O — до стрелки: + H₂O
  • Al(OH)₃ + NaOH при сплавлении → NaAlO₂ + H₂O (метаалюминат)
  • Cr(OH)₃ — серо-зелёный осадок, амфотерный! Fe(OH)₃ — бурый осадок, тоже амфотерный
  • Fe(OH)₂ — не амфотерный, реагирует только с кислотами. Fe(OH)₃ — амфотерный!

Разложение гидроксидов при нагревании

При нагревании нерастворимые основания разлагаются на оксид металла и воду. Щёлочи (NaOH, KOH) при умеренном нагревании не разлагаются.

1. Нерастворимое основание →(t°) оксид металла + H₂O
Cu(OH)₂ →(t°) CuO + H₂O     (чёрный осадок) 2Fe(OH)₃ →(t°) Fe₂O₃ + 3H₂O Fe(OH)₂ →(t°) FeO + H₂O Mg(OH)₂ →(t°) MgO + H₂O 2Al(OH)₃ →(t°) Al₂O₃ + 3H₂O Zn(OH)₂ →(t°) ZnO + H₂O Cr(OH)₃ →(t°) ½Cr₂O₃ + 3/2 H₂O   (или: 2Cr(OH)₃ → Cr₂O₃ + 3H₂O) Ca(OH)₂ →(очень высокое t°) CaO + H₂O
⚠️ Ловушки ЕГЭ
  • NaOH и KOH не разлагаются при обычном нагревании — ловушка! Они плавятся (~320 °C), но не разлагаются
  • Cu(OH)₂ → CuO (чёрный) + H₂O — цвет меняется с голубого на чёрный
  • 2Fe(OH)₃ → Fe₂O₃ (бурый оксид) — правильно расставить коэффициенты!
  • Кислоты тоже разлагаются: H₂CO₃ → CO₂ + H₂O; H₂SiO₃ →(t°) SiO₂ + H₂O
2. Нестойкая кислота → кислотный оксид + H₂O (или газ + H₂O)

Разложение кислот

H₂CO₃ → CO₂↑ + H₂O   (неустойчива, разлагается сразу) H₂SiO₃ →(t°) SiO₂ + H₂O 4HNO₃(конц.) →(t°) 4NO₂ + O₂ + 2H₂O H₂SO₄ — не разлагается при умеренном нагревании
✅ Что разлагается / что не разлагается
  • Разлагаются: все нерастворимые основания, H₂CO₃, H₂SiO₃, HNO₃ (конц., горячая)
  • НЕ разлагаются: NaOH, KOH, Ba(OH)₂, H₂SO₄, HCl (в обычных условиях)

Способы получения гидроксидов

Получение оснований

1. Активный металл + H₂O → щёлочь + H₂↑
2Na + 2H₂O → 2NaOH + H₂↑ Ca + 2H₂O → Ca(OH)₂ + H₂↑ 2K + 2H₂O → 2KOH + H₂↑

Так реагируют щелочные (Li, Na, K, Rb, Cs) и щелочноземельные (Ca, Sr, Ba) металлы. Al, Mg, Fe с водой в обычных условиях не реагируют.

2. Основной оксид + H₂O → щёлочь
Na₂O + H₂O → 2NaOH CaO + H₂O → Ca(OH)₂   (гашение извести) BaO + H₂O → Ba(OH)₂

Оксиды амфотерных и малоактивных металлов (Al₂O₃, FeO, CuO) с водой не реагируют.

3. Соль + щёлочь → нерастворимое основание↓ + соль
CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄ FeCl₃ + 3KOH → Fe(OH)₃↓ + 3KCl AlCl₃ + 3NaOH(недост.) → Al(OH)₃↓ + 3NaCl
⚠️ AlCl₃ + NaOH — два варианта!
  • NaOH недостаток: AlCl₃ + 3NaOH → Al(OH)₃↓ + 3NaCl
  • NaOH избыток: AlCl₃ + 4NaOH → Na[Al(OH)₄] + 3NaCl
4. Электролиз: 2MeCl + 2H₂O → 2MeOH + H₂↑ + Cl₂↑
2NaCl + 2H₂O →(электролиз) 2NaOH + H₂↑ + Cl₂↑ 2KCl + 2H₂O →(электролиз) 2KOH + H₂↑ + Cl₂↑ 2LiCl + 2H₂O →(электролиз) 2LiOH + H₂↑ + Cl₂↑

Промышленный способ получения NaOH — электролиз раствора NaCl (хлорщелочной процесс).

Получение кислот

1. Кислотный оксид + H₂O → кислота (SiO₂ — исключение!)
SO₃ + H₂O → H₂SO₄ P₂O₅ + 3H₂O → 2H₃PO₄ CO₂ + H₂O → H₂CO₃ N₂O₅ + H₂O → 2HNO₃

SiO₂ с водой не реагирует — H₂SiO₃ получают другими способами.

2. Сильная кислота + соль слабой кислоты → новая соль + слабая кислота↑/↓
Na₂SiO₃ + 2HCl → 2NaCl + H₂SiO₃↓ Na₂CO₃ + H₂SO₄ → Na₂SO₄ + H₂O + CO₂↑ BaS + H₂SO₄ → BaSO₄↓ + H₂S↑
3. H₂ + неметалл → HX(газ) → растворить в H₂O → бескислородная кислота
H₂ + Cl₂ → 2HCl    → растворяем в воде → соляная кислота H₂ + S →(t°) H₂S    → растворяем в воде → сероводородная кислота

Генетическая связь классов неорганических веществ

Генетическая связь показывает, как классы неорганических веществ переходят друг в друга через химические реакции.

Пример: цепочка натрия

4Na + O₂ → 2Na₂O   (металл → оксид) Na₂O + H₂O → 2NaOH   (оксид → основание) NaOH + HCl → NaCl + H₂O   (основание → соль) NaCl + AgNO₃ → AgCl↓ + NaNO₃   (соль → другая соль)

Пример: цепочка кальция

2Ca + O₂ → 2CaO CaO + H₂O → Ca(OH)₂ Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O CaCO₃ →(t°) CaO + CO₂↑

Пример: цепочка серы

S + O₂ → SO₂   (неметалл → оксид) 2SO₂ + O₂ →(кат., t°) 2SO₃   (оксид → высший оксид) SO₃ + H₂O → H₂SO₄   (оксид → кислота) H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O   (кислота → соль)
