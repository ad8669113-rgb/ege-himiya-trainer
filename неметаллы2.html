Аллотропия. Физические свойства. Главные ловушки

1.1 Аллотропные модификации

Аллотропия — существование двух и более простых веществ одного элемента с разным строением. Модификации одного элемента сильно отличаются по свойствам.

Углерод C
sp³ · атомная
Алмаз
Самый твёрдый. Изолятор (не проводит ток). Прозрачный. t° пл. ≈ 3550°C.
sp² · слоистая
Графит
Проводит ток! Мягкий, скользкий. Серо-чёрный. Используется в карандашах, электродах.
молекулярная
Фуллерен C₆₀
Шар из 60 атомов C: 20 шестиугольников + 12 пятиугольников. Молекулярная решётка.
Фосфор P
P₄ · молекулярная
Белый P₄
Ядовит! Самовоспл. при ~34°C. Светится в темноте. Хранят под водой.
атомная · полимер
Красный P
Не ядовит. Стабилен на воздухе. Используется в спичках. Красно-бурый порошок.
слоистая
Чёрный P
Полупроводник. Наиболее стабилен. Слоистая гофрированная структура. Похож на графит.
Кремний Si
sp³ · алмазный тип
Кристаллический Si
Атомная решётка. Полупроводник. Серебристый металлический блеск. Тугоплавкий (1414°C).
нет порядка
Аморфный Si
Без строгой кристаллической решётки. Реакционноспособнее кристаллического. Применяется в солнечных батареях.
💡 Тип решётки → свойства
  • Атомная (алмаз, Si, красный P, SiO₂) — очень твёрдые, тугоплавкие, плохо проводят ток
  • Молекулярная (белый P₄, CO₂, H₂O) — летучие, низкая t° плавления, хрупкие
  • Слоистая (графит, чёрный P) — скользкие, анизотропные, могут проводить ток

1.3 Главные ловушки ЕГЭ — часть 2

🚫 НЕ РЕАГИРУЮТ — запомни!
  • H₂ + Si ↛ и H₂ + P ↛ — с водородом напрямую не реагируют! SiH₄ и PH₃ получают только косвенно (гидролиз силицидов и фосфидов).
  • C + I₂ ↛ — углерод с иодом не реагирует. Но Si + I₂ → SiI₄ — кремний реагирует со всеми галогенами!
  • Si + HNO₃ ↛ и Si + H₂SO₄(конц.) ↛ — Si пассивен к кислотам-окислителям, растворяется только в HF.
  • C + NaOH ↛ — углерод со щелочами не реагирует. Но Si + NaOH → Na₂SiO₃ + H₂↑!
  • SiO₂ + HCl ↛, SiO₂ + H₂SO₄ ↛ — SiO₂ реагирует только с HF и щелочами.
⚠ Зависит от количества реагента
  • P + Cl₂(изб.) → PCl₅ (P→+5); P + Cl₂(нед.) → PCl₃ (P→+3)
  • P + I₂ → PI₃ всегда (P→+3 только, PI₅ не существует!)
  • C + O₂(нед.) → 2CO — угарный газ; C + O₂(изб.) → CO₂

Химические свойства фосфора

2.1 С простыми веществами

Фосфор реагирует с большинством простых веществ. С кислородом — количество O₂ определяет продукт. С галогенами — количество галогена определяет с.о. P (+3 или +5). С водородом — напрямую не реагирует!

С кислородом 4P + 5O₂(изб.) → 2P₂O₅  (⬜ белый дым, P₂O₅ — сильный водоотнимающий агент) 4P + 3O₂(нед.) → 2P₂O₃ С галогенами 2P + 5Cl₂(изб.) → 2PCl₅ 2P + 3Cl₂(нед.) → 2PCl₃ 2P + 3I₂ → 2PI₃  (с I₂ — только до +3, PI₅ не существует!) С водородом H₂ + P ↛  (напрямую не реагируют! PH₃ — только косвенный синтез) ↳ косвенные пути → PH₃: AlP + 3H₂O → Al(OH)₃↓ + PH₃↑  (гидролиз фосфида) Ca₃P₂ + 6H₂O → 3Ca(OH)₂ + 2PH₃↑  (гидролиз фосфида) 4P(бел.) + 3KOH(конц.) + 3H₂O →t° 3KH₂PO₂ + PH₃↑  (диспропорционирование) С металлами 3Ca + 2P →t° Ca₃P₂  (фосфид кальция) Al + P →t° AlP  (фосфид алюминия) 3Zn + 2P →t° Zn₃P₂  (фосфид цинка)
⚠ Галогены и фосфор — количество решает!
  • P + Cl₂ (изб.) → PCl₅ (P→ +5)
  • P + Cl₂ (нед.) → PCl₃ (P→ +3)
  • P + I₂ → PI₃ — с иодом всегда только +3. PI₅ не существует!

2.2 С кислотами-окислителями и щёлочью

Фосфор — восстановитель: окисляется кислотами-окислителями до H₃PO₄. При нагревании с концентрированной щёлочью — диспропорционирует, образуя ядовитый PH₃.

P + 5HNO₃(конц.) → H₃PO₄ + 5NO₂↑ + H₂O  (🟤 NO₂) 3P + 5HNO₃(разб.) + 2H₂O → 3H₃PO₄ + 5NO↑ 2P + 5H₂SO₄(конц.) → 2H₃PO₄ + 5SO₂↑ + 2H₂O 4P(бел.) + 3KOH(конц.) + 3H₂O →t° 3KH₂PO₂ + PH₃↑  (PH₃ — ядовит, самовоспл.!)
🚫 Диспропорционирование белого фосфора со щёлочью
Только белый P₄ реагирует со щёлочью. Красный — нет!
Продукт: KH₂PO₂ (гипофосфит, P→+1) + PH₃↑ (фосфин, P→−3).
PH₃ — бесцветный ядовитый газ, самовоспламеняется на воздухе («болотные огни»!).

2.3 Промышленное получение P

Ca₃(PO₄)₂ + 3SiO₂ + 5C →t° 3CaSiO₃ + 2P↑ + 5CO↑  (промышленное получение фосфора)

Химические свойства кремния

3.1 С простыми веществами

Кремний — сравнительно инертный неметалл. Реагирует с галогенами (всеми, включая I₂ — в отличие от C и S!), кислородом, углеродом. С водородом напрямую не реагирует.

С кислородом Si + O₂ →t° SiO₂  (кварц; SiO₂ — атомная кристаллическая решётка) С галогенами Si + 2Cl₂ →t° SiCl₄ Si + 2Br₂ →t° SiBr₄ Si + 2I₂ →t° SiI₄  (Si реагирует со всеми Hal₂, включая I₂!) С углеродом Si + C →t° SiC  (карборунд — атомная решётка, прочность близка к алмазу) С металлами Si + 2Mg →t° Mg₂Si  (гидролиз: Mg₂Si + 4H₂O → 2Mg(OH)₂ + SiH₄↑) С водородом H₂ + Si ↛  (SiH₄ нельзя получить прямым синтезом!) ↳ косвенные пути → SiH₄: Mg₂Si + 4H₂O → 2Mg(OH)₂ + SiH₄↑  (гидролиз силицида водой) Mg₂Si + 4HCl → 2MgCl₂ + SiH₄↑  (гидролиз силицида кислотой)
⚠ Si vs C vs S — реакция с I₂ (ловушка ЕГЭ!)
  • Si + I₂ → SiI₄ — кремний реагирует с иодом ✓
  • C + I₂ ↛ — углерод с иодом не реагирует
  • S + I₂ ↛ — сера с иодом не реагирует

3.2 Со сложными веществами

Si не реагирует с большинством кислот, включая конц. HNO₃ и H₂SO₄. Растворяется только в HF. Зато реагирует со щелочами — редкое свойство для неметалла.

С кислотами (только HF!) Si + 4HF → SiF₄↑ + 2H₂↑  (единственная кислота-неокислитель, растворяющая Si) С кислотами-окислителями ↛ Si + HNO₃ ↛  (пассивен!) Si + H₂SO₄(конц.) ↛  (Si пассивен к кислотам-окислителям!) Со щёлочью Si + 2NaOH(конц.) + H₂O →t° Na₂SiO₃ + 2H₂↑  (Si реагирует со щёлочью — редкость!) С водяным паром Si + 2H₂O(пар) →t° SiO₂ + 2H₂↑
🚫 Si пассивен к HNO₃ и H₂SO₄(конц.) — но реагирует с HF и NaOH!
Сравни с Fe: Fe тоже пассивируется конц. HNO₃ и H₂SO₄ — но по другой причине (оксидная плёнка).
Si не растворяется из-за особой прочности связей Si–O на поверхности.
HF разрушает эту плёнку, образуя летучий SiF₄.

3.3 Получение кремния

SiO₂ + 2C →t° Si + 2CO↑  (промышленный способ — восстановление коксом) SiO₂ + 2Mg →t° Si + 2MgO  (лабораторный способ) Mg₂Si + 4HCl → 2MgCl₂ + SiH₄↑  (получение силана SiH₄ — гидролиз силицида)

Химические свойства углерода

4.1 С простыми веществами

Углерод — амфотерный по ОВР: может быть окислителем (с активными металлами) и восстановителем (с O₂, галогенами, кислотами). C + I₂ ↛ — главная ловушка!

С кислородом C + O₂(изб.) → CO₂ 2C + O₂(нед.) → 2CO  (CO — угарный газ, ядовит! бесцветный, без запаха) С водородом и серой C + 2H₂ ⇄t°, кат. CH₄ C + 2S →t° CS₂  (CS₂ — бесцветная жидкость-растворитель) С галогенами C + 2Cl₂ →t° CCl₄ C + 2F₂ → CF₄ C + I₂ ↛  (углерод с иодом не реагирует!) С металлами (карбиды) 2C + Ca →t° CaC₂  (карбид кальция; CaC₂ + 2H₂O → Ca(OH)₂ + C₂H₂↑ — ацетилен) 4Al + 3C →t° Al₄C₃  (метанид; Al₄C₃ + 12H₂O → 4Al(OH)₃ + 3CH₄↑)
⚠ Карбиды и их гидролиз — продукт зависит от типа карбида
  • CaC₂ (ацетиленид, C₂²⁻) + H₂O → C₂H₂↑ (ацетилен)
  • Al₄C₃ (метанид, C⁴⁻) + H₂O → CH₄↑ (метан)
  • Be₂C (метанид) + H₂O → CH₄↑

4.2 Со сложными веществами

С водяным паром C + H₂O(пар) →t° CO + H₂  («водяной газ» — горючая смесь CO + H₂) С кислотами-окислителями C + 4HNO₃(конц.) → CO₂↑ + 4NO₂↑ + 2H₂O  (C→CO₂, 🟤 NO₂) 3C + 4HNO₃(разб.) → 3CO₂↑ + 4NO↑ + 2H₂O C + 2H₂SO₄(конц.) → CO₂↑ + 2SO₂↑ + 2H₂O Со щёлочью ↛ C + NaOH ↛  (углерод со щёлочью не реагирует! В отличие от Si)

Химические свойства водорода

5.1 С простыми веществами

Водород — окислитель с активными металлами (→ гидриды, H⁻¹) и восстановитель с неметаллами (→ H⁺¹). С Si и P напрямую не реагирует!

С галогенами H₂ + F₂ →hν 2HF  (взрыв даже в темноте!) H₂ + Cl₂ → 2HCl  (взрыв на свету) H₂ + Br₂ ⇄ 2HBr H₂ + I₂ ⇄ 2HI − Q  (с поглощением тепла) С кислородом, серой, азотом 2H₂ + O₂ → 2H₂O H₂ + S ⇄ H₂S N₂ + 3H₂ ⇄Fe, t°, P 2NH₃ С углеродом C + 2H₂ ⇄t°, кат. CH₄  (метанирование) Не реагирует H₂ + Si ↛  (SiH₄ нельзя получить прямым синтезом!) H₂ + P ↛  (Si и P с H₂ напрямую не реагируют!) С активными металлами (гидриды) 2Na + H₂ →t° 2NaH  (H в с.о. −1) Ca + H₂ →t° CaH₂  (гидриды: H в с.о. −1)
⚠ Активность H₂ с галогенами убывает!
  • H₂ + F₂ → взрыв на свету (даже в темноте)
  • H₂ + Cl₂ → взрыв на свету; в темноте — медленно
  • H₂ + Br₂ ⇄ обратимо; H₂ + I₂ ⇄ обратимо с поглощением тепла

5.2 С оксидами металлов — H₂ как восстановитель

CuO + H₂ →t° Cu + H₂O  (⬛ CuO чёрный → 🔴 Cu красная) Fe₂O₃ + 3H₂ →t° 2Fe + 3H₂O WO₃ + 3H₂ →t° W + 3H₂O PbO + H₂ →t° Pb + H₂O ZnO + H₂ →t° Zn + H₂O
💡 CuO + H₂ — самая наглядная реакция восстановления
⬛ Чёрный оксид меди CuO при нагревании в токе H₂ превращается в красную медь Cu. Видна смена цвета — классическое наблюдение для ЕГЭ.
H₂ восстанавливает оксиды металлов, стоящих правее Al в ряду активности.
