Что такое электролиты

Электролиты — вещества, растворы которых проводят электрический ток. Почему? Потому что в растворе они распадаются на заряженные частицы — ионы.

Неэлектролиты — не проводят ток, ионов в растворе нет (например, сахар, спирт).

⚡ Примеры
  • Электролит: NaCl (поваренная соль) — в воде даёт ионы Na⁺ и Cl⁻
  • Неэлектролит: C₁₂H₂₂O₁₁ (сахароза) — в воде не распадается
  • Вода — очень слабый электролит (незначительно диссоциирует)

Электролитическая диссоциация

Электролитическая диссоциация — процесс распада вещества на ионы под действием молекул воды.

NaCl (кристалл) + H₂O → Na⁺ (катион) + Cl⁻ (анион)

Ионы — заряженные частицы. Катионы (+), анионы (−).

🧪 Классификация ионов
  • По составу: простые (Mg²⁺, Cl⁻) и сложные (PO₄³⁻, NH₄⁺)
  • По заряду: катионы (+) и анионы (−)
📊 Таблица растворимости (компактная)

Как пользоваться: Катионы (положительные ионы) расположены по горизонтали (синий фон). Анионы (отрицательные) — по вертикали (серо-голубой фон). Заряд иона определяется по его месту в таблице.

Диссоциация кислот

Кислоты → катионы водорода H⁺ и анионы кислотного остатка.

📝 Примеры
  • HCl → H⁺ + Cl⁻
  • H₂SO₄ → 2H⁺ + SO₄²⁻
  • H₃PO₄ ⇄ H⁺ + H₂PO₄⁻ (по ступеням, слабая)
4. Запиши диссоциацию HNO₃ (выбери правильную запись).
5

Диссоциация оснований

Основания → катион металла (или NH₄⁺) + гидроксид-ионы OH⁻.

📝 Примеры
  • NaOH → Na⁺ + OH⁻
  • Ba(OH)₂ → Ba²⁺ + 2OH⁻
5. Какая запись верна для диссоциации Ca(OH)₂?
6

Диссоциация солей

Соли → катион металла (или NH₄⁺) + анион кислотного остатка. Всегда в одну ступень.

📝 Примеры
  • CaCl₂ → Ca²⁺ + 2Cl⁻
  • Na₂SO₄ → 2Na⁺ + SO₄²⁻
  • Кислые соли: NaHCO₃ → Na⁺ + HCO₃⁻ (не распадается дальше!)
6. Как диссоциирует Al₂(SO₄)₃?

Молекулярные уравнения

Молекулярное уравнение — это обычная запись реакции с формулами веществ (без ионов).

🧪 Пример
  • NaOH + HCl → NaCl + H₂O
  • BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
7. Допиши молекулярное уравнение: KOH + HNO₃ → ...
8

Полное ионное уравнение

Алгоритм:

  1. Записать молекулярное уравнение с коэффициентами.
  2. Определить сильные растворимые электролиты.
  3. Расписать их на ионы (сохраняя коэффициенты).
  4. Оставить в молекулярном виде: осадки, газы, слабые электролиты, воду.
📝 Пример
  • Мол.: BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
  • Полн. ион.: Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄↓ + 2Na⁺ + 2Cl⁻
8. В полном ионном уравнении для реакции NaOH + HCl → NaCl + H₂O, какие вещества расписывают на ионы?
9

Сокращённое ионное уравнение

Сокращённое ионное получается из полного удалением одинаковых ионов ("зрителей") из левой и правой частей.

📝 Пример
  • Полн.: Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄↓ + 2Na⁺ + 2Cl⁻
  • Сокр.: Ba²⁺ + SO₄²⁻ → BaSO₄↓
  • Зрители: 2Na⁺ и 2Cl⁻ (сокращаются)
9. Какие ионы являются "зрителями" в реакции Na₂CO₃ + 2HCl → 2NaCl + CO₂↑ + H₂O?

  • H⁺ + OH⁻ → H₂O (вода)
