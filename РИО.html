Что такое электролиты

Электролиты — вещества, растворы которых проводят электрический ток. Почему? Потому что в растворе они распадаются на заряженные частицы — ионы.

Неэлектролиты — не проводят ток, ионов в растворе нет (например, сахар, спирт).

⚡ Примеры
  • Электролит: NaCl (поваренная соль) — в воде даёт ионы Na⁺ и Cl⁻
  • Неэлектролит: C₁₂H₂₂O₁₁ (сахароза) — в воде не распадается
  • Вода — очень слабый электролит (незначительно диссоциирует)

Электролитическая диссоциация

Электролитическая диссоциация — процесс распада вещества на ионы под действием молекул воды.

NaCl (кристалл) + H₂O → Na⁺ (катион) + Cl⁻ (анион)

Ионы — заряженные частицы. Катионы (+), анионы (−).

🧪 Классификация ионов
  • По составу: простые (Mg²⁺, Cl⁻) и сложные (PO₄³⁻, NH₄⁺)
  • По заряду: катионы (+) и анионы (−)
📊 Таблица растворимости (компактная)

Как пользоваться: Катионы (положительные ионы) расположены по горизонтали (синий фон). Анионы (отрицательные) — по вертикали (серо-голубой фон). Заряд иона определяется по его месту в таблице.

Диссоциация кислот

Кислоты → катионы водорода H⁺ и анионы кислотного остатка.

📝 Примеры
  • HCl → H⁺ + Cl⁻
  • H₂SO₄ → 2H⁺ + SO₄²⁻
  • H₃PO₄ ⇄ H⁺ + H₂PO₄⁻ (по ступеням, слабая)
4. Запиши диссоциацию HNO₃ (выбери правильную запись).

Диссоциация оснований

Основания → катион металла (или NH₄⁺) + гидроксид-ионы OH⁻.

📝 Примеры
  • NaOH → Na⁺ + OH⁻
  • Ba(OH)₂ → Ba²⁺ + 2OH⁻
5. Какая запись верна для диссоциации Ca(OH)₂?

Диссоциация солей

Соли → катион металла (или NH₄⁺) + анион кислотного остатка. Всегда в одну ступень.

📝 Примеры
  • CaCl₂ → Ca²⁺ + 2Cl⁻
  • Na₂SO₄ → 2Na⁺ + SO₄²⁻
  • Кислые соли: NaHCO₃ → Na⁺ + HCO₃⁻ (не распадается дальше!)

Молекулярные уравнения

Молекулярное уравнение — это обычная запись реакции с формулами веществ (без ионов).

🧪 Пример
  • NaOH + HCl → NaCl + H₂O
  • BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl

8

Полное ионное уравнение

Алгоритм:

  1. Записать молекулярное уравнение с коэффициентами.
  2. Определить сильные растворимые электролиты.
  3. Расписать их на ионы (сохраняя коэффициенты).
  4. Оставить в молекулярном виде: осадки, газы, слабые электролиты, воду.
📝 Пример
  • Мол.: BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
  • Полн. ион.: Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄↓ + 2Na⁺ + 2Cl⁻
8. В полном ионном уравнении для реакции NaOH + HCl → NaCl + H₂O, какие вещества расписывают на ионы?
9

Сокращённое ионное уравнение

Сокращённое ионное получается из полного удалением одинаковых ионов ("зрителей") из левой и правой частей.

📝 Пример
  • Полн.: Ba²⁺ + 2Cl⁻ + 2Na⁺ + SO₄²⁻ → BaSO₄↓ + 2Na⁺ + 2Cl⁻
  • Сокр.: Ba²⁺ + SO₄²⁻ → BaSO₄↓
  • Зрители: 2Na⁺ и 2Cl⁻ (сокращаются)
9. Какие ионы являются "зрителями" в реакции Na₂CO₃ + 2HCl → 2NaCl + CO₂↑ + H₂O?

🪨 Образование осадка

13 задания из ЕГЭ

Как решать
1Из перечня выбери два вещества, при смешивании которых образуется нерастворимый продукт — проверяй по таблице растворимости
2Запиши молекулярное уравнение с коэффициентами, поставь ↓ у осадка
3Полное ионное: растворимые соли, сильные кислоты, щёлочи → разбей на ионы; осадок (↓), слабые кислоты, вода — оставь молекулой

⚠️ Ag₂S — чёрный осадок, не растворяется даже в кислотах: в кратком уравнении он всегда молекулой
⚠️ Если вода в реакции не образуется — не добавляй H₂O в уравнение

💧 Образование слабого электролита

22 задания из ЕГЭ

Как решать
1Определи, что образуется в продуктах: это должен быть слабый электролит — вещество, которое почти не диссоциирует на ионы
2Слабые электролиты (выучи!): H₂O, CH₃COOH, HF, HNO₂, H₂S, NH₃·H₂O, Mg(OH)₂, Fe(OH)₃, Al(OH)₃, Cr(OH)₃
3В полном ионном уравнении слабый электролит пиши МОЛЕКУЛОЙ — не разбивай его на ионы!

Частые ошибки
⚠️ HNO₂ (азотистая) — слабая, HNO₃ (азотная) — сильная: разные вещества!
⚠️ HF — слабая кислота, хотя фтор самый активный галоген: в ионном пиши HF молекулой
⚠️ NH₄F + кислота → образуется HF (слабый электролит); NH₄F + щёлочь → образуется NH₃·H₂O (тоже слабый)

💨 Выделение газа

13 задания из ЕГЭ

Как решать
1Найди газ среди продуктов. Газы в ИО-реакциях: CO₂, SO₂, NH₃, H₂S — именно они выделяются при ионном обмене
2Запомни схемы: карбонат/гидрокарбонат + кислота → CO₂↑ + H₂O; сульфит + кислота → SO₂↑ + H₂O; соль аммония + щёлочь → NH₃↑ + H₂O
3H₂CO₃ и H₂SO₃ — нестабильны, сразу пиши как CO₂↑ + H₂O и SO₂↑ + H₂O (не пиши саму кислоту). NH₃·H₂O тоже нестабилен: пиши NH₃↑ + H₂O
4В ионных уравнениях газ всегда пиши молекулой с символом ↑, вычеркни зрителей → краткое ионное
Частые ошибки
⚠️ Сульфит (SO₃²⁻) + кислота → SO₂↑, а сульфат (SO₄²⁻) + кислота газа НЕ даёт — не путай суффиксы -ит и -ат!
⚠️ Гидрокарбонат + кислота → CO₂↑; гидрокарбонат + щёлочь → CO₃²⁻ (газа нет!)
⚠️ Символ ↑ — только у газа, ↓ — только у осадка; не перепутай местами

🔀 Кислые и основные соли

14 задания из ЕГЭ

Как решать
1Найди кислую соль — в её формуле есть H после металла: NaHCO₃, KHSO₄, NaH₂PO₄, K₂HPO₄, Mg(HCO₃)₂
2Кислая соль + щёлочь → средняя соль + H₂O. Кислый анион отдаёт свой H⁺ иону OH⁻. Пример: HCO₃⁻ + OH⁻ → CO₃²⁻ + H₂O
3Кислая соль + кислота → газ или другой продукт. Пример: HCO₃⁻ + H⁺ → CO₂↑ + H₂O
4Кислая соль + кислая соль → реакции нет (оба кислые); кислая соль + средняя соль → только если образуется осадок
Частые ошибки
⚠️ NaHCO₃ + HCl → CO₂↑ + H₂O + NaCl (газ, не осадок!)
⚠️ KHSO₄ — особая соль: диссоциирует полностью → K⁺ + H⁺ + SO₄²⁻ (пиши в ионном как сильную кислоту)
⚠️ H₂PO₄⁻ + 2OH⁻ → PO₄³⁻ + 2H₂O (два протона отдаёт, не один — считай внимательно)
