Физические свойства. Аллотропия. Ряд ЭО

1.1 Ряд электроотрицательности

Атомы неметаллов имеют большое число электронов на внешнем слое, небольшой радиус и высокую ЭО — поэтому стремятся принимать электроны. Исключение — фтор: он всегда только окислитель, с.о. всегда −1.

◄ слабее (восстановители)сильнее (окислители) ►
МеSi=H=P CS IBr ClN OF
Si, H, P, C, S — преимущественно восстановители N, O, F — преимущественно окислители

1.2 Физические свойства и цвета

ВеществоСостояние при н.у.Цвет и особенности
F₂Газ🟡 Бледно-жёлтый. Самый сильный окислитель. С.о. всегда −1. Реагирует с водой со взрывом.
Cl₂Газ🟡🟢 Жёлто-зелёный. Резкий запах. Ядовит. В воде → хлорная вода (HCl + HClO).
Br₂⚠ Жидкость🟤 Красно-бурая жидкость. Единственный жидкий неметалл при н.у.
I₂Твёрдое⬛ Серо-чёрные кристаллы. Пары фиолетовые. С крахмалом → синий цвет.

✏️ Задания на закрепление — блок 1.1–1.2
1
Br₂ — это газ или жидкость при н.у.? Какой цвет?
Ответ
Жидкость. 🟤 Красно-бурая.
Единственный жидкий неметалл при н.у.
2
Какого цвета пары I₂? Как определить I₂ качественно?
Ответ
Пары I₂ — фиолетовые. Качественная реакция: I₂ + крахмал → синий цвет.
Крахмало-йодная реакция — стандарт в аналитической химии.
3
Почему F₂ всегда имеет с.о. −1? Что это значит для его химических свойств?
Ответ
F — самый электроотрицательный элемент. С.о. всегда −1 → F₂ только окислитель, никогда не восстановитель.
Фтор не может отдавать электроны ни при каких условиях.
4
Расположи в порядке убывания активности: I₂, F₂, Br₂, Cl₂
Ответ
F₂ > Cl₂ > Br₂ > I₂
Активность убывает сверху вниз в группе VIIA. Запомни этот ряд — он нужен для всех реакций вытеснения.
✅ Запомнить
  • 🟤 Br₂ — единственный жидкий неметалл. ⬛ I₂ — пары фиолетовые.
  • F₂ — только окислитель, с.о. всегда −1. Инертные газы ни с чем не реагируют.
  • 🟡 S↓ жёлтый осадок: при Cl₂+H₂S, H₂S+O₂(нед.), I₂+H₂S и др.
  • 🟤 NO₂ — бурый газ; NO — бесцветный; SO₂ — бесцветный с резким запахом.

Химические свойства галогенов

2.1 С водородом H₂

Все галогены реагируют с H₂, образуя галогеноводороды HHal. Чем активнее галоген — тем жёстче условия и необратимее реакция. Активность убывает: F₂ > Cl₂ > Br₂ > I₂.

H₂ + F₂ →hν 2HF  (взрыв даже в темноте и на холоду!) H₂ + Cl₂ → 2HCl  (горение; ⬜ белый дым HCl) H₂ + Br₂ ⇄ 2HBr   H₂ + I₂ ⇄ 2HI − Q  (обратимые; H₂+I₂ — эндотермическая)
✏️ Задания — 2.1 Галогены + H₂
1
H₂ + F₂ → ? Какое условие? Почему реакция такая бурная?
Ответ
H₂ + F₂ →(hν) 2HF. Реакция со взрывом даже в темноте, при −200°С.
F₂ — самый сильный окислитель среди всех простых веществ.
2
H₂ + I₂ → ? Почему реакция обратима и эндотермическая?
Ответ
H₂ + I₂ ⇄ 2HI − Q. Обратимая, эндотермическая.
I₂ — слабый окислитель, реакция не идёт до конца. При нагреве равновесие смещается влево.
3
Сравни: H₂ + Cl₂ → ? (обратима ли реакция?)
Ответ
H₂ + Cl₂ → 2HCl. Необратимая (в отличие от H₂ + I₂).
Cl₂ активнее I₂ → реакция с H₂ идёт до конца.

2.2 С металлами — правило Fe и Cu

Все металлы + Hal₂ → галогениды. Степень окисления Fe и Cu зависит от силы галогена-окислителя.

⚠ Сила галогена определяет с.о. Fe и Cu
  • F₂, Cl₂, Br₂ (сильные окислители) → Fe³⁺, Cu²⁺
  • I₂ (слабый окислитель) → Fe²⁺, Cu⁺
  • FeI₃ не существует — I₂ не способен окислить Fe до +3
  • CuI₂ не существует — CuI₂ нестабилен, сразу разлагается до CuI

💡 Мнемоника: «Иод — слабак» → с иодом железо и медь дают низшую с.о.

2Fe + 3Cl₂ →t° 2FeCl₃  (Fe→+3, Cl₂ сильный)   Fe + I₂ →t° FeI₂  (Fe→+2! FeI₃ не существует) Cu + Cl₂ →t° CuCl₂  (Cu→+2)   2Cu + I₂ →t° 2CuI  (Cu→+1! CuI₂ не существует) 2Al + 3Cl₂ →t° 2AlCl₃   2Na + Cl₂ → 2NaCl   Mg + Br₂ → MgBr₂ 2Al + 3I₂ →H₂O 2AlI₃  (Al + I₂ только с катализатором H₂O!) C + I₂ ↛   S + I₂ ↛  (углерод и сера с иодом не реагируют!)
✏️ Задания — 2.2 Галогены + металлы (Fe и Cu)
1
Fe + Cl₂ → ? Какая с.о. Fe?
Ответ
2Fe + 3Cl₂ →(t°) 2FeCl₃. Fe→+3.
Cl₂ — сильный → Fe³⁺. Запомни: с Cl₂, Br₂, F₂ → железо всегда Fe³⁺.
2
Fe + I₂ → ? Можно ли написать FeI₃?
Ответ
Fe + I₂ →(t°) FeI₂. FeI₃ не существует!
I₂ слабый → Fe только до +2.
3
Cu + Cl₂ → ? и Cu + I₂ → ? Сравни с.о. Cu.
Ответ
Cu + Cl₂ →(t°) CuCl₂ (Cu→+2); 2Cu + I₂ →(t°) 2CuI (Cu→+1).
CuI₂ нестабилен — разлагается до CuI. С Cl₂ → +2, с I₂ → +1.
4
Al + I₂ → ? Что нужно для реакции?
Ответ
2Al + 3I₂ →(H₂O) 2AlI₃. Катализатор — вода H₂O.
Без воды Al + I₂ не реагирует. Это исключение!

2.3 С водой H₂O

При н.у. с водой реагируют только F₂ и Cl₂. Br₂ и I₂ в воде практически не взаимодействуют.

2F₂ + 2H₂O → 4HF + O₂  (взрыв! F₂ окисляет кислород воды) Cl₂ + H₂O ⇄ HCl + HClO  (равновесие; HClO — хлорноватистая к-та, сильный окислитель) Br₂ + H₂O ↛   I₂ + H₂O ↛  (при н.у. практически не реагируют)
📌 Почему хлорная вода — окислитель?

Cl₂ + H₂O ⇄ HCl + HClO. Хлорноватистая кислота HClO — нестабильный сильный окислитель. Именно она обесцвечивает ткани, убивает бактерии при хлорировании воды. Равновесие смещается вправо при разбавлении.

✏️ Задания — 2.3 Галогены + H₂O
1
Cl₂ + H₂O → ? Какое вещество делает хлорную воду окислителем?
Ответ
Cl₂ + H₂O ⇄ HCl + HClO. Окислитель — HClO (хлорноватистая кислота).
HClO обесцвечивает лакмус — используется для отбелки и обеззараживания воды.
2
F₂ + H₂O → ? Почему F₂ реагирует с водой, а Br₂ нет?
Ответ
2F₂ + 2H₂O → 4HF + O₂. F₂ — сильнейший окислитель, окисляет даже кислород воды. Br₂ слабее → не реагирует.
Реакция F₂ с водой опасна — идёт со взрывом.

2.4 Вытеснение из растворов кислот и солей

Более активный галоген вытесняет менее активный из растворов его солей и кислот: F₂ > Cl₂ > Br₂ > I₂. Обратная реакция невозможна.

Cl₂ + 2KBr → 2KCl + Br₂  (🟤 Br₂ красно-бурый) Cl₂ + 2KI → 2KCl + I₂  (⬛ I₂ серо-чёрный; с крахмалом — синий!) Cl₂ + H₂S → 2HCl + S↓  (🟡 S↓ жёлтый осадок) Br₂ + 2KI → 2KBr + I₂↓   Br₂ + H₂S → 2HBr + S↓  (🟡 S↓) I₂ + K₂S → 2KI + S↓  (🟡 S↓)   I₂ + H₂S → 2HI + S↓ S + KI ↛  (сера не вытесняет I₂ — I₂ активнее серы!)
✏️ Задания — 2.4 Вытеснение галогенов
1
Cl₂ + KBr → ? Что наблюдается?
Ответ
Cl₂ + 2KBr → 2KCl + Br₂. Раствор буреет — выделяется 🟤 красно-бурый Br₂.
Cl₂ активнее Br₂ → вытесняет его из бромида. Цвет меняется: бесцветный → бурый.
2
I₂ + K₂S → ? Какой цвет осадка?
Ответ
I₂ + K₂S → 2KI + S↓. 🟡 S↓ — жёлтый осадок.
I₂ — самый слабый галоген — окисляет только сульфиды.
3
S + KI → ? Почему реакция не идёт?
Ответ
S + KI ↛. Сера не может вытеснить иод.
I₂ активнее серы (стоит правее в ряду ЭО). Только более активное вещество вытесняет менее активное.
4
Br₂ + KCl → ? Идёт ли реакция? Объясни.
Ответ
Br₂ + KCl ↛. Br₂ не может вытеснить Cl₂ из KCl — Cl₂ активнее!
Реакция вытеснения идёт только от более активного к менее активному галогену.

2.5 Реакции со щелочами — диспропорционирование

Все галогены кроме фтора при взаимодействии со щелочами диспропорционируют — одновременно и окисляются, и восстанавливаются. Продукт зависит от температуры.

🚫 Главное правило: температура меняет продукт у Cl₂ и Br₂!
  • Холодная щёлочь → гипогалогенит (−1 и +1): Cl₂ + 2KOH(хол.) → KCl + KClO + H₂O
  • Горячая щёлочь → галогенат (−1 и +5): 3Cl₂ + 6KOH →(t°) 5KCl + KClO₃ + 3H₂O
  • I₂ при любой t° → иодат KIO₃. Гипоиодита KIO не существует!
  • F₂ не диспропорционирует — окисляет O²⁻ щёлочи до O₂
ГалогенХолодная щёлочьГорячая щёлочь
F₂2F₂ + 4NaOH → 4NaF + O₂↑ + 2H₂O  (не диспропорционирует! Окисляет O²⁻)
Cl₂Cl₂ + 2KOH → KCl + KClO + H₂O
(гипохлорит, с.о. Cl: −1 и +1)		3Cl₂ + 6KOH →(t°) 5KCl + KClO₃ + 3H₂O
(хлорат, с.о. Cl: −1 и +5)
Br₂Br₂ + 2KOH → KBr + KBrO + H₂O3Br₂ + 6KOH →(t°) 5KBr + KBrO₃ + 3H₂O
I₂ ⚠3I₂ + 6KOH → 5KI + KIO₃ + 3H₂O  (при ЛЮБОЙ t° → иодат!)
✏️ Задания — 2.5 Галогены + щёлочь
1
Cl₂ + KOH(хол.) → ? и Cl₂ + KOH(гор.) → ? Сравни продукты.
Ответ
Хол.: Cl₂ + 2KOH → KCl + KClO + H₂O. Гор.: 3Cl₂ + 6KOH →(t°) 5KCl + KClO₃ + 3H₂O.
Температура полностью меняет продукт! Холод → гипохлорит (KClO); нагрев → хлорат (KClO₃).
2
I₂ + KOH(хол.) → ? Гипоиодит или иодат?
Ответ
3I₂ + 6KOH → 5KI + KIO₃ + 3H₂O. Иодат при любой температуре!
Гипоиодита KIO не существует — он нестабилен и сразу диспропорционирует дальше до KIO₃.
3
F₂ + NaOH → ? Это диспропорционирование?
Ответ
2F₂ + 4NaOH → 4NaF + O₂ + 2H₂O. НЕ диспропорционирование!
F₂ не может повышать с.о. — всегда −1. Поэтому окисляет O²⁻ щёлочи до O₂.
✅ Запомнить — галогены
  • F₂ > Cl₂ > Br₂ > I₂ — активность убывает. Каждый вытесняет последующий.
  • Fe + Cl₂/Br₂ → Fe³⁺; Fe + I₂ → Fe²⁺. FeI₃ не существует!
  • Cu + Cl₂ → Cu²⁺; Cu + I₂ → Cu⁺. CuI₂ не существует!
  • C + I₂ ↛; S + I₂ ↛ — углерод и сера с иодом не реагируют.
  • I₂ при любой t° + щёлочь → иодат KIO₃ (не гипоиодит!).
  • Cl₂, Br₂, I₂ с O₂ не реагируют. F₂ + O₂ → O₂F₂ (фторид, не оксид!).
3

Химические свойства серы

3.1 С металлами и неметаллами

Сера — средний окислитель. С металлами образует сульфиды. Важно: с железом сера даёт только FeS (Fe²⁺), а не Fe₂S₃ — в отличие от хлора, который даёт FeCl₃ (Fe³⁺).

Fe + S →t° FeS  (Fe→+2, НЕ +3! Сера — средний окислитель) 2Cu + S(нед.) →t° Cu₂S   Cu + S(изб.) →t° CuS   Zn + S →t° ZnS   2Al + 3S →t° Al₂S₃ S + O₂ → SO₂   C + 2S →t° CS₂  (сероуглерод — бесцветный растворитель) S + I₂ ↛   S + HI ↛  (сера с иодом и HI не реагирует!)
✏️ Задания — 3.1 Сера + простые вещества
1
Fe + S → ? Почему не Fe₂S₃, как FeCl₃ с хлором?
Ответ
Fe + S →(t°) FeS. Только Fe²⁺ — сера средний окислитель.
С Cl₂ железо → Fe³⁺ (Cl₂ сильный), с серой → только Fe²⁺ (S средний). Сила окислителя важна!
2
S + I₂ → ? и C + I₂ → ?
Ответ
S + I₂ ↛ и C + I₂ ↛. Обе реакции не идут!
Запомни пару ловушек: сера с иодом и углерод с иодом не реагируют.

3.2 С водородом и кислотами-окислителями

Сера может быть и окислителем (реакции с металлами, H₂), и восстановителем (реакции с O₂, конц. кислотами).

H₂ + S ⇄ H₂S  (сероводород — бесцветный газ, запах тухлых яиц, ядовит) S + 6HNO₃(конц.) → H₂SO₄ + 6NO₂↑ + 2H₂O  (🟤 NO₂ бурый) S + 2HNO₃(разб.) → H₂SO₄ + 2NO↑   S + 2H₂SO₄(конц.) → 3SO₂↑ + 2H₂O 3S + 6KOH(конц.) →t° 2K₂S + K₂SO₃ + 3H₂O  (диспропорционирование S²⁻ и SO₃²⁻)

3.3 Кислород O₂ со сложными веществами серы

Это один из самых важных блоков для ЕГЭ — здесь сразу несколько ловушек.

2SO₂ + O₂ →V₂O₅, t° 2SO₃  (ключевая реакция производства H₂SO₄; катализатор V₂O₅) 2H₂S + O₂(нед.) → 2S↓ + 2H₂O  (🟡 S↓ жёлтый при нед. O₂) 2H₂S + 3O₂(изб.) → 2SO₂ + 2H₂O  (при изб. O₂ → SO₂, не S! Классическая ловушка!) 4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂  (🔴 Fe₂O₃ красно-коричн.; обжиг пирита — источник SO₂) 2ZnS + 3O₂ → 2ZnO + 2SO₂   2CuS + 3O₂ → 2CuO + 2SO₂
✏️ Задания — 3.2–3.3 Сера со сложными веществами
1
H₂S + O₂(нед.) → ? Какой цвет продукта?
Ответ
2H₂S + O₂(нед.) → 2S↓ + 2H₂O. 🟡 S↓ — жёлтый осадок.
При недостатке O₂ — сера не догорает, выпадает осадок. Классическая ловушка ЕГЭ!
2
H₂S + O₂(изб.) → ? Чем отличается?
Ответ
2H₂S + 3O₂(изб.) → 2SO₂ + 2H₂O. Продукт — SO₂, не S!
Количество кислорода полностью меняет продукт. Запомни оба случая.
3
2SO₂ + O₂ → ? Какой катализатор? Где применяется?
Ответ
2SO₂ + O₂ →(V₂O₅, t°) 2SO₃. Катализатор V₂O₅ (оксид ванадия(V)).
SO₃ + H₂O → H₂SO₄. Это контактный способ производства серной кислоты.
4
4FeS₂ + O₂ → ? Какого цвета продукт?
Ответ
4FeS₂ + 11O₂ → 2Fe₂O₃ + 8SO₂. 🔴 Fe₂O₃ — красно-коричневый.
Обжиг пирита FeS₂ — основной промышленный источник SO₂ для производства H₂SO₄.
✅ Запомнить — сера
  • Fe + S → FeS (Fe²⁺). Не Fe₂S₃! Сера — средний окислитель.
  • H₂S + O₂(нед.) → 🟡 S↓ жёлтый; H₂S + O₂(изб.) → SO₂.
  • 2SO₂ + O₂ →(V₂O₅) 2SO₃ — ключевая реакция производства H₂SO₄.
  • S + I₂ ↛ и S + HI ↛ — сера с иодом не реагирует.

Химические свойства азота и аммиака

4.1 Реакции молекулярного N₂

Молекула N₂ очень прочная (тройная связь N≡N, энергия 945 кДж/моль). Поэтому N₂ малоактивен — реагирует только в жёстких условиях. Исключение: Li + N₂ при н.у.!

N₂ + 3H₂ ⇄Fe, 450°C, 150–300 атм 2NH₃  (синтез аммиака — важнейший промышленный процесс) N₂ + O₂ ⇄ 2NO − Q  (молния / электрический разряд; эндотермическая; равновесие при н.у. сдвинуто влево) N₂O + O₂ ↛  (N₂O с O₂ не реагирует! N₂O — несолеобразующий оксид) 6Li + N₂ →н.у. 2Li₃N  (Li — единственный металл, реагирующий с N₂ при н.у.!) 3Mg + N₂ →t° Mg₃N₂   2Al + N₂ →t° 2AlN  (остальные металлы — только при нагреве)
✏️ Задания — 4.1 Азот N₂
1
N₂ + O₂ → ? Тип реакции? Что происходит с NO на воздухе?
Ответ
N₂ + O₂ ⇄ 2NO − Q. Эндотермическая (молния). На воздухе: 2NO + O₂ → 2NO₂ (🟤 бурый).
Молния фиксирует N₂ → NO → NO₂ → HNO₃ → нитраты → питание растений. Круговорот азота.
2
N₂O + O₂ → ? Почему не реагирует?
Ответ
N₂O + O₂ ↛. N₂O — несолеобразующий оксид, инертен к O₂.
Классическая ловушка ЕГЭ! N₂O часто путают с NO. N₂O (с.о. N = +1) с O₂ не реагирует.
3
Какой металл реагирует с N₂ при н.у.?
Ответ
6Li + N₂ →(н.у.) 2Li₃N. Только литий!
Все остальные металлы реагируют с N₂ только при нагревании.

4.3 Аммиак NH₃ — важнейшее соединение азота

Аммиак — бесцветный газ с резким запахом, хорошо растворяется в воде (нашатырный спирт). Ключевая реакция: окисление NH₃ зависит от наличия катализатора.

⚠ Катализатор меняет продукт горения NH₃
  • Без катализатора: 4NH₃ + 3O₂ → 2N₂ + 6H₂O (→ N₂)
  • С катализатором Pt: 4NH₃ + 5O₂ →(Pt, t°) 4NO + 6H₂O (→ NO)

С катализатором → NO → первый шаг промышленного производства HNO₃.

4NH₃ + 3O₂ → 2N₂ + 6H₂O  (горение без катализатора → N₂) 4NH₃ + 5O₂ →Pt, t° 4NO + 6H₂O  (с кат. Pt → NO; 1-й шаг произв. HNO₃) 2NO + O₂ → 2NO₂  (NO бесцветный → 🟤 NO₂ бурый на воздухе) 3NO₂ + H₂O → 2HNO₃ + NO  (3-й шаг произв. HNO₃; NO возвращается в цикл) NH₃ + HCl → NH₄Cl  (⬜ белый дым — качественная реакция на NH₃) NH₃ + H₂O ⇄ NH₄OH ⇄ NH₄⁺ + OH⁻  (нашатырный спирт — слабое основание)
✏️ Задания — 4.2–4.3 Аммиак и оксиды азота
1
NH₃ + O₂ без кат. → ? и с кат. Pt → ? Сравни продукты.
Ответ
Без кат.: 4NH₃ + 3O₂ → 2N₂ + 6H₂O. С Pt: 4NH₃ + 5O₂ →(Pt,t°) 4NO + 6H₂O.
Катализатор полностью меняет продукт: N₂ (горение) → NO (промышленность HNO₃).
2
2NO + O₂ → ? Что наблюдается?
Ответ
2NO + O₂ → 2NO₂. Бесцветный NO мгновенно буреет → 🟤 NO₂.
Именно так выглядит образование фотохимического смога в атмосфере.
3
Как из NO₂ получить HNO₃?
Ответ
3NO₂ + H₂O → 2HNO₃ + NO. Третья ступень промышленного синтеза HNO₃.
NO снова возвращается в цикл → окисляется O₂ → NO₂ → снова поглощается водой.
4
NH₃ + HCl → ? Что наблюдается? Как это используется?
Ответ
NH₃ + HCl → NH₄Cl. ⬜ Белый дым NH₄Cl.
Если поднести палочку с HCl к газу NH₃ — появляется белый дым. Качественная реакция на NH₃.
✅ Запомнить — азот
  • N₂ + O₂ — эндотермическая, при молнии. N₂O + O₂ ↛!
  • NO — бесцветный → на воздухе мгновенно → 🟤 NO₂ бурый (2NO + O₂ → 2NO₂).
  • NH₃ + O₂: без кат. → N₂; с кат. Pt → NO.
  • Li + N₂ — единственный металл с N₂ при н.у.
