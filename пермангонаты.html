Основы ОВР: степени окисления, окислители и восстановители

Что такое окислительно-восстановительная реакция?

Окислительно-восстановительные реакции (ОВР) — это реакции, в которых изменяются степени окисления атомов элементов, входящих в состав реагентов.

🧪 Степень окисления

Степень окисления — это условный заряд атома в соединении, вычисленный в предположении, что все связи являются ионными. Обозначается +n или −n.

Правила определения степени окисления:

  • В простых веществах (Na, O₂, Cl₂) степень окисления равна 0.
  • Степень окисления водорода в большинстве соединений +1 (исключение: гидриды металлов, например NaH, где H⁻).
  • Степень окисления кислорода обычно −2 (исключение: пероксиды, где −1; OF₂, где +2).
  • Сумма степеней окисления в молекуле равна 0, в ионе — заряду иона.

Окислитель — вещество, содержащее атом, который принимает электроны и понижает свою степень окисления. Сам окислитель восстанавливается.

Восстановитель — вещество, содержащее атом, который отдаёт электроны и повышает свою степень окисления. Сам восстановитель окисляется.

  • Только окислители: высшая степень окисления (S⁺⁶, N⁺⁵, Mn⁺⁷).
  • Только восстановители: низшая степень окисления (S²⁻, N³⁻, Cl⁻).

Как расставить коэффициенты в ОВР

Рассмотрим алгоритм на примере реакции:

PH₃ + KMnO₄ + H₂SO₄ → H₃PO₄ + MnSO₄ + K₂SO₄ + H₂O
1 Записать схему реакции
PH₃ + KMnO₄ + H₂SO₄ → H₃PO₄ + MnSO₄ + K₂SO₄ + H₂O
2 Определить элементы, которые меняют степень окисления
P⁻³ → P⁺⁵ (повышение, отдаёт электроны)
Mn⁺⁷ → Mn⁺² (понижение, принимает электроны)
3 Составить полуреакции (соблюдая массу и заряд)
P⁻³ − 8ē → P⁺⁵
Mn⁺⁷ + 5ē → Mn⁺²
4 Найти НОК (наименьшее общее кратное) электронов
НОК(8,5) = 40
Умножаем полуреакции: P⁻³ − 8ē → P⁺⁵  |×5|
Mn⁺⁷ + 5ē → Mn⁺²  |×8|
5 Перенести коэффициенты в схему
5PH₃ + 8KMnO₄ + H₂SO₄ → 5H₃PO₄ + 8MnSO₄ + K₂SO₄ + H₂O
6 Уравнять остальные элементы (по балансу)
5PH₃ + 8KMnO₄ + 12H₂SO₄ → 5H₃PO₄ + 8MnSO₄ + 4K₂SO₄ + 12H₂O
7 Проверить по кислороду
Слева: 8·4 + 12·4 = 80; справа: 5·4 + 8·4 + 4·4 + 12 = 80. Всё верно.
✅ Итог
5PH₃ + 8KMnO₄ + 12H₂SO₄ → 5H₃PO₄ + 8MnSO₄ + 4K₂SO₄ + 12H₂O

PH₃ (P⁻³) — восстановитель, KMnO₄ (Mn⁺⁷) — окислитель.

ОВР с соединениями марганца: перманганаты в разных средах

Перманганат калия — сильный окислитель

KMnO₄ — тёмно-фиолетовые кристаллы, в растворе даёт яркий малиновый цвет. Сильный окислитель за счёт марганца в степени окисления +7.

🧪 Среда определяет продукты

Восстановление Mn⁺⁷ зависит от кислотности среды:

  • Кислая среда: Mn⁺⁷ → Mn⁺² (соли Mn²⁺, раствор обесцвечивается)
  • Нейтральная среда: Mn⁺⁷ → Mn⁺⁴ (MnO₂↓ бурый осадок)
  • Сильнощелочная среда: Mn⁺⁷ → Mn⁺⁶ (MnO₄²⁻, зелёный раствор)

⚠️ Типичные ловушки ЕГЭ

🔴
NH₃ в кислой среде не окисляется KMnO₄. В кислой среде аммиак протонируется до NH₄⁺ и теряет восстановительные свойства. Реакция идёт только в нейтральной или щелочной среде.
🔴
HCl — одновременно кислота и восстановитель. В реакциях с KMnO₄ HCl создаёт кислую среду (H⁺) и сама окисляется (Cl⁻ → Cl₂). Нужно учитывать оба расхода HCl.
🔴
H₂O₂ — двойная роль. С более сильными окислителями (KMnO₄) H₂O₂ — восстановитель: H₂O₂ − 2ē → O₂. С более сильными восстановителями — окислитель: H₂O₂ + 2ē → 2OH⁻.
🔴
Сульфид → сера, не сульфат, в кислой среде. Na₂S в реакции с KMnO₄ даёт S↓ (жёлтая), а не SO₄²⁻. Исключение — если KMnO₄ в избытке и среда очень кислая.
🔴
Сопропорционирование: Mn⁺⁷ + Mn²⁺ → MnO₂↓. Если в задаче смешивают KMnO₄ и соль Mn²⁺ в нейтральной среде — оба дают Mn⁺⁴. Не перепутай с диспропорционированием.

Кислая среда (H₂SO₄, HNO₃, HCl)

В кислой среде перманганат восстанавливается до Mn²⁺ (соли марганца(II)), раствор обесцвечивается.

Примеры реакций в кислой среде 8KMnO₄ + 5PH₃ + 12H₂SO₄ → 8MnSO₄ + 5H₃PO₄ + 4K₂SO₄ + 12H₂O 8KMnO₄ + 5SiH₄ + 12H₂SO₄ → 8MnSO₄ + 5H₂SiO₃↓ + 4K₂SO₄ + 17H₂O 2KMnO₄ + 5H₂S + 3H₂SO₄ → 2MnSO₄ + 5S↓ + K₂SO₄ + 8H₂O 2KMnO₄ + 5H₂O₂ + 3H₂SO₄ → 2MnSO₄ + 5O₂↑ + K₂SO₄ + 8H₂O 2KMnO₄ + 16HI → 2MnI₂ + 5I₂ + 2KI + 8H₂O 2KMnO₄ + 5SO₂ + 2H₂O → 2MnSO₄ + K₂SO₄ + 2H₂SO₄ 2KMnO₄ + 5K₂SO₃ + 3H₂SO₄ → 2MnSO₄ + 6K₂SO₄ + 3H₂O 2KMnO₄ + 10FeCl₂ + 18H₂SO₄ → 2MnSO₄ + 5Fe₂(SO₄)₃ + 20HCl + K₂SO₄ + 8H₂O
⚠️ Важно
  • При окислении сильных кислот-восстановителей (HCl, HI) дополнительное подкисление не требуется.
  • Продукт окисления должен содержать тот же катион, что был у восстановителя (например, K₂SO₃ → K₂SO₄).
  • Для Fe²⁺ в кислой среде образуется соль железа(III) той кислоты, которая использовалась для подкисления.

Нейтральная среда (H₂O)

В нейтральной (или слабощелочной) среде Mn⁺⁷ восстанавливается до MnO₂↓ (бурый осадок).

Примеры в нейтральной среде 2KMnO₄ + 3H₂S → 2MnO₂↓ + 3S↓ + 2KOH + 2H₂O 8KMnO₄ + 3Na₃P + 4H₂O → 8MnO₂↓ + 3Na₃PO₄ + 8KOH 2KMnO₄ + 6NaBr + 4H₂O → 2MnO₂↓ + 3Br₂ + 2KOH + 6NaOH 2KMnO₄ + 2NH₃ → 2MnO₂↓ + N₂↑ + 2KOH + 2H₂O 2KMnO₄ + 3H₂O₂ → 2MnO₂↓ + 3O₂↑ + 2KOH + 2H₂O 2KMnO₄ + 3MnSO₄ + 2H₂O → 5MnO₂↓ + K₂SO₄ + 2H₂SO₄
💡 Сопропорционирование

В нейтральной среде перманганат может реагировать с солями Mn²⁺ (сопропорционирование):

2KMnO₄ + 3MnSO₄ + 2H₂O → 5MnO₂↓ + K₂SO₄ + 2H₂SO₄

Mn⁺⁷ + Mn⁺² → 2Mn⁺⁴ (MnO₂).

Сильнощелочная среда (KOH, NaOH)

В концентрированной щёлочи Mn⁺⁷ восстанавливается до MnO₄²⁻ (манганат-ион, зелёный раствор).

Примеры в щелочной среде 8KMnO₄ + PH₃ + 11KOH → 8K₂MnO₄ + K₃PO₄ + 7H₂O 2KMnO₄ + Na₂SO₃ + 2KOH → 2K₂MnO₄ + Na₂SO₄ + H₂O KMnO₄ + NO₂ + 2KOH → K₂MnO₄ + KNO₃ + H₂O KMnO₄ + Fe(NO₃)₂ + 3KOH → K₂MnO₄ + Fe(OH)₃↓ + 2KNO₃ 2NaMnO₄ + Na₂S → 2Na₂MnO₄ + S↓
⚠️ Особенности
  • При окислении бромидов, иодидов, сульфидов в щелочной среде щёлочь не нужна для уравнивания (она не входит в уравнение).
  • Продукты окисления восстановителей те же, но в виде солей (K₃PO₄, Na₂SO₄ и др.).
