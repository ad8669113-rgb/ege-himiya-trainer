Окислительно-восстановительные
реакции (ОВР)

Теория и 37 задач ЕГЭ — H₂O₂, HNO₃, H₂SO₄(конц), Cl₂, Br₂, KClO₃ и диспропорционирование. Без KMnO₄ и соединений хрома.

Классификация ОВР
  • Межмолекулярные — окислитель и восстановитель разные вещества: Fe⁰ + S⁰ → Fe+2S-2
  • Внутримолекулярные — в одном веществе, атомы разных элементов: 2NaN+5O₃-2 → 2NaN+3O₂ + O₂⁰
  • Диспропорционирование — один элемент в промежуточной с.о. и окисляется, и восстанавливается: Br₂⁰ + NaOH → Na+1Br-1O + NaBr-1

Важно запомнить
Вещества с промежуточной с.о. (SO₂, H₂O₂, NO₂) могут быть и окислителем, и восстановителем в зависимости от партнёра по реакции.
Br⁻, I⁻ → окисляются до Br₂, I₂ (0) при действии HNO₃(конц) или H₂SO₄(к).
S, P, C из любой с.о. → до высших: S+6, P+5, C+4.

Примеры реакций HNO₃

Mg + HNO₃(оч.разб) → Mg(NO₃)₂ + NH₄NO₃ + H₂O Zn + HNO₃(разб) → Zn(NO₃)₂ + N₂ + H₂O Fe + HNO₃(разб) → Fe(NO₃)₃ + NO + H₂O FeO + HNO₃(разб) → Fe(NO₃)₃ + NO + H₂O Fe(NO₃)₂ + HNO₃(разб) → Fe(NO₃)₃ + NO + H₂O CuS + HNO₃(конц) → CuSO₄ + NO₂ + H₂O Ag₂S + HNO₃(конц) → Ag₂SO₄ + NO₂ + H₂O PH₃ + HNO₃(разб) → H₃PO₄ + NO + H₂O I₂ + HNO₃(конц) → HIO₃ + NO₂ + H₂O NaI + HNO₃(конц) → I₂ + NaNO₃ + NO + H₂O (NaI — восст., I⁻→I₂) SO₂ + HNO₃(конц) → H₂SO₄ + NO₂
⚠️ Пассивация
Al, Fe, Cr пассивируются концентрированной HNO₃ на холоду (не реагируют). При нагревании реакция идёт.

Разбавленная H₂SO₄ — обычная кислота (не ОВР по сере).
KNO₃ + H₂SO₄ = нитрующая смесь

Типичные задачи с H₂O₂ (окислитель)

2LiBr + H₂O₂ + H₂SO₄ → Li₂SO₄ + Br₂ + 2H₂O Br⁻(-1) – ē → Br(0) | 2 (окисление, восстановитель — LiBr) O(-1) + ē → O(-2) | 2 (восстановление, окислитель — H₂O₂) 2Fe(OH)₂ + H₂O₂ + 2H₂SO₄ → Fe₂(SO₄)₃ + 6H₂O Fe(+2) – ē → Fe(+3) | 2 O(-1) + ē → O(-2) | 2 2Cr(OH)₃ + 3H₂O₂ + 4NaOH → 2Na₂CrO₄ + 8H₂O (Cr→+6, желтый) Cu₂O + H₂O₂ + 2H₂SO₄ → 2CuSO₄ + 3H₂O
Cl₂ / Br₂ Галогены как окислители
Cl₂ и Br₂ — сильные окислители. Cl₂(0) + 2ē → 2Cl⁻(−1). В щелочной среде окисляют Cr³⁺ → Cr⁶⁺ (жёлтый CrO₄²⁻), Fe²⁺ → Fe³⁺, S²⁻ → S⁶⁺ и т.д.

Cl₂ — типичные реакции

2Fe(OH)₂ + Cl₂ + 2NaOH → 2Fe(OH)₃ + 2NaCl Cr₂O₃ + 3Cl₂ + 10KOH → 2K₂CrO₄ + 6KCl + 5H₂O (желтый раствор) 2CrCl₃ + 3Cl₂ + 16KOH → 2K₂CrO₄ + 12KCl + 8H₂O H₂S + 4Cl₂ + 4H₂O → H₂SO₄ + 8HCl (NH₄)₂SO₃ + Cl₂ + H₂O → (NH₄)₂SO₄ + 2HCl SO₂ + Cl₂ + 2H₂O → H₂SO₄ + 2HCl

Br₂ — типичные реакции

KNO₂ + Br₂ + H₂O → KNO₃ + 2HBr 2Cr(OH)₃ + 3Br₂ + 10KOH → 2K₂CrO₄ + 6KBr + 8H₂O (желтый) SO₂ + Br₂ + 2H₂O → H₂SO₄ + 2HBr
Ключевые сигналы в задаче
«Жёлтый раствор» + щёлочная среда + Cl₂/Br₂ → скорее всего образуется CrO₄²⁻ (хромат — жёлтый) или I₂/Br₂.
«Две кислоты» + Cl₂ → один из продуктов HCl, другой H₂SO₄ (из SO₂/S) или HIO₃ и т.п.

ДИСПРОП. Диспропорционирование
Один и тот же элемент в промежуточной с.о. одновременно и окисляется, и восстанавливается. Окислитель = восстановитель.
Br₂⁰ + 2NaOH → NaBr⁻¹O + NaBr + H₂O Br(0) + ē → Br(-1) | 1 (восстановление) Br(0) − ē → Br(+1) | 1 (окисление) Br₂ является и окислителем, и восстановителем 2NO₂ + 2KOH → KNO₃ + KNO₂ + H₂O N(+4) + ē → N(+3) | 1 (восстановление → KNO₂) N(+4) − ē → N(+5) | 1 (окисление → KNO₃) NO₂ является и окислителем, и восстановителем
Подсказка в задаче
«Окислителем и восстановителем является одно и то же вещество» → это диспропорционирование. Ищи вещество с промежуточной с.о.: Br₂(0), NO₂(+4), SO₂(+4), Cl₂(0) и т.д.
АЛГОРИТМ Алгоритм решения задания 29
1
Читай условие внимательно: ищи ключевые слова — «бурый газ» (NO₂), «газ со сладким запахом» (N₂O), «жёлтый раствор» (хроматы/I₂), «окрашенный раствор» (Cu²⁺ голубой, Fe³⁺ жёлто-бурый), «два газа», «без осадка», «без газа».
2
Определи окислитель и восстановитель по с.о.: у кого высшая с.о. — окислитель; у кого низшая — восстановитель.
3
Определи продукт восстановления окислителя: HNO₃(разб) + [Fe...Ag] → NO; HNO₃(конц) → NO₂; H₂SO₄(к) + [Fe...Ag] → SO₂; H₂O₂ → H₂O.
4
Расставь степени окисления у всех атомов, которые изменяются.
5
Составь электронный баланс: число принятых электронов = числу отданных. Найди коэффициенты для окислителя и восстановителя.
6
Расставь остальные коэффициенты (атомы, не участвующие в ОВР) методом атомов/молекул.
7
Проверь баланс по кислороду и водороду. Укажи окислитель и восстановитель.
Ключевые слова → сигналы
  • «Бурый газ» → NO₂ → HNO₃(конц) или NO(разб) + O₂ на воздухе
  • «Окрашенный раствор» → Cu²⁺ (голубой), Fe³⁺ (бурый/желтый), Cr₂O₇²⁻ (оранжевый), CrO₄²⁻ (жёлтый), I₂ (коричн./фиолет.)
  • «Одна соль и вода, без газа» → проверь H₂O₂ с Fe²⁺ или Fe(OH)₂
  • «Окислитель = восстановитель» → диспропорционирование
  • «Простое вещество + бурый газ» → NaI + HNO₃ или I₂ + HNO₃(конц)
