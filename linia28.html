БЛОК 1

Выход продукта реакции

Ключевые формулы

Выход по объёму
η% = VпрактVтеор · 100%
Vпракт = Vтеор · η%100%
Vтеор = Vпракт · 100%η%
Выход по массе
η% = mпрактmтеор · 100%
mпракт = mтеор · η%100%
mтеор = mпракт · 100%η%
Моль / масса / объём
n = mM
m = n · M
n = V22,4
V = n · 22,4 л/моль
⚠ Три типа задач
  1. Дано η → найти Vпракт или mпракт — умножь теоретическое на η% и раздели на 100%
  2. Дан Vпракт → найти η — раздели практическое на теоретическое
  3. Дан Vпракт и η → найти исходное — обратная задача (в смесях)

Алгоритм решения

1
Напишите уравнение реакции
2
Найдите число моль исходного: n = m/M или n = V/22,4
3
Найдите nтеор продукта по коэффициентам реакции
4
Найдите Vтеор = n·22,4 или mтеор = n·M
5
Если дано η% → Vпракт = Vтеор · η% / 100%  |  Если дан Vпракт → η% = Vпракт / Vтеор · 100%
Запомни: η подставляется в формулы в процентах (например, 75%), деление на 100% автоматически переводит в долю

БЛОК 2

Технические смеси

Ключевые формулы

Масса чистого вещества
mчист. = mобразца · ωчист.%100%
ωчист. = 100% − ωприм.
Массовая доля примесей
ωприм. = mприм.mобразца · 100%
mприм. = mобразца − mчист.
Масса образца (обратная)
mобразца = mчист. · 100%ωчист.%
ωчист. = 100% − ωприм.
Объёмная доля
φ% = VвеществаVсмеси · 100%
Vвещества = Vсмеси · φ%100%
Vсмеси = Vвещества · 100%φ%
Моль / масса / объём
n = mM
m = n · M
n = V22,4
V = n · 22,4 л/моль

Ключевые понятия

Техническое вещество
  • Технический образец = чистое вещество + инертные примеси
  • ω(примесей) — доля примесей; примеси не реагируют
  • ω(чист.) = 100% − ω(прим.)
  • m(чист.) = m(образца) · ω(чист.) / 100%
⚠ Три типа задач
  1. Тип В1: дана ω примесей → найти V или m продукта
  2. Тип В2: дан продукт → найти ω примесей (или чистого вещества) в %
  3. Тип В3: дан продукт → найти массу исходного образца

Алгоритм (Тип В1)

1
Найдите массу чистого вещества: m(чист.) = m(обр.) · (100% − ω(прим.)) / 100%
2
Найдите число моль: n = m(чист.) / M
3
По коэффициентам реакции найдите n продукта
4
Найдите m = n·M или V = n·22,4
