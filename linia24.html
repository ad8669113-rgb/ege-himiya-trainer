Признаки химических реакций
Что это такое?
Признак реакции — наблюдаемое изменение, которое указывает на то, что реакция протекает. В задании нужно сопоставить пару веществ с наблюдаемым признаком.
🪨
Осадок
Выпадение нерастворимого вещества: белого, голубого, жёлтого, бурого, чёрного
💨
Выделение газа
CO₂ (бесцвет.), SO₂, NH₃, H₂S, NO₂ (бурый), NO, H₂, Cl₂
🎨
Изменение цвета
Появление или исчезновение окраски раствора
🫧

Реакции без видимых признаков

Когда «видимых признаков нет»
Реакция протекает, но внешне ничего не видно. Главный признак таких реакций — образование воды без выделения газа и без выпадения осадка.

  • Нейтрализация сильной кислоты сильным основанием: HCl + NaOH → NaCl + H₂O
  • Реакция с образованием только растворимых солей: CH₃COOH + NaOH → CH₃COONa + H₂O
  • Некоторые реакции обмена без осадка/газа: KHCO₃ + KOH → K₂CO₃ + H₂O

АЛГОРИТМ
Как решать задание Линии 24
1
Определи тип реакции — кислота + основание, соль + кислота, соль + основание, металл + кислота
2
Напиши продукты — по правилам ионных реакций. Осадок? Газ? Растворимые продукты?
3
Определи признак — по продукту реакции. Если в продуктах нерастворимая соль → осадок; газ → выделение газа; все продукты растворимы → нет видимых признаков.
4
Сопоставь с вариантами ответа — найди нужный номер и запиши 4-значный ответ для А, Б, В, Г.
💡 Лайфхак: осадок или нет — смотри в таблицу растворимости
Если хоть один продукт нерастворим (Н в таблице) → признак «образование осадка».
Если исходное вещество осадок + реагент → смотри, растворится ли он: Zn(OH)₂ + H₂SO₄ → ZnSO₄ (раств.) → растворение осадка.
⚠️ Ловушки:
• Амфотерные гидроксиды (Al(OH)₃, Zn(OH)₂, Be(OH)₂, Cr(OH)₃) растворяются и в кислотах, и в щелочах
• Хромат K₂CrO₄ (жёлтый) + кислота → дихромат K₂Cr₂O₇ (оранжевый) — изменение цвета
• Дихромат K₂Cr₂O₇ + щёлочь → хромат (жёлтый) — изменение цвета
• Cu + HNO₃(конц) → Cu(NO₃)₂ + NO₂ (бурый газ) + H₂O — и растворение металла, и выделение газа

Реактивы для распознавания веществ
Суть задания
Дана пара веществ (А, Б, В, Г). Нужно найти реактив, который реагирует с одним из двух (даёт видимый эффект), но не реагирует с другим. Это позволяет «различить» вещества.
⚗️
AgNO₃
Cl⁻→AgCl белый, Br⁻→AgBr жёлт, I⁻→AgI жёлт. Не реагирует с NO₃⁻, SO₄²⁻
🧊
BaCl₂ / Ba(NO₃)₂
SO₄²⁻ → BaSO₄↓ белый (нерастворим в HNO₃)
🟦
NaOH (изб.)

🔵

NH₃ → Cu(OH)₂↓ голубой; KOH → Cu(OH)₂↓. Не реагирует с NaCl, KNO₃
🟡
H₂SO₄ (разб.)
Ba²⁺→BaSO₄↓, карбонаты→CO₂↑, сульфиты→SO₂↑, Ме(акт.)→H₂↑
🟤
HCl / HNO₃
Силикаты→H₂SiO₃↓, карбонаты→CO₂↑, акт. Ме→H₂↑; Cu реагирует только с HNO₃
АЛГОРИТМ
Как выбрать реактив для различения
1
Определи «уникальный» ион у каждого из двух веществ в паре — что есть у одного, чего нет у другого?
2
Найди реактив, который реагирует с этим уникальным ионом и даёт видимый признак (осадок, газ, цвет).
3
Проверь: с другим веществом пары этот реактив не реагирует (или нет видимого признака).
4
Запиши номер реактива для этой позиции.
💡 Типичные пары и их реактивы:
Хлорид vs нитрат → AgNO₃ (AgCl↓ с хлоридом, нет с нитратом)
Al(OH)₃ vs Mg(OH)₂ → NaOH изб. (Al(OH)₃ растворяется, Mg(OH)₂ — нет)
Карбонат vs сульфат → HCl (CO₂↑ с карбонатом, нет с сульфатом)
Силикат vs карбонат → HCl (H₂SiO₃↓ с силикатом, CO₂↑ с карбонатом — разные признаки!)
⚠️ Ловушки:
• Cu реагирует с HNO₃(разб.), но не реагирует с H₂SO₄(разб.) и HCl!
• NaOH(изб.) растворяет Al(OH)₃ и Zn(OH)₂, но НЕ растворяет Mg(OH)₂ и Ca(OH)₂
• BaCl₂ даёт белый осадок и с SO₄²⁻ (BaSO₄), и с SO₃²⁻ (BaSO₃) — не различает их!
• Лакмус различает кислоту и щёлочь, но не различает два вещества одного класса

БЛОК 3 · ТЕОРИЯ
Качественные реакции органических веществ
Суть задания
Даны органические вещества (А, Б, В, Г) и признаки реакций. Нужно сопоставить каждое вещество с признаком его взаимодействия с указанным реагентом.
Алканы CₙH₂ₙ₊₂
✕ нет реакции с KMnO₄ и Br₂
не обесцвечивают KMnO₄ (розовый) и бромную воду —
нет кратных связей (нет C=C и C≡C)
Алкены, алкадиены, алкины (C=C, C≡C)
🟣/🟤→⬜ обесцвечивание
1. KMnO₄ (нейтр. среда): обесцвечивание + бурый осадок MnO₂
3CH₂=CH₂ + 2KMnO₄ + 4H₂O → 3HOCH₂–CH₂OH + 2MnO₂↓ + 2KOH
2. KMnO₄ (щелочная среда): 🟢 зелёный раствор (манганат K₂MnO₄)
CH₂=CH₂ + 2KMnO₄ + 2KOH → продукты окисления + 2K₂MnO₄ + 2H₂O
3. KMnO₄ (кислая среда, H₂SO₄): обесцвечивание (без осадка, Mn²⁺)
5CH₂=CH₂ + 2KMnO₄ + 3H₂SO₄ → 5CH₂OH–CH₂OH + 2MnSO₄ + K₂SO₄ + 3H₂O
4. Br₂ (водн., жёлтый): обесцвечивание
CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br
5. I₂ (бурый): обесцвечивание
CH₂=CH₂ + I₂ → CH₂I–CH₂I
Ацетилен и терминальные алкины (R–C≡C–H)
⬜↓ белый осадок / 🔴↓ красный осадок
1. [Ag(NH₃)₂]OH: белый осадок (взрывоопасен!)
CH≡CH + 2[Ag(NH₃)₂]OH → CAg≡CAg↓ + 4NH₃↑ + 2H₂O
2. [Cu(NH₃)₂]Cl: красный осадок
CH≡CH + 2[Cu(NH₃)₂]Cl → CCu≡CCu↓ + 2NH₄Cl + 2NH₃↑
не реагируют внутренние алкины (R–C≡C–R)
Бензол C₆H₆
🟡 жёлтая жидкость с запахом миндаля
Нитрующая смесь (HNO₃ + H₂SO₄): нитрование
C₆H₆ + HNO₃ → C₆H₅NO₂ + H₂O
нитробензол — светло-жёлтая маслянистая жидкость
не обесцвечивает KMnO₄ и бромную воду (ароматическое кольцо)
Толуол C₆H₅–CH₃, алкилбензолы
🟣→⬜ обесцвечивание KMnO₄
KMnO₄ + H₂SO₄: обесцвечивание (окисляется боковая цепь)
C₆H₅–CH₃ + KMnO₄ + H₂SO₄ → C₆H₅–COOH + K₂SO₄ + MnSO₄ + H₂O
бензольное кольцо не обесцвечивает KMnO₄ и Br₂
Фенол C₆H₅–OH (карболовая к-та)
🟣 фиолетовый р-р / ⬜↓ белый осадок
1. FeCl₃ (р-р): фиолетовый/малиновый раствор
C₆H₅OH + FeCl₃ → фиолетовый комплекс
2. Br₂ (водн., насыщ.): белый осадок + обесцвечивание
C₆H₅OH + 3Br₂ → C₆H₂Br₃OH↓ + 3HBr (2,4,6-трибромфенол)
3. Na, K: H₂↑ (кислотные свойства –OH)
Анилин C₆H₅–NH₂ (аминобензол)
🟣 фиолетовый р-р / ⬜↓ белый осадок
1. CaOCl₂ (хлорная известь, бесцв.): фиолетовый р-р
C₆H₅NH₂ + CaOCl₂ → фиолетовый комплекс
2. Br₂ (водн., насыщ.): белый осадок + обесцвечивание
C₆H₅NH₂ + 3Br₂ → C₆H₂Br₃NH₂↓ + 3HBr (2,4,6-триброманилин)
Спирты, фенол (–OH группа)
💨 выделение H₂↑
Металлический Na, K: пузырьки H₂, бесцветная масса
2CH₃–CH₂–OH + 2Na → 2CH₃–CH₂–ONa + H₂↑
2C₆H₅OH + 2K → 2C₆H₅OK + H₂↑
кислоты (–OH не спиртовой): тоже + H₂↑ с Na
Этанол CH₃–CH₂–OH (особые реакции)
🟡↓ осадок CHI₃ / 🔴↓ медь
1. I₂ + NaOH (иодоформная проба):
CH₃–CH₂–OH + I₂ + NaOH → CHI₃↓ + HCOONa + NaI + H₂O
осадок CHI₃ — светло-жёлтый, специфический запах
2. CuO (прокалённая медная проволока):
CH₃–CH₂–OH + CuO → CH₃CHO + Cu↓ + H₂O
медь восстанавливается, запах ацетальдегида
Многоатомные спирты, глюкоза (≥2 –OH рядом)
🔵 ярко-синий раствор
Cu(OH)₂ (свежеосажд., без нагрева): растворяется → ярко-синий р-р
2HOCH₂–CH₂OH + Cu(OH)₂ → этиленгликолят меди(II) + 2H₂O
реагируют: глицерин (3×–OH), этиленгликоль (2×–OH), глюкоза
не реагирует: одноатомный спирт (только 1 –OH)
Альдегиды –CHO (и муравьиная к-та HCOOH)
🪞 серебряное зеркало / 🔴↓ Cu₂O
1. [Ag(NH₃)₂]OH: блестящий налёт Ag («серебряное зеркало»)
CH₃CHO + 2[Ag(NH₃)₂]OH → CH₃COOH + 2Ag↓ + 4NH₃↑ + H₂O
2. Cu(OH)₂ (свежеосажд., нагрев): красный осадок Cu₂O
CH₃CHO + 2Cu(OH)₂ →(t°) CH₃COOH + Cu₂O↓ + 2H₂O
HCOOH также: имеет –CHO → даёт оба признака
Муравьиная кислота HCOOH
🔴 лакмус / Cu₂O↓ / серебряное зеркало
1. Лакмус: розово-красный р-р (кислота)
2. Cu(OH)₂ (нагрев): красный осадок Cu₂O (есть –CHO!)
HCOOH + Cu(OH)₂ → Cu₂O↓ + CO₂↑ + H₂O
3. [Ag(NH₃)₂]OH: серебряное зеркало (есть –CHO!)
HCOOH + 2[Ag(NH₃)₂]OH → (NH₄)₂CO₃ + 2Ag↓ + 2NH₃↑ + H₂O
Карбоновые кислоты (–COOH)
🔴 лакмус / 💨 CO₂↑ с NaHCO₃
1. Лакмус: розово-красный р-р
2. NaHCO₃: выделение CO₂↑
CH₃COOH + NaHCO₃ → CH₃COONa + CO₂↑ + H₂O
3. Спирт + H₂SO₄ (катализ.): запах сложного эфира
CH₃COOH + CH₃CH₂OH ⇄ CH₃COOC₂H₅ + H₂O
Олеиновая кислота C₁₇H₃₃COOH (C=C есть!)
🟣/🟤→⬜ обесцвечивание (как алкены)
1. KMnO₄ (водн.): обесцвечивание + MnO₂↓
C₁₇H₃₃COOH + KMnO₄ + H₂O → [по C=C] + MnO₂↓ + KOH
2. Br₂: обесцвечивание (по C=C)
3. I₂: обесцвечивание (по C=C)
стеариновая C₁₇H₃₅COOH — насыщ., не обесцвечивает!
Ацетаты CH₃COO⁻ (соли уксусной к-ты)
🟤 красно-бурый р-р с FeCl₃
FeCl₃ (р-р): красно-бурое окрашивание
3CH₃COONa + FeCl₃ → (CH₃COO)₃Fe + 3NaCl
реагируют: ацетат натрия, кальция, аммония…
Стеарат натрия C₁₇H₃₅COONa (мыло)
⬜↓ осадок / 🌸 малиновый (фенолфталеин)
1. Раствор Ca²⁺ (CaCl₂): серовато-белый осадок
2C₁₇H₃₅COONa + CaCl₂ → (C₁₇H₃₅COO)₂Ca↓ + 2NaCl
2. Конц. HCl (H⁺): белый осадок стеариновой к-ты
C₁₇H₃₅COONa + H⁺ → C₁₇H₃₅COOH↓ + Na⁺
3. H₂O (гидролиз) + фенолфталеин: малиновый р-р (щелочная среда)
Крахмал (C₆H₁₀O₅)ₙ
🔵 тёмно-синяя окраска с I₂
I₂ (р-р): тёмно-синяя/фиолетово-синяя окраска
не реагируют с I₂: глюкоза, сахароза, целлюлоза
реакция обратима: при нагревании окраска исчезает, при охлаждении — возвращается
Белки (полипептиды)
🟡→🟠 ксантопротеиновая / 🟣 биуретовая
1. Пламя: запах «жжёных перьев / паленого»
2. HNO₃ (конц.) — ксантопротеиновая:
жёлтое окрашивание → + NH₃: оранжевое (ароматические а/к)
3. Cu(OH)₂ в щелочи — биуретовая:
ярко-фиолетовый р-р (пептидные связи –CO–NH–)
4. Pb(CH₃COO)₂ в щелочи — цистеиновая:
чёрное окрашивание PbS (цистеин содержит –SH)
